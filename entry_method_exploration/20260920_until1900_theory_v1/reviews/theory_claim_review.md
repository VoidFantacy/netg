# 综合理论表述复查

2026-09-20，root对本次推导、冻结报告和数据角色作逐项检查。此表是自审，不是独立第三方审稿或新增实验。

| 结论 | 证据/推导 | 必须保留的条件或反例 |
|---|---|---|
| GT10是解析学习目标的最优解 | 加权单位query与hub先验的线性球面目标，Cauchy–Schwarz | 固定权重、非退化向量；不是搜索最优或全部浮点实现保证 |
| 加权方向有有限样本风险解释 | 对Z=a(Q)X(Q)作IID均值分析，再转方向亲和风险 | H事先固定、IID未在真实来源证明、总体均值非零；a可依赖query，十GT不是十独立样本 |
| 系统收益不能全部归给十目标 | E106同H精确GT10−GT1混合，E107单位hub自适应单入口已有收益 | H本身由GT监督选择，精确路由成本不同；一个L不是完整性能结论 |
| GT10小图较省距离计算 | E115四格与后继32768对原/观察版结果及NDC恢复 | 完整图状态含不同层级/入口；尚未分离纯建边原因，不是QPS结论 |
| 省NDC并非必然展开更少 | 固定U时GP展开略多而邻边扫描更少 | 计数器原来只含上层；base首次/skip是源码恒等式派生量，不伪称独立探针 |
| 集中度不足以解释稀疏图 | 共同分量嵌入使距离统一正缩放、方向更集中 | 理想精确算术及固定层级/顺序；保持中心化相对谱，不能拿来否定降内在维度解释 |
| 最终topK的严格得分局部闭合 | 原池维护/最终成员完整展开，E114所有返回出邻接核验 | K≤L、无额外提前停止、同节点分数固定；严格得分不等于指定并列GT ID |
| 入口变化常汇合到同一终点 | E114八种既有策略在多数query同K1返回 | 有限八策略，非全H或全策略不可能性；相同K1不等于K100/路径/wall相同 |
| 图/GT1信息不足以完全决定最佳入口 | 旧四次query分支反例，同GT1而入口优劣翻转 | 人工有向图；该例线性query符号即可区分，不证明必须MLP |
| 两固定动作单线性评分可能不够 | 新XOR人工图8次原内核核验与线性不可分证明 | 仅两固定单入口动作；四画像和简单非线性都能解决，非当前WFree不可能性 |
| 首行覆盖有经验次模保证 | E112固定图/GT的单调最大覆盖，标准贪心界 | 只保证经验覆盖；GT100外部排名/浮点/并列仍是假设；信息门失败不等于实际Recall已失败 |
| 排名核心提供条件可达保证 | E111当前kernel范围审查；与NGFix直接相关 | 已有前作，不称新定理；重复向量GT ID的原违例保留；覆盖不足不是效用上界 |
| WFree已拟合教师但未形成净收益 | E104 fit C8最优集合100%，E105救回/损伤125/126与63/63 | 不是全H真实效用拟合100%；入口变化、命中状态变化、净Recall是不同量 |
| 平均分数漂移未扩大 | 冻结WFree的cal/E105残差约为fit的0.93–0.98倍 | 总体平均不排除局部排序边界改变，不是Recall稳定证明 |
| 教师支持稀疏与迁移困难相容 | 非恒定教师支持、具体比较对和GT ID覆盖统计 | 没有独立识别全部因果份额；不是证明抽象图特征不存在 |
| 区间跨0应保留不确定性 | 原配对query区间与净增损方差恒等式 | 不证明真值精确0，不自动追加数据；局部多重校正不抵消研究过程中的开发集曝光 |
| 保留默认与停止候选有依据 | E105完整wall、E108匹配线上对照及E112/E113/E115预锁门 | 相应版本未满足门，不能据此否定全部RL/MLP/入口优化；不承诺论文录用 |
