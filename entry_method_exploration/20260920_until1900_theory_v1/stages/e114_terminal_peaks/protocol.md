固定 E107 两集全部4096条已曝光开发 query，8个原方法、K1/L128；读取原真实返回 ID/距离及原 GT100 的第一列。每个 query 对相同返回 ID 只扫描一次原图有效出邻居；同向量不同 ID 分开保存，GT1 仍按原 ID 命中。原图/查询/GT/返回均不修改，无新的 ANN/NSG/GT/图/梯度或画像训练。

数值审查以原 float32 向量在 float64 中重算内积；记录每终点最小出边得分差、差向量归一化后的最小间隔、GT1 得分差、同向量标记和原返回距离偏差。全部严格负差及浮点误差界内的不确定非同向量差用精确有理数复核，保留全部例外，不凭阈值删除查询。保守 float64 内积误差界采用 gamma_(2d+3) 乘绝对乘积和的两倍；同向量差直接确认为0。

对每方法保存局部闭合通过/违反数、旧 R1/失败数、半径分位；对全部28个方法对保存终点 ID/向量相同率、GT1 增损、双方都失败时得分变化。保存全部8方法终点多样性和旧结果中的有限联合成功率；这些是已测方法范围描述，不是可部署 oracle 或全入口上界。全部查询等权，不按结果另选数据、特征、阈值或 learner。

独立数值核验预定 query 位置0、256、…、3840，检查全部出现终点及所有出邻居；用 math.fsum 分别累加原 float32 乘积并与向量化结果比较。原 E107 16点 R1/失败数重新核对汇总 CSV；源/结果 SHA 保存，图 size/mtime 与旧配置相同。
