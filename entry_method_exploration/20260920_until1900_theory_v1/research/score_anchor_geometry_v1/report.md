# WFree锚定没有在后续query上整体失控

2026-09-20。只读原WFree/原P、原fit/cal与已曝光E105 query。检验的是平均平方分数漂移，不是新Recall或ANN性能；模型/默认保持。

|---|---:|---:|---:|
| Web fit2048 | 0.00107872 | 1.0000 | 1.0000 |
| Web cal512 | 0.00100926 | 0.9356 | 8.2016 |
| Web E105曝光4096 | 0.00100471 | 0.9314 | 4.7758 |
| Yandex fit2048 | 0.00173308 | 1.0000 | 1.0000 |
| Yandex cal512 | 0.00169017 | 0.9752 | 3.5995 |
| Yandex E105曝光4096 | 0.00169123 | 0.9759 | 2.2906 |

实际Delta的漂移在两组后续query都略低于fit，因此没有支持“平均分数锚定在新query上严重放大”的解释。最坏方向上界较大，与实际模型所用方向是两个事实。分数漂移没有放大不保证top3不变，也不能排除个别hub/边界的变化；本版不增加事后子集检验或正则网格。

每hub潜在教师支持很小：排除56动作全最优、损失恒为0的query后，C8中出现的查询数中位数Web13、Y10；最大142/47，全部815/821个hub都少于512/200维。Web49、Y3个hub无此类教师支持。这里给的是数据项梯度张成空间的秩上界，不能据此声称其他方向完全不受约束，因为全H score anchor仍使用全部fit query，也不证明这是泛化失败的因果原因。

Web fit二阶矩条件数约5.46e7、Y约1466，两者在预设阈值下均数值正定。直接QDelta与二阶矩trace计算最大差约1.09e-18，原float32训练漂移复原。该有限矩阵比较不检验总体IID或源分布相同；小样本/高维也影响广义特征值。

共计算10,889,216个线性分数残差坐标，0新模型训练/NSG/ANN/GT/图，分析0.411秒、RSS约169MiB。19项输入SHA前后相同，全部query漂移与hub支持保留；E105只读取query，不读取其GT或失败标签。
