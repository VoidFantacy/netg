# E220 Q8 等价提速与按需扩表回放

使用 E219 已验收的模型、图、GT10 路由、CPU15 单线程和公布的查询窗。所有正常计时每点两遍，按实际 N/wall 取平均，完整批次包含主搜、补点、六数组复制与生命周期。候选集合、粗分、同分规则、原距离精算和最终合并沿原版。此实验聚焦 E219 加密的 COCO 和 WebVid K100，另做 WebVid 真 K1 的等价回放。生产版本另有 E99/E211 合同。

## 四种等价实现

- Q8-original 复用原实现。
- Q8-check 只把粗排中码槽异常、入口异常和预算检查的错误字符串移到失败分支。
- Q8-top 只把全排序换成各侧前 min(16,旧尾数,新点数) 的选择再局部排序，沿原比较器。
- Q8-fast 合并两项。

全量 dev/cal 使用 E219 实际 L184、相同真实 K 和补点宽度。逐查询在四实现中核对精算候选 ID、精算浮点和最终结果字节，并对原版返回核对 E219 封存。另在公共窗计时前做 256 查询逐项资格验证。回放补点速度独立计量，另在独立的带计时副本中分段记录候选构造、选代表、取表、编码、打分、排序写回及精算合并。分段仪表不用于正式吞吐。

正式使用公共 3072–6143 行，COCO 两表，WebVid 四表。两集控制 L224/228/232/236/240/244/248，每 L 测 GT10、完整 B32、B32-fit、CACHE 和 BKT8。COCO L224、WebVid L232 四种等价版本同批 A/B。COCO L232 和 WebVid L224 另跑 Q8-fast。找到达到每个 Q8-fast 实际召回的最快同期控制点。复核与 E219 重叠的原始返回。公共 GT 在全部正式批次结束后仅用于评估。

## WebVid K100 按需扩表诊断

在同一 L184 训练角色回放，Q8-fast2 与四表共享两张最近表及相同的逐查询精算名额。每条以真实 Top-K 的四表减两表命中差作收益。只用两表扫描后、原距离精算前就能拿到的信号，包括第 K 名门槛、粗分最好的新点到门槛余量、达到门槛的数量、新点、尾部和实际置换数。开发窗用固定 L2 逻辑回归拟合是否有额外净收益，按开发窗至少保留 98% 正净收益的阈值冻结后回放校准窗。报告节省四表的比例以及相对同窗 B32-fit L192 的实际命中差。此处只诊断可预测性和扫描上限，计算及时间与完整等价 A/B 分开。
