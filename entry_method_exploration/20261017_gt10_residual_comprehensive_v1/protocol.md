# E183：GT10 与残差补全的跨数据集及失败查询综合评测

2026-10-17。用户明确授权执行较全面的多模态、非多模态测试，并交付详细中文 PDF。生产默认 E99 GT10 作为当前背景；本轮在独立目录实现、冻结和评价，不覆盖历史科学产物。

## 问题与范围

1. GT10 入口方案相对原 NSG 的 Recall–QPS、救回与损伤。
2. 固定 GT10 路由与主搜索后，训练遗漏编表补全的增量收益与完整查询费用。
3. 这些效应在 Deep10M、BIGANN-SIFT10M、GIST1M（原始 squared L2）和 WebVid、Yandex、COCO、Flickr（原始 IP）上的差异。
4. 失败查询的修复比例、损伤、残留失败，以及训练源覆盖、路由关联、容量选取和合并边界。

七集均复用已确认的原始底库、主图、GT10 画像、小图和合法查询角色。大资产直接引用，禁止为统一代码而归一化底库或更改 metric。五个 E97/E103 数据集保留真实 ID 升序的入口合同；COCO/Flickr 保留其 E181 heap-pop 合同。不同数据集之间还有规模、维度、图、训练密度和来源差异；此评测证明迁移表现，不能单独证明模态的因果效应。

## 冻结方法和预算

每个已有 hard/soft 的数据集测 NSG、GT10-hard、GT10-soft-t1、hard+JOINT8、hard+JOINT32、soft+JOINT8、soft+JOINT32。COCO/Flickr 沿已有 hard 画像测 NSG、GT10-hard、hard+JOINT8、hard+JOINT32，不用测试选择新画像。共计划 645 个方法/K/L 点、1935 个正式计时批次。

K1 的 L 为 16/32/64/100/200/400/800/1200；K100 的 L 为 100/128/200/400/800/1000/1200。全部使用真实 K1/K100 输出。每点三轮完整单线程计时，预热最多256条，轮换方法顺序；使用各集原完整测试角色（Deep/SIFT/Web/Y各10K、GIST1K、COCO10K、Flickr5K）。新增范围或修复须保留原尝试并说明原因，不能看结果追加到通过。

每个 hard/soft 分别用合法非test残差查询的前16000条、K100/L200主搜索遗漏，训练一张单位 query–GT 成员 token 的表。Deep/SIFT/GIST及Web/Y可与原画像fit共享训练查询，必须如实披露；COCO/Flickr沿独立残差角色。每query遗漏目标与当时三个路由hub关联，按最大未覆盖token贪心取表，按B8→B32前缀扩展，ties依hub/目标固定ID。保存未截断的源/路由关联池。K1/K100共享同张K100教师表，是冻结迁移条件，不宣称最优。测试query、GT和失败标签不进入训练、容量选择或方法选择。

NSG使用原固定入口；GT10使用原小图三入口；POST保留同一原主搜索返回及距离，只对去重且未在主返回中的表候选按实际任务距离补算和topK合并。没有第二次主图搜索。主比较是NSG→GT10和GT10→GT10+补全；各L曲线同时提供增大L的成本替代。此设计不声称补全独立于GT10。

## 测量与输出

正式固定 CPU15、threads=1、OMP/BLAS/MKL/NUMEXPR=1，核实际进程/OMP线程。训练、GT、hash、编译和绘图在正式计时之外串行安排。wall含正常Batch/visited/retset创建、初始化、路由、原主搜索、补点、统一输出包复制和正常销毁；加载、GT评分、审计和写盘在wall外。所有方法采用相同主搜索核；新绝对QPS不与E103的不同优化核拼接。

保存第一轮实际计时输出（ID、float32距离、入口ID和画像距离）及其SHA。其余两轮输出必须逐字等于第一轮并保存逐轮hash/耗时，不能将一次未计时重跑冒充计时输出。GT10与POST的主返回/路由保持核验；全部post输出由独立标量合并oracle核验。小规模距离/GT抽样审计与正式输出整数独立复算分开。

完整曲线保留全部实测点，速度报三轮中位数、范围及轮内配对比率。共同Recall区间的线段插值只作为描述，不称为新增等Recall实测点，不外推。三轮计时不增加质量样本数；query bootstrap按对齐查询抽样，只作已曝光测试上的描述性区间。历史公开测试已曝光，不称新盲确认或无偏方法选择。

## 失败和覆盖分析

K1分别报 miss→hit 的救回、hit→miss 的损伤、持续miss，救回率以原miss为分母，损伤率以原hit为分母。K100分别报真实GT成员补回/丢失、遗漏修复率、逐query净变化，并按基线hits=0、1–10、11–50、51–90、91–99、100分层；至少补1个成员不能写成整条query已解决。预先采用90/100命中作为额外质量门槛，100/100完整恢复另列。模块相对各自基线，并单列GT10新增失败被补全修复的数量。

对每个GT遗漏依次区分：训练残差全局源外、源内但当前三路由关联源外、路由源内但有限表未选中、候选存在但未最终命中、实际补回。另按目标在训练中的频次分层。候选覆盖是机会，最终救回才是质量收益。重复向量/浮点近并列/GT ID tie保持原统计，另作诊断；不能依据测试表现修改GT。
