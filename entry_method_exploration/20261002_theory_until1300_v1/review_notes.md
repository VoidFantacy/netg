2026-10-02，13:00截止研究。此记录区分审阅职责与证据强度，不是新性能核验。

## 职责与核验范围

- 搜索理论代理核对原有限pool源码、证明/反例与5篇直接前作；历史代理独立审阅可达行状态、安全前沿、native区间条件和新MIPS代数，没有遗留逻辑问题。
- 访问论文代理实读9篇访问/成本论文及GATE补充，核对固定作者代码；root核对metric/概率迁移及完整费用关系，并对17＋3篇实读来源建立清单。记录的是相关章节，不是20篇全文或穷尽新颖性审查。
- 桶核算的两实现来自同一代理，不能称人员独立。旧终局返回的第二实现来自另一代理，使用stdlib独立重算147456个pair-query、828字段；无新搜索或新确认query。
- 封存工具只核对输入身份、脚本/结果对应、文档语法/链接和声明范围；它不执行native、不重新跑数学/统计脚本、不测QPS。

## 已解决的实质修正

| 审阅发现 | 最终处理 |
|---|---|
| GTK/native共同序不能省略，混合kernel比较也需共同严格序 | 精确Recall等式显加前件；区间下界区分Q_L展开和Q_K返回；真实全base前件未证明 |
| 原hub通常在P_L外，初始安全闭包可能为空 | 增加实际outside-expanded的后验边界B_L分解；不包装成免费在线特征 |
| 同终局K-ID集合不证明中间pool汇合或费用一致 | 旧响应统计保留终局含义，单独记录NDC；无逐query wall或prefix trace |
| 旧同集合也有不同返回顺序 | 保留164个累计pair-query边界，不归因为某种tie或kernel错误，不外推位级保真 |
| 默认memo可变慢，单独胜DefaultMemo可制造假成功 | 先保原Default控制；再纳入UpperHandoff，最终门使用所有冻结默认的最快者 |
| 同ID/bytes并不自动证明跨地址回调bits一致 | 明列原callback跨槽bit/地址算术路径门；cache只改变计算，不合并物理图节点 |
| 上层终点本已评分，base再次计算 | 增加两路UpperHandoff简单控制；只在原base会评分分支复用，通用memo须公平比较 |
| 简单pivot球界当前阈值无间隔，不代表整行永不拒绝 | 保留邻居处理收紧threshold后的例外，未预测实际触发率或速度 |
| E116槽绑定H外动作会随query选slot变化 | 不把动态H外/保两入口命名为首次；新组合缺口限定20Kraw访问与真联合反馈 |
| Query-scaled的top1对齐与全排序/近似质量不同 | 给全比较margin条件、top1不保top2例及1D近似反例；严格μ边界写明tie |
| GATE已是直接且本地已适配前作 | 核对E96/E97/E103与作者snapshot，区分数学最短hop、发现hop和完整wall；不以release问题反推论文实验无效 |
| E166绝对QPS来自共享span+batch4研究核 | 明确为研究控制时钟，原E99输出回归不等于生产现场计时；换核需所有控制重测 |
