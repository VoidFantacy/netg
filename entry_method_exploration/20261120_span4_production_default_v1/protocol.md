# E211 正式入口 A/B 与默认切换

2026-11-20预先固定。目标是验证 E210 的 span+batch4 能否在生产 ACSG::search_new mode=2 默认使用。正式两臂走同一二进制、同一个函数和已有 GT10/B32 流程。仅在 batch 外切换索引内布尔开关。复用 E210 四套 raw-IP 的图、存储、GT10画像、完整 B32 表及公开前3072条查询。本轮宽度按当前邻接行求得，无离线缓存。L2 与非标准 Flat 用标量后端。

## 矩阵和计时

- 数据集 COCO、Flickr30k、WebVid、Yandex first10M。真实 K1 的 L64/100/160/200/320/400/800，真实 K100 的 L100/160/200/320/400/640/960。
- 纯 GT10 与原 GT10+B32 各配新旧内核，总 224 点与 448 批。CPU15、实测单线程、OMP/BLAS 等单线程，按状态旋转顺序且第二遍反向，每批前预热256条。
- 完整 wall 包含正常临时批分配、路由、主搜与相应补点、六数组复制和销毁。加载、预热、输出写盘、SHA、merge oracle、GT及并发回归在计时外。QPS用两遍各 N/wall 的算术平均。
- 每集先验证全矩阵每臂256条返回，并逐状态比较另64条的完整候选池字段和 visited。所有正式重复和新旧配对要求 ID、距离位元、入口与画像距完全一致；实际数据与 E210 冻结包交叉核。B32逐查询做独立线性合并核对。GT在四集计时全部完成后才实读。

## 默认验收

- 四个适用数据集都需要字节等价、scratch 等价与分流/回退测试通过。单点速度筛选为平均QPS至少+1%，较慢的优化遍快于较快的标量遍。每集每个K与每种方法至少5/7点通过，且无双遍一致下降超过3%的点。报告所有未过速度筛选的点。
- 验收后修改源码的默认开关，再独立重建，验证默认分流与显式回退。覆盖同索引并发独立 scratch、边修改、空/重复入口、访问标记循环、L2及自定义距离回退。仅模式2原生 Flat IP 开新内核，旧格式索引继续可读，无需重训画像或重造表。生产源码、产物和历史 E210 静态库分别保留。
