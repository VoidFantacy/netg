# E95结果与当前分支停止结论

2026-09-14。**没有得到更好的方法；停止当前固定H、围绕GT10的参数扰动RL、画像增补与小图构造/局部修补分支。** 默认仍为Web GT10-soft-t1 / Yandex GT10-hard。停止包含本轮两种查询统计构图；不再排队追加尺度、seed、ef、簇数、步长或RL训练。此结论是有边界的研究取舍，不是否定所有入口学习、所有RL或整个ACSG项目。

本轮在既有E23–E94证据之外，实际完成了一个机制不同的最小实验，随后按查询前冻结的门停止。不是仅将9月13日收口状态重述为目标完成。[停止决定](decision.md) · [方法比较](research.md) · [冻结协议](protocol.md) · [开发门](results/gate.json)

## 做了什么

从原P-fit20K raw query计算未中心化二阶矩，用full平方根作为主方案、仅保留对角作为备选，构造新的离线坐标C=P A。普通HNSW在C上建图，再逐字恢复原GT10画像P；线上仍raw query→一次HNSW top3→三个真实入口→原NSG。没有在线变换、网络、多画像或额外入口，也没有使用E94最终坏例。

与E56局部有界rank16奖励扰动不同，这里是一次闭式全维共响应构造；与E78改变线上评分相反，本轮线上所有画像字节不变。这样检验“用查询分数的共响应关系改造导航边”能否在保留评分函数时改善真实搜索。它不保证保留原HNSW的近似入口行为。

两数据集各7952历史aux query，L64/128；identity/full/diag三个模型全部实测。独立128预检另收费。fit源行10000–29999与aux2048–9999不交叠，aux固定两半3976；这些数据均有历史暴露，接受反馈计开发/训练信息，不称盲验证。

## 全量结果

Recall变化单位为百分点；失败为返回top10与GT10零交集的净新增数量，参照各数据集匹配的原GT10。

|---|---:|---:|---:|---:|---:|
| Web full | −2.3868 | −1.4940 | +225 / +130 | −35.49% | +4.40% |
| Web diag | −3.8556 | −2.0297 | +359 / +165 | −52.82% | +6.85% |
| Yandex full | −0.0553 | −0.2364 | +23 / +28 | −13.96% | +2.60% |
| Yandex diag | −0.0478 | −0.0666 | +3 / +3 | −5.50% | −0.009% |

八个完整比较点Recall均负；固定两半的16个Recall差也全部为负。四个候选–数据集组合均未过预锁开发门。Web的full/diag分别改变7610/7488条query的三入口；Yandex分别改变7079/609条。因此本轮不能归因于“修改太小、没有实际改道”。

全量路由NDC下降没有带来更好的原NSG搜索：L128总NDC变化依上表顺序为+1.85%、+3.03%、+2.00%、−0.21%。Yandex diag虽总NDC略减，Recall与失败仍退化。**NDC不是wall，本轮没有测QPS，也没有得出端到端加速结论。** 因开发门全部失败，条件五L五轮性能阶段未启动。

共响应构图实际产生了不同且更差的入口行为，说明保住P评分函数不足以保住原路由收益。未中心化统计受到共同方向、画像范数及HNSW建图规则影响可能解释退化；本轮没有做这些因素的独立干预，因此只将其列为解释假设，不把原因定为“均值偏置”或宣布全部查询感知构图无效。不能按结果再加中心化、收缩强度或反向变换网格。

## 为什么停止当前分支

1. 现有优化问题已用真实对照定位：E50发现正候选到确定更新的转化缺口，E52/E53已经实际修复部分更新方式，E56已分离纯构图；不能再把“直接提交、真实步长或只学图”列为未试过的新方案。
2. 动作与迁移证据分开：E60只证明既有固定小动作支持稀疏；E89/90证明较大恢复动作有查询间增损、并图非加性与跨来源门失败，不能以扩大动作或反馈预算自动解决。
3. E94的完整最终比较未建立稳定优于原GT10的整体Recall–QPS前沿；Web后期修复主要追回compact自己的损失。
4. 本轮定向比较了监督静态画像、多步图编辑策略和闭式查询统计构图。前两者没有足够新的可检验动作/迁移依据，第三者用有限实测补齐后也失败。因此不再投入当前分支，而不是仅因论文里出现过组件就否决方法。

原GT10局部收益、Web局部RL和组合修复等正信号继续保留；停止不证明搜索空间全无解。若将来有实质不同的新问题与独立证据，应另立分支，不恢复本runner或从E94最终失败例选动作。[既有机制复盘86](../../experiment_history/86_post_closeout_rl_direction_review.md) · [E32原开发门](../20260911_direct_reward_policy_v1/results/development_gate.json) · [E33原开发门](../20260911_hnsw_edge_rl_v1/results/development_gate.json) · [E90原接受门](../20260913_until2100_v1/stage31_cross_source_restore_v1/results/gate.json)
