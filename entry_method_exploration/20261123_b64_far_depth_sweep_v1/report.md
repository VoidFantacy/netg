# E231 WebVid 第三路深度扫描

保留原 B32 前缀。B64 对最远入口分别扫描 40/48/52/56/60，另两路保持 64。同期比较 B32、老 B64、均匀 B56。真实 K100，次序、底库、主图、GT10 路由、原生精算合并固定。

开发和确认各 3,072 条。确认物理行从 3073 至 9222 按冻结清单选择，与开发、E229 诊断及原画像拟合窗精确字节隔离。176 点、352 批 CPU15 单线程两遍完整计时。结果均从真实返回评分。
