# A+B 入口选择方法调研

建议选择**主方案：Fast 初始化的低秩多区域入口路由**；备用为**本地 v4 的直接效用斜切树**。本轮结论是“有合理的可实现研究方案，等待方法选择”，不是方法有效或实验 GO。

主方案保持 815/821 个、原维度的路由向量，把“向量代表哪个真实入口”从一一绑定改为可学习的多对一映射，并按原 NSG、指定 L 下的真实 Recall 联合调整向量和映射。低秩表示在离线折叠，在线仍是一轮 Micro-HNSW 内积检索和一次 ID 查表。相同索引规模不保证相同路由耗时，仍须未来实测。
