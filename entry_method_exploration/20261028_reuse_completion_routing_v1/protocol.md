# E189：复用 GT10 信息的稀疏补全路由

2026-10-28，用户明确要求“继续研究吧”。本协议先于新模型、返回和性能。E188 已完成，本轮独立版本，旧科学文件和 seal 只读。

## 假设与固定方法

E188 同时付出全1024粗代表评分与区域内全部块代表评分。研究已有三个 GT10 入口和主返回能否直接提出有用的少量区域/块，减少重复路由，保留对旧固定ID表外目标的访问。不是 E174 的 posting seed 加 NSG 一跳；本轮不读邻接、不改变主搜索，候选来自 E188 全base PQ块。

新训练只读原合法16K的前12000条 query 的 L200 教师返回、入口与 GT100。将每个实际遗漏成员映射至 E187 区域和 E188 块，向该query的三个真实入口分别累加成员出现次数。每hub分别选计数最高8个区域/8个块，ties按整数ID；不足8用-1。没有测试训练、超参搜索或新距离核。块含原全base ID，不局限于训练见过的目标ID；稀疏表仍可能限制泛化，必须测量。

- REUSE-REG：三个入口的区域表并集（最多24）加主返回100个ID中计数最高8个区域。计数ties按区域ID。去重后最多32个粗代表原metric评分，保留最近最多8个，沿冻结E187 REG-R模型选最多2区。特征rank除7，跨度取实际最后候选；少于2区不补位。其余完全沿E188 BLOCK-R2048：每区1024码/48候选。该模型迁移到稀疏候选rank，可能失配，不能视为返回等价优化。
- REUSE-BLOCK（主候选）：三个入口的块表并集（最多24）加主返回中计数最高8块，去重后最多32块。用原metric给PQ重构块中心评分，按距离/块ID排序，跳过超出剩余预算的整块，访问最多2048码；全局PQ短名单96，原R排除，原metric精算及严格合并。
- MAIN-BLOCK：只取上述主返回最高8块，其余与REUSE-BLOCK一致。它是信息来源对照，实际上最多1024码；相同上限不等于相同实际工作。
- GT10、旧16K B32、原E188 BLOCK-R2048在同一二进制/窗口重测。旧B32保留正式参考，因末4K用于其训练，不进入本轮校准矩阵，不参与自动选择。

本轮不另加扫描内核优化、门控、重训旧ridge、PQ/块/图变化、完整搜索状态缓存。R分数复用沿旧实现。新方案的主搜索、查表/统计/去重/评分、PQ LUT/扫描/筛选/精算/合并与输出生命周期全部付费。

## 固定范围与角色

COCO raw-IP、Deep10M squared-L2；原base/图/GT10/metric不变，真实K100。补全L=[100,200,400]；GT10控制L=[100,104,112,128,160,200,208,216,224,240,256,288,320,400,416,432,448,480,512,640]。正式每集35点，共70点/210轮，原公共10K。校准原末4K，同矩阵但去掉B32，每集32点，共64点/192轮。全部矩阵提前固定；不因校准好坏取消正式或调整参数，不做数据集/L配置选择。

新表12K fit，末4K无新增拟合；历史GT10可能使用这些合法fit查询，故不是整个系统的全新held-out。正式test历史曝光，不能声称盲确认。仅两集K100，无其他五集/K1的新证据。原16K完整遗漏并集用于“旧来源外”审计，不能与新12K训练源混称。

CPU15，实际threads=1，OMP/BLAS/MKL/NUMEXPR=1，性能期禁止并发训练/编译/数值分析/其他benchmark。每点warm256、三轮，按L序号及轮数旋转方法顺序。统一Batch正常分配初始化、路由/主搜/补全、六数组复制与销毁的完整wall；加载/GT评价/hash/写盘/oracle另记。计数在wall内，正常路径无阶段计时器。

每点保存首轮实际包，另外两轮逐字/SHA一致；同L真实GT10包重建全排序PQ与合并oracle；旧GT10/B32/BLOCK-R2048前缀与正式包核对。新池/块路由的第二实现抽检、所有ID/score/预算核验。计新增/损伤成员、改善/完整恢复、原Recall<10%的0–9命中失败/改善/脱离、新失败及旧来源外实际救回。bootstrap5000仅描述查询差值，三轮不是三个独立质量样本。

冻结协议/实现/二进制/配置/模型/编译依赖/小输入SHA；大base/图继承E188来源并核stat。只新增ID→block映射和小表，旧块/PQ不复制；新增产物目标<1.2GiB，剩余磁盘至少0.8GiB。旧E188科学目录全seal前后核验；根文档更新前备份，旧根SHA保持当时身份。

## 判定与收口

同时报告相同L、实际离散同Recall阈值、同完整wall预算和Pareto覆盖；不把少扫码、少代表评分或来源外救回当可靠线上优势。探索筛选：实测达到候选Recall的最快GT10参照上速度至少+2%且三轮同向，或候选费用内最佳GT10之上Recall至少+0.05pp。离散网格与多比较限制明确，不据单点自动替换。
