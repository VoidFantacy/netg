# E227 B32 截止分双塔

COCO hard 和 WebVid soft-t1 真 K100。原版 GT10、三路 B32 表、去重、主返回排除、SPAN4 主搜索和四路原生精算合并均沿 E226。学习版只在原版 B32 候选池内选点。

查询和候选分别用独立、可学习的 512→16 线性塔。用真实原内积分数回归，重点惩罚对实际 B32 通过并补回的真值成员低估。以主搜索第 100 名的原内积分数作截止线，候选粗分低于截止线减安全余量时跳过，否则保留原顺序原生精算。精算数由查询与候选共同决定。一条查询筛剩不到 min(16, 原候选数) 时恢复整池。采用转置权重融合 SIMD 投影，B32 posting 预绑定紧凑码槽，在一趟阈值选择中压紧候选数组。原分及合并保持 native。

训练和校准复用 E222 第二公共窗上 E226 已冻结的身份划分和真 K100 主返回、B32 原结果，覆盖 L176/184/200/224。第三公共窗之前用于部分历史实验，以 6144–9215 的 3,072 条为本轮正式留出。COCO 核验源身份，WebVid 核验精确 query 字节，拟合/校准去掉与第三窗重合的记录。模型训练后在校准窗选择一个全 L 共用的余量，从 0 到 0.240 每 0.002 一档，选真实 B32 正确成员总损失不超过 0.03 个 Recall@100 百分点时精算量最小的余量。无可行项时用原版整池回退，并完整报告。低召回及实际精算量逐 L 保存。正式 GT 在两集所有计时结束之后评分。

正式网格 L176/184/188/192/196/200/208/224/232/236/244，每集 22 点、44 批，合计 44 点、88 批。CPU15 实际单线程，每点两遍，交替首臂，次遍逆序。完整 wall 包含路由、主搜索、双塔、精算、合并和批生命周期。加载、预热、输出散列、写盘、GT 评分、分段探针都在 wall 外。资格取每档前 256 条，再跑标量全排序、同池和精算量见证。分段值取资格回放，含逐查询打点，不作端到端 QPS。两张曲线只画原版 GT10+B32 和本轮新版。两集报告原版本基线是否逐字匹配可用历史对照；其余按同期比较。
