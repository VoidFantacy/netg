# E105 解释与证据范围

此文件在完整性能结果评分之前记录解释边界，不包含预判结论。

- 唯一候选是E104已保存的WFree模型、小图和单位化query路由路径。Web对照原GT10-soft-t1，Yandex对照原GT10-hard。两份WFree原小图seed为20260920，GT10加载历史原图；没有为本轮重新构图、改变ef或训练。比较的是两条完整冻结流程，不能将差异单独归因于W方向、W范数或图拓扑。
- query在两套原始learn/train源的预锁窗口内依源序选取，并与已登记的aco/router/validation/public四分区逐行去重。来源行及字节互斥可核验；这不是全原始源随机抽样，也不证明无语义重复、无序列相关性或所有未登记历史使用均已排除。结论适用于该复验窗口，不能直接替代公开测试或新数据集结果。
- 模型与协议在新query载荷访问前封存，query在GT生成和新模型输出前封存。GT只用于评价，不以新query的难度、GT或方法收益筛选样本；候选不足时按原协议停止。
- 新GT由当前Python环境Faiss 1.15.0的IndexFlatIP在原完整base上计算；在线搜索仍链接项目原静态库，共享原E103 span+batch4。GT版本单独记录；16条独立float64全库top100集合全部一致，原NSG内嵌base与GT base另做16个位置字节核对。抽样核验不是全部base向量逐字比较，但两份base完整SHA已对照原manifest。
- WFree按E104保留query单位化用于路由，原raw query进NSG；归一化、路由和输出全部计入在线wall。GT10对照保留原raw-query路由。历史parity以E104原Identity单位化路径验证，不将其冒充新正式raw-query对照；正式配置明确normalize_anchor=false。
- Recall每query按真实返回K与exact GT K集合交集评分。时间重复不增加独立query样本，多个L/重复召回门槛也不算独立胜场。配对bootstrap区间是对本样本的近似不确定性描述；98.75%逐项区间用于四主指标的Bonferroni控制，不作为普遍有效或严格理论保证。
- 90/95/99%门槛选择的是最快达到目标的实测预算；两方法实际召回可不同，不能称恰好相同召回或通过插值得到连续前沿。完整曲线与预算/L、实际Recall、三轮QPS范围一起报告。
- 本次只回答冻结WFree能否稳定超越现有GT10；没有新增GATE、NSG单入口、完整HNSW的重测，不能扩成全基线第一。通过只获得机制研究资格；不通过停止本候选，不证明全部离线学习不可能。
- 新增训练/小图或底图构建均为零；新query获取、精确GT、编译/恢复、完整搜索、分析耗时分别列出。E104训练/56集合监督及原GT10/base/图的继承成本保持原报告身份，不能因为本轮不重做就当成从零成本为零。
