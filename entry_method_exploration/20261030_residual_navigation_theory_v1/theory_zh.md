# 残差补全的适用边界与补点导航价值

2026-10-30。`THEORY_ONLY_UNIMPLEMENTED_UNTESTED`。本文整理本轮文献分析和用户提出的“补点是否不适合作为入口、是否需要处理连通度或密度”问题。已测事实、直接数学推导、论文结论、尚未验证的解释与后继提案分别标注。没有新增训练、构图、ANN、GT、计时或PDF，未改默认；不分配E195或恢复旧实验。

## 1. 当前判断与实现事实

当前证据支持条件性的补全价值，尚不足以支持把持续扩大后置残差补全作为通用主路线。保留B32为强参照，保留M5/SQ各自历史有效场景；后继研究先解释有限预算图搜索的遗漏，再判断导航代表、路径修复或主搜索评分是否更有价值。此判断不撤销E173/E191/E194的实测正面结果，也不把E193有限门控结果外推成所有补全无效。

**已实现：** GT10画像路由到三个真实base ID，运行原NSG；B32在主搜索结束后取三个路由行，去重前至多96个ID，排除主返回与重复，按原metric精确评分、严格合并Top-K。它不将补点作为入口续搜，不改变原visited/展开/停止。

B32用合法16K训练query、K100/L200教师遗漏生成query–GT成员token；编译考虑三个路由行的联合边际覆盖，B8→16→32保留前缀。不能把它描述成简单的逐行高频Top32。K1/其他L共用该表是固定配置，不是已证明对所有K/L最优。

REUSE-SQ通过hub-block表和主返回的块分布提出候选，最多扫描2048码、最多96追加精算。它已使用主返回R；E193已预测补全收益/费用。重新提出“用R”“预测收益/费用”不构成新的机制。查询相关密度、连通性感知seed选择、残差点到导航代表的映射和按导航价值选择入口均未在本次实现。

现有search_new最多消费前三个入口位置；SearchTrace/retset/visited不是完整可恢复搜索状态。本文中的状态注入、共享评分缓存或续搜均只是理论接口需求，不能把96个补点直接作为现接口支持的新入口集合。当前实现合同见[spec](../../spec.md)。

## 2. 固定ID补全的覆盖上限

**本项目机制的直接推导，不是新测量。** 记真实遗漏集合为M(q)=GT_K(q)\R(q)，路由信息为Z=z，p_x(z)=P(x∈M(q)|Z=z)。任何只根据z选择至多b个固定ID的表T(z)，都有：

```math
E[|M(q) ∩ T(z)| | Z=z]
= Σ_{x∈T(z)} p_x(z)
≤ Σ_{j=1}^{b} p_(j)(z).
```

右侧假定知道真实条件概率并能自由选取最高b项，忽略共享行约束、训练误差和执行费用，是乐观覆盖上限；不是当前greedy达到该值的保证。涉及训练迁移时还需要分布稳定性等假设。

同路由下遗漏若分散到许多不同ID，小固定表就受限。更细条件可能集中遗漏质量，也可能使有限训练支持更稀疏。扩大模型或表并不自动解决这一取舍。候选选择的多标签分类视角已有[论文1](#参考论文)，其一致性条件不能直接套到固定容量的三hub表上；本文也不为嵌套B32编译器补写未经证明的1−1/e或1/2保证。

该上限只针对固定ID候选。区域/块能覆盖旧残差源外的ID；图入口作用于有限搜索轨迹，不能一概套用固定ID复现条件。已有集合支持结论见[E192](../../experiment_history/192_sharing_necessity_v1.md)。

## 4. 答案价值和入口价值需要分别建模

**机制区别：** 一个点r是正确答案，意味着它按原任务metric应进入Top-K；r适合作为入口，则要求它在有限预算下引出更多尚未覆盖的目标。两种价值没有一般等价关系。直接补点阶段无需通过连通度或密度资格筛选；入口分支需要另行评价导航价值。

| 属性 | 可以支持的解释 | 不能据此认定的结论 |
| --- | --- | --- |
| 入度低 | 可能难从其他节点进入 | 主动跳到该点后一定不好用 |
| 有效出边少/方向单一 | 可能难以从该点到达其他有用区域 | 原始出度小就一定没有价值 |
| 局部密度低 | 可能是孤立正确目标，缺少后续扩展收益 | 应删除这个补回目标 |
| 局部密度高 | 可能有更多邻近候选 | 候选一定相关、未覆盖且值得扫描 |
| 图全局连通 | 存在路径或从某个起点可达 | 有向图各点互达，或有限beam一定能走通 |

**尚未验证的假设：** 残差收集可能富集难以到达的节点，但“难以进入”和“进入后难以继续”不同。前者可能恰好适合主动跳入，后者需要直接补答案或修复局部连接。当前没有新统计证明补点整体更稀疏、入度更低、出边更差，也没有证据确认它们是E174或SQ费用结果的主因。

静态度数/密度只作辅助。应考察有向出边的有效性、有限步/预算覆盖、邻接方向多样性、不同seed间的覆盖重叠，以及与原搜索已覆盖区域的重叠；区分已见、已评分和已展开，不能把visited简单当作已充分搜索。raw-IP下不能未经说明用归一化余弦密度替换原任务排序；新诊断量需要固定定义与来源。

## 5. 路径障碍视角及适用边界

**论文结论：** RoarGraph在其跨模态数据上观察到同一查询的真实近邻彼此可能相距很远，并用查询引导的图投影建立路径。这是论文所测工作负载的现象，不是所有ACSG数据上的既定事实。[论文2](#参考论文)

NGFix定义Escape Hardness：

```math
EH_q(u,v)=min_{p:u→v} max_{x∈p} rank_q(x).
```

直观上，它描述从u到v的路径至少要经过排名多差的中间点；其搜索容量保证依赖论文所规定的算法。它是分析路径障碍的依据，不能未经队列/淘汰/visited/并列/多入口原生绑定就当作本项目有限L定理，也不是可以免费在线读取的特征。[论文3](#参考论文)

应区分入口未到目标附近、到附近后目标之间缺少预算内路径、评分/候选竞争造成提前停止。现有GT10改善入口，不自动修复后两类。新增边可能帮助端点以外的目标，也可能增加扫描并伤害其他查询，迁移与净收益都尚未证明。RoarGraph/NGFix已经覆盖查询引导图修复的大方向，不能直接声称本提案具有新颖性。

## 6. 先保留答案，再研究导航代表

**尚未实现的设计：** 直接补点集合C保留独立的原metric评分与合并资格；另构造很小的导航候选集合H。对每个残差相关区域，可以由r自己或其他真实base节点h承担导航，不能仅按密度剔除r。

选择h应考虑从h出发的有向路径和其他遗漏区域，不能只找离r近或度数大的节点。存在h→r、r→h或几何近邻是三种不同关系；即使h能到r，也不证明h能带来更多目标。若多个h都指向同一片已覆盖区域，应计冗余，不能把单seed收益相加冒充联合搜索。

给定可实现的搜索状态σ和剩余工作预算b，可用以下离线目标评价：

```math
U_b(h | q,σ)
= E[|GT_K(q) ∩ R_b(σ⊕h)| − |GT_K(q) ∩ R_b(σ)|].
```

σ⊕h表示待设计的合法注入/独立扩展动作，不代表现有API。比较保留相同剩余工作预算、原metric与明确的队列语义；GT只用于离线评价。U允许为负，因为新增入口可挤占原beam或预算。相同工作预算仍不保证相同wall，因此完整Recall–QPS另行验证，选择开销也必须支付。保留C支持不保证最终返回为旧Top-K ID超集，实际成员损伤/近并列仍需报告。

若将来研究在线选择，优先评估预计算静态摘要与低成本查询条件，记录实际选择费用；为筛入口在线做大量BFS或完整邻域打分，可能先花掉预期收益。当前尚无可部署的U估计器或已验证代表映射。

## 7. 既有一跳实验不能换名重启

**E174事实：** 原M5完整C≤24保留，每路由行选择query-best且不在主返回R的seed，至多3个；沿原NSG按物理槽轮转，一跳生成额外24/96个精算候选，过滤main visited/C/重复。它不是暂停恢复或完整多步续搜。主候选相对原M5的16个同L点中，14点Recall升、2点平，完整配对QPS中位数全下降0.13%–0.70%；未形成其协议要求的两角色较强局部双升。E175扩展五L仍是原冻结机制，不将原M5已有跨L优势计成区域新贡献。

来源：[E174卡片](../../experiment_history/174_m5_residual_regions.md)、[原协议](../20261010_m5_residual_regions_v1/protocol.md)、[实际报告](../20261010_m5_residual_regions_v1/analysis/final_v1/report.md)、[E175卡片](../../experiment_history/175_m5_region_budget_curve_v1.md)。

E174没有隔离比较连通性感知入口、密度筛选、区域代表或多步状态复用。因此它既不能确认“补点不适合导航”的因果解释，也不能证明新筛选一定有效。后继若实施，必须说明与原距离选seed/一跳机制的差别，并另冻协议；本次不启动。

## 8. 主搜索内评分是另一条机制，不与入口筛选混为一谈

**直接推导：** raw-IP重构误差e=x−x_hat导致分数误差qᵀe，固定e下有E_q[(qᵀe)²]=eᵀE[qqᵀ]e。E[qqᵀ]为二阶矩，不泛称中心化协方差。普通向量重构MSE不一定对齐查询分数误差；该式也不直接保证Top-K决策正确，相关候选/阈值附近还需单独考虑。

各向异性量化和LeanVec-OOD提供查询相关表示的参照。可以研究在原主搜索必经访问上使用更便宜的评分，把省下的预算用于探索；需要支付查询变换、编码元数据、精排及误差造成的轨迹变化，不能把论文加速倍数移植为本项目预期。[论文4–5](#参考论文)

另一种思路是围绕当前入选阈值τ使用可靠距离下界：仅当下界>τ时排除候选，其余精算。RaBitQ以误差界决定重排，但只对已探测候选提供相应高概率保护，不能弥补未访问源，也不是确定性的原生浮点保证；多次/自适应比较的风险、raw-IP范数及原比较语义需另绑定。[论文6](#参考论文)

本方向与旧M2及已有FINGER/PAG等工作存在重合；本文不声称新颖性，也没有实现新的评分器。[旧理论总报告](../20261002_overnight_algorithm_audit_v1/combined_report.md)、[论文7–8](#参考论文)。更复杂的补全门控暂不优先：E193已预测收益/费用，后继需说明信息或动作本身的实质改进；预测难度不等于预测动作价值。

## 9. 后继研究顺序、反证与接续

以下仅定义研究问题，具体样本、预算、训练/校准/确认角色和运行边界尚未冻结，没有自动执行授权。

1. **优先区分答案与导航价值。** 设计或只读核对补点本身命中、有限预算扩展新增/损失目标、入/出方向、覆盖重叠与成本的口径。距离选seed为历史对照，度数/密度只是特征基线。需要对照直接补C、原距离选seed、导航筛选/代表，在同源候选与明确预算下隔离差别，另与更大L GT10/强B32比完整费用。若静态统计与导航增量不稳定相关，不能继续把度数/密度当主要解释；oracle只给诊断机会，不作为可部署收益。
2. **有路径障碍依据后再评估稀疏修复。** 研究受出度预算约束的查询引导连接，分别报告到达与继续扩展。若新增扫描抵消路径缩短，或只对训练目标有效，则收窄或停止具体方案。改变图后必须按spec重绑依赖，不能复用不兼容的残差教师/响应/费用。将来实现需与RoarGraph/NGFix等机制区分；不自动恢复旧runner。
3. **主搜索评分作为另一机制候选。** 先核可节省动作与实际成本，再研究查询相关压缩/阈值判断；若变换、guard、精排和误差扩张成本抵消节省，则不以码长/MSE/NDC宣称净收益。旧M2优先级只保留历史身份，本次没有恢复其执行队列。

B32及两集K100/L100 OPT-B32小幅等价省费配置继续保留原E194证据；SQ少量有效区间仍须与更紧B32控制比较。它们是强基线与具体工程候选，本次理论整理不替换默认。任何将来正式测试仍限真实K1/K100、单方法串行T1、完整wall、成员救损和必要稳定性核验；已曝光窗口不得重称盲确认，不能追加测试到通过。

可复制接续：请从LOCAL_CODEX_START和四根文档读取E194完成状态，再读本理论文稿。当前任务是理论同步已完成，无待恢复矩阵；先明确补点答案价值与有限预算导航价值的区别。低密度/低连通度原因尚未确认；E174已测距离选seed的一跳版本，不能换名重启。保留原M5/B32/SQ正面证据。按新用户指令继续，未明确要求执行时不要训练、构图、ANN、生成GT、扩大矩阵、改默认或生成PDF。
