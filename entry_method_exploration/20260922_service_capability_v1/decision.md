# E119 最终判断

2026-09-22：`STOP_CAPABILITY_PILOT`。预定缓存检验与审计完成，没有新方法达到进入原生性能阶段的条件；默认 WebVid `GT10-soft-t1`、Yandex `GT10-hard` 和生产 E99 不变。没有新增 QPS 结果。

## 本轮实际推进

建立了四步研究链：事后最优动作存在空间，不等于该空间可由廉价信息识别；可识别不等于有限样本上能迁移；能迁移仍须支付完整在线成本。条件均值、廉价策略类误差分解、两倍一致评分误差的决策遗憾界，以及平均 MSE 很小但选错动作的反例见 [理论边界](theory_bounds.md)。这些是标准工具，不冒称新定理。固定确定性搜索的全原始 query 未必有不可消除的信息噪声，不能由小模型失败推导出信息论不可能。

查阅并区分了 UniRoute 的响应表示、decision-focused ranking 的决策目标、DCNv2 的显式交互、作者 TabM 强控制，以及 ALORS/双线性算法选择的直接前作。能力画像、排序损失、非线性评分或计入推理成本本身均不是新颖性；本次是具体的 ANN 假设检验，不是这些论文的完整复现。来源与差异见 [研究合同](research.md)、[算法选择前作补充](prior_work_addendum.md)。

## 实测结论

每集 4096 条历史开发 query，四折 query-out；每折 support/fit/monitor/outer 为 1024/1792/256/1024。只复用 E118 全 H 的真实 K1/K100、L128 响应，候选包含原 GT10 动态三入口和 H 个单入口。下表是相对原 GT10 的 Recall 百分点差，不是相对百分比。

| 方法 | Web R1 / R100 | Yandex R1 / R100 | 两集净收益门 |
|---|---:|---:|---|
| GeomMSE | -1.0742 / -0.4331 | +0.0244 / -0.0542 | 未通过 |
| CapMSE | -1.7822 / -0.4355 | -0.3662 / -0.1611 | 未通过 |
| GeomRank | -1.7334 / -0.7314 | -0.5859 / -0.3274 | 未通过 |
| CapRank | -1.8555 / -0.8367 | -0.0488 / -0.3501 | 未通过 |
| GBDT | -0.0488 / -0.1631 | +0.0488 / +0.0183 | 未通过 |
| TabM | -0.2441 / -0.0151 | -0.1709 / -0.0305 | 未通过 |

净效用 `U = ΔRecall - 0.1 × 归一化搜索时间差`，两 K 等权。全部六配置在两集的 query-out U 均为负。GBDT 的 Yandex 两个 Recall 均值略正，但缓存搜索时间增加约 2.789% / 1.585%，尚未计算新评分器与路由开销；不能转换为 QPS 或部署提升。

能力表示的 H1 双集门未通过，相对 E118 加性参考的 H2 均值门也未通过。CapRank 相对 GeomRank 在 Yandex 有局部改善，Web 却更差，不能挑一集称能力表示有效。MSE 版本的能力坐标在两集都未改善整体决策。BestFixed 的每折两 K 均选择默认；ClusterMean 也未建立净收益。

GBDT / TabM 的拟合净效用 U×100 为 Web +2.2392 / +2.4314，Yandex +2.0720 / +2.1452；查询外分别为 Web -0.2496 / -0.2981，Yandex -0.1851 / -0.2609。说明本版强控制能获得拟合内动作收益，但没有迁移。它不能唯一归因于噪声、样本量、表征或优化，也不是所有 GBDT/TabM 配置的能力上界。

例如 Web CapMSE 的 K1 救回 46 条、损伤 119 条；TabM 为 40 / 50。不是只因区间跨零而停止，实际点估计和选择损伤也不支持推进。完整折别、描述性区间、切换数量与拟合曲线见 [完整报告](report.md) 和 [全部统计](analysis/results.json)。

## 审计与成本

训练 87.98 分钟、峰值 RSS 20.009 GiB，离线数值库最多 8 线程，不能当单线程查询测速。0 新搜索、GT、图、K10、正式 wall 或新鲜测试载荷。继承的 E118 标签获取本身花费 4.776 小时、46,964,928 次搜索，不把监督成本算成免费。

预检验证所有旧 top1 对 GT1、K100 mask 计数、query 角色互斥、外折响应替换不影响表示、默认与同分规则、梯度及标量前向。另对 Web 26112 / Yandex 26304 份已保存全 H 抽样 K100 返回，以及各集全部 4096 默认返回，重新按 GT100 核对完整 mask。

独立数值实现重新构造能力统计，验证全部已保存外折动作与收益，检查 32 个主模型的抽样双精度前向及完整监控检查点，并重载全部 GBDT / TabM 模型抽查输出。920 个继承文件与冻结训练源码身份保持。这里的“独立”是同会话的独立实现，不是另一位人工或代理的评审。两 base 全 SHA 已核对；图仅核对继承 stat，没有重新声称做全图 SHA。

预检中多线程聚类逐位不确定性在任何拟合前修正为单线程；来源审查的 metadata 字段遍历修正也已保存初版。均未因外折结果调整参数或门槛。正式统计/审计首次运行成功。

## 停止与后继边界

本版停止，不训练更多 seed/depth/cluster/lambda，不调阈值，也不为挽救结果读取新测试集。原生移植、新源样本量锁定和完整单线程曲线是条件分支，当前未触发，不是假装已完成的性能验证。

后继不能只是换一个更大打分器。若继续同一入口范围，必须先提出实质新、在线可用的信息或可验证的结构条件，并说明为何能缓解已观测的 query-out 选择误差，给出同监督简单对照与事先反驳条件；否则停止这一分支。当前缓存不支持宣布“更多数据必然解决”或“所有入口学习都不可能”，也没有自动启动下一版。
