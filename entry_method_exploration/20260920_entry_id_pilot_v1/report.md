# E116：固定GT10路由的H外入口绑定试验

2026-09-20。**STOP_ENTRY_ID_PILOT：未获得可确认的默认替换。** 用户“测试一下看看”授权的双数据集有界试验已完成。四项主召回差的98.75%配对bootstrap区间均跨0，质量点估计和完整QPS也未全部不降，因此不进入条件五预算扩测，不追加候选/阈值/seed或重训。默认Web GT10-soft-t1、Yandex GT10-hard与生产E99保持。

## 1. 实际测试对象

原画像P、序列化Micro-HNSW、ef10、raw query评分和小图label全部保持，只有外部真实入口绑定表变化。主NSG、距离函数、候选池L、展开和停止规则未改。每个模型替换16个槽位为互异H外节点，仍把升序三个真实ID交给同一冻结主搜索；不是三个独立搜索结果合并。

已有E24 fit20K按固定源位置分成10K提议与10K选择，未发现字节重复。每槽以提议GT100加权频率和单位query均值raw-IP各提出4个候选，排除旧H。仅按真实三入口联合搜索测收益。选择10K再按源行奇偶分两半，要求每半至少8条受影响查询，两个K均不损伤且等权净增量为正。Cost还要求两半平均配对搜索时间均不增加；RecallControl不加该时间条件。按两半较小的条件平均召回净增量排序，最多16编辑；该排序是固定启发式，不宣称全局最优或按总体受影响概率最优。

## 4. 验证与成本

- 标签：Web 242,408、Y 246,072个真实查询—动作；两次plain与一次count全量返回ID/距离bits一致。合计1,465,568次搜索含原内核/K1校验。
- 训练K1标签从K100首返回复用，仅基于固定L时K只影响输出循环的源码契约；每集32个真实动作另调用K1和链接E99核验ID/距离bits/NDC。最终审计K1、K100分别实际运行及计时。
- 两集默认审计的全部返回ID、距离bits、入口和路由/主搜索NDC逐字恢复E105；新模型每点另16条链接E99 smoke。12个点、36轮wall，完整预热/plain/count一致。
- 独立核验保存的真实ID到GT评分、所有单编辑入口关系、最终组合绑定、未改入口查询结果、选中动作的两折门、源/候选/模型hash和数据角色无重叠。原画像与小图hash、生产源码与kernel副本身份核验通过。
- 总计1,711,520次真实主搜索，另80,000次路由准备调用；主搜索流程还含20,000次标注路由及245,760次审计路由，总路由345,760次。离散选择产生4份绑定表，0新画像/梯度训练、0新图、0新GT。
- 控制器含准备/路由/标注/选择/审计/分析共484.627秒（8.08分钟）；编译另列两次。观测最大RSS 10.086 GiB，资源守护无违规。不是只报告训练器时间或把离线标签吞吐当QPS。

## 5. 本次结论与限制

该版本提出的H外入口在训练两半满足局部条件，但冻结组合在当前独立角色审计上仍出现救回/损伤抵消，未建立正的净增量。结果没有解决跨query迁移问题，也未显示成本约束带来稳定QPS收益。不能据此证明全部H外入口无效，不能将负结果单独归因为候选不足、路由不可预测或组合冲突；本试验没有分离这些原因。

停止范围是本协议的4+4提议、两折单编辑筛选与最多16绑定组合版本。不追加配置、不改默认、不把这批已曝光审计查询选子集继续训练。L128主门失败，条件完整五预算比较未启动；当前证据不是完整Recall–QPS前沿结论。
