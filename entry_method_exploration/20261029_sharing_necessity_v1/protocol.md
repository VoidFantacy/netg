# E192：邻域共享的必要条件、上界与重配对照

2026-10-29。用户在E191完成后要求“想办法证明一下吧”，指相似查询不共享邻域时方法是否无用。本轮同时检验支持证据和反例，不把待证判断预设为结论。

## 命题与可证明范围

设原实际Top-K为R(q)，严格GT_K为G(q)，遗漏M(q)=G(q)\R(q)。若补全实际只能从候选集合C(q)加入ID，最终输出F(q)包含于R(q)∪C(q)，则

`|G∩F|−|G∩R| ≤ |M∩C|`。

因此C与遗漏交集为零时净召回增量≤0；若合并保住原命中则等于0。固定ID表的C包含于训练残差ID并集S，因此`平均ΔRecall ≤ Σ|M∩S|/(nK)`。这是候选集合的必要条件，不是“最近训练query与test没有共同GT就所有方法无效”的定理。块方法的C可以超出S；将给出可执行的数学反例和实际旧源外救回证据。

## 冻结实验

1. 七集原E191测试，真实K1/K100、L200实际返回，全部query。32次PCG64重配，seed=20261029+j，j=0..31；按每行非负块数分组，在组内随机置换整行hub→block表。全局表行/块频次及每个hub行长度不变，主返回块不变。可能偶然保持原行，照实计数，不强行命名为零共享。仅报告候选池覆盖上界，非在线Recall/QPS。重配0预先指定进入正式测量，不挑最好/最坏重配。
2. COCO、Deep10M、SIFT10M，固定K100/L200六方法同窗口：GT10、旧B32、REUSE-PQ、REUSE-SQ、SHUFFLE-SQ、MAIN-SQ。SHUFFLE-SQ只将训练块表换为重配0，正常和打乱版本其他数组、块排序、SQ评分、2048扫码/96精算上限、主返回完全相同；实际去重、块数、扫描数可能变化，属于干预后的中间量，分别报告。MAIN-SQ不作纯共享因果对照。
3. 同窗口GT10 L=[160,200,216,232,256,288,320,400]。每集13点/39轮，三集39点/117轮。仅此固定矩阵，无读结果后加点/重配/调参。全部CPU15/实际T1，各数值库1线程，warm256，三轮轮转，原完整Batch生命周期计时；保留首轮真实timed包，后两轮bits/SHA与全量补全oracle核对。无性能与数值分析/训练/编译重叠。
4. 正式前每集128query、真实K1/L32和K100/L200的六方法资格；36点单轮另计。原五方法与E191对应实际包前缀必须逐字节一致。新原生源码为E191局部拷贝，只新增第二张小块表及选择分支；旧源码/库/图/base/metric/监督不改。

另将E185已固定的每集512条最近合法训练query诊断按原query ID对齐：最近query GT重合=0/正、其遗漏覆盖=0/正分别分层，报告本轮固定补全救损。只作事后描述，不把零重合样本改称整个训练集/所有邻近query都零共享，不提供分层线上QPS。

## 判断与证据边界

重配对照检验在固定系统中“hub与已训练块表的对应关系”对质量的贡献；它不改变整个数据集的几何、GT重合或监督身份，不能被说成构造了完全不共享的数据集。32次重配用于描述稳定性，不声称独立query样本或无条件因果推断。在线只测预定重配0，完整费用与同窗口更大L GT10一起报告。

严格上界由集合包含关系证明，并在七集实际包逐query核验。源外救回、ID共享、块共享、最近query的GT重合分开；不以直接删除GT目标后“救不回”充当发现。若命题被反例否定，明确否定其普遍形式，给出成立所需条件。
