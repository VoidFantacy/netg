# 从完整时间成本推导改动，并核对历史重复

2026-09-20。状态：THEORY_REVIEW_ONLY_UNRUN_NO_METHOD_GO。

本轮只读当前交接、源码、历史协议/结果和一手文献，完成理论推导及候选排除。没有新标签、训练、量化编码、ANN、NSG、GT、构图、合成搜索、编译或性能评测；没有安装工具或改变默认。前一版完整动作岭回归提案的降级保持。

## 1. 先确定什么问题值得改

目标是相同质量下缩短完整查询时间，或相同时间下提高质量。单线程串行下 QPS=N/T_batch，不能平均逐 query 的 1/t 代替。K1、K100 分别定义目标与真实返回；不存在一个混合 reward 变正就自动证明两指标分别改善的结论。

旧入口方法的困难至少有三项：真实组合效用与简单几何目标不一致；fit 动作收益不能稳定迁移；新路由成本可能吃掉收益。E104 的训练 C8 最优集合拟合、E105 的独立复验以及 E85 的固定岭回归均已覆盖相应失败。仅更换模型、动作数量、残差写法或加 NDC 惩罚，不能成为下一候选的理论理由。

本轮比较两个不同干预对象：A 在一次距离比较内部避免不必要的完整内积；B 在同一次搜索轨迹上选择何时停止。它们都是搜索执行层的改动，不是新的 GT10 入口学习方法。

历史 E98/E100 指向主搜索而非路由是时间大头，但采样来自当时 WebVid/K100 工作点；不能把 63.94% 等比例外推为最新 span+batch4、所有数据集和预算的当前占比。

## 2. 主候选 A：带确定上界的 raw-IP 拒绝筛选

### 2.1 源码中的干预点

当前 [ACSG.cpp](../../ACSG/ACSG.cpp) 的 search_new 邻居循环先标记 visited，再调用完整 `dis(id)`，池满时用 `dist >= retset[L-1].distance` 拒绝。IP 由 NegativeDistanceComputer 转成越小越好的负内积。最终评测用的 [span+batch4 ResearchKernel](../20260916_faiss_nsg_comparison_v1/src/kernels.hpp) 仍执行完整距离后按原顺序插入/拒绝。

对于一个最终必被该比较拒绝的点，算法只需要知道“不可能过阈值”，不一定需要其完整内积数值。这里目标是省掉这笔计算与访存，不改变入口、图、候选池 L、访问规则或保留候选的真实分数。

### 2.2 一个不依赖 Recall 学习的确定界

为每个原始 base 向量 x 保存一个可廉价计算内积的重构 x_tilde，以及真实重构误差的向上界 e_x：

`e_x >= ||x-x_tilde||_2`。

由 Cauchy–Schwarz，对任意原始查询 q：

`q^T x <= q^T x_tilde + ||q||_2 e_x = U(q,x)`。

这是确定不等式，不要求 query 与训练同分布，不需要 GT，也不把 raw-IP 改成 cosine。PQ 只是一种让 `q^T x_tilde` 可以查表计算的编码选择：原始 x 仍保留；codebook 及真实残差在离线计算。它不是直接用近似分数替换候选池内的排序分数。

令 theta 是池中当前最差保留节点的内积门槛，池未满时禁用筛选。若一个向上取整并含数值误差保护的 U_safe 严格小于 theta，就可以拒绝；否则调用原完整距离内核，再执行原比较和插入。

U_safe 必须覆盖原内积实现相对实数内积的舍入误差、查表求和误差、query 范数误差以及 e_x 存储误差。单纯把普通 float 范数叫上界不成立；NaN、Inf、溢出、未知距离类型、边界不确定均回退完整计算。

还能推导筛选什么时候一定有效。令真实拒绝间隔 `g=theta-q^T x>0`、`epsilon=||q|| e_x`。由同一个双边误差界，`U <= q^T x+2 epsilon`，所以在实数模型下，`g>2 epsilon` 足以保证该点被廉价界筛掉。浮点实现还要加上述数值保护量。整组版本要求组中每个点都满足对应条件。

这说明值得检查的是**拒绝间隔相对重构误差是否足够大**，不能仅看平均量化 MSE 小或原方法拒绝比例高。远离阈值且误差小的点最有希望省算；阈值附近的点保留完整内积。该充分条件对任意 query 成立，但当前没有测过这些间隔/残差比，不能据此报有效筛选比例。

### 2.3 条件性等价证明

固定相同初始状态和原比较规则，按原候选处理顺序归纳：

1. 若筛选拒绝，确定界保证原完整内积比较也拒绝；visited 的更新与原方法相同，队列不变。
2. 若不能证明拒绝，执行原完整内核和原插入；分数及队列更新相同。
3. 因而下一扩展节点、后续候选和最终输出均相同。

该证明的前提是界真正覆盖原浮点比较、未改变 visited/顺序/边界；它给出的是**相对同一原搜索的输出等价**，不声称原 NSG 已经是精确 KNN。成立时，所有 query 的 K1/K100 Recall 和失败数保持，而不只是均值大致不变。

### 2.4 必须对齐最新 batch4，而非退回慢基线

最新研究内核先取原顺序最多四个有效邻居，再 `distances_batch_4`，最后顺序插入。实现不能因为筛选重新打包就假定浮点结果必然相同。

最保守的具体版本：保持原四元分组，使用组开始时的满池阈值，只在整组的每个点都已被证明确认拒绝时跳过该组距离调用；有任意不确定点则原样执行整个 batch4。组开始阈值是安全但较松的阈值，不能反过来用更严格的假想未来阈值拒绝当前候选。此版本的有效率是“整组能跳过的比例”，不是单点拒绝比例。

它可保留原 batch4 浮点内核和分组，但可能明显削弱节省空间。若未来研究部分 lane 筛除，需另行证明并核验该浮点路径，不能自动继承上述保证。预取也须计入：提前读取原向量会减少筛选可能节省的访存；不能既沿用原预取成本又把全部向量读取计为已省掉。

### 2.5 QPS 提高的条件

令 Q 为 lookup/query 准备费用；F 为全部筛选费用；S 为真正省掉的原完整距离及访存费用；H 为额外控制、缓存变化等净开销，则完整时间差为

`T_new - T_old = Q + F + H - S`。

时间改善要求 `E[S] > E[Q+F+H]`。在同质分组成本的简化模型下，设 V 个可筛组、p 比例整组免算、C_exact 为每组完整成本、C_filter 为筛选成本：

`p C_exact > C_filter + (Q+H)/V`。

这只是可检查的收支条件；真实访问、batch4 和缓存成本不均匀，最终必须由完整 wall 判断。没有本项目已测 p、界宽度或速度预测，不报提升百分比。NDC 计数要区分逻辑候选比较、廉价界计算和完整距离调用，不能沿用“全部调用等成本”的解释。

### 2.6 最可能失败的地方和成本

确定界可能太松，尤其高维、低码长或 raw-IP 的向量范数差异大时；整组跳过率可能很低，查表和 cache 成本反而更高。提高码长会增加代码、表和编码成本，不能在失败后自动变成码长网格。

可用分块残差 `sum_b ||q_b|| e_(x,b)` 替代整体残差界，数学上不更松，但额外读取/乘加可能更贵；本轮只分析该取舍，没有将其列为第二个待跑版本。

离线仍需训练/确定编码器、扫描全部 base 生成 codes 和真实残差，另有额外内存、加载和身份绑定成本；不需要 query×入口动作的真实 NSG 标签矩阵。没有测离线时长，不把它说成免费。

## 3. 备选 B：单次搜索中的质量损失与剩余时间选择

### 3.1 最小具体机制

保留 GT10 原路由、原图、raw query。选定一个完整搜索参考配置 B；从开始到结束保持相同候选池容量，不在中途修改 L。只在预先定义的一个完整展开边界作一次决策：立即返回当前 topK，或从原状态继续到自然结束。池中不足 K 个合法节点时不可早停。

这不是先跑小 L、再从头跑大 L，也不增加入口或深克隆搜索状态。拟用少量当前分数间隔、结果更新和进度统计分别预测：

`D(q,s)=R_B(q)-R_s(q)`；`S(q,s)=T_B(q)-T_s(q)`。

前者是现在停下会损失的真实召回，后者是可省的剩余主搜索时间。应使用同一实际轨迹的前缀及完整结果；旧多个 L 的终态不能当作这条轨迹的前缀，因为容量变化会改变候选接受和路径。

拟议选择目标为在总体 Recall 约束下最大化所省完整时间。例如一个固定单检查点策略可比较 `E[S|z]-lambda E[D|z]`，但 lambda 服从质量约束，不能只按标量正值验收。评分器费用对所有到达检查点的 query 收费，提前自然结束者不强行调用。模型家族、检查点和预算尚未锁定，也没有拟合。

当前距离不再改善、结果集合暂时稳定，都不能证明 D=0；E114 错误终点与 E14 旧 trace 失败恰好要求警惕。单步边际收益也不代表所有未来收益，不用一步增益/时间比冒充一般最优停止定理。

### 3.2 为什么它可能同时改善质量和速度，以及必须满足什么

令 b 为当前待比较的基线工作点，B 为预先确定的较充分搜索参考，A 为选择早停的 query 集合，C 为完整控制开销。逐 query 使用相同前缀/参考定义，有恒等式：

`E[R_new-R_b] = E[R_B-R_b] - E[1_A D]`；

`E[T_new-T_b] = E[T_B-T_b] + E[C] - E[1_A S]`。

两个指标分别改善要求：

`E[1_A D] < E[R_B-R_b]`，且 `E[1_A S] > E[T_B-T_b]+E[C]`。

因此收益来自：较充分搜索提供质量余量，在可省时间的 query 上截掉对质量贡献较小的尾段。B 相对 b 是否真有质量余量、尾段是否可预测、节省能否覆盖控制及较充分搜索额外时间，全部未知；较大 L 不能逐 query 当作 Recall 单调定理。

若 B 就是同一基线 b，纯提前停止一般只能保持或损失同一轨迹上的质量，不能声称同 L Recall 提高。严格并列/GT ID 问题必须使用原评分口径保留；如果原浮点与 GT 排序一致且无边界并列，前缀 topK 命中不下降，D 非负；不满足时直接保留真实有符号 D，不伪造单调性。上述恒等式不依赖非负假设。

这两条是收支分解，不是预测器已实现它们的证明。特别是平均 Recall 约束可能牺牲难查询，必须同时报告零命中失败和完整救回/损伤，不能只展示均值。

### 3.3 相对入口学习的结构差别与剩余风险

只选停/继续，继续分支路径固定。一条完整训练轨迹可提供该检查点的质量差，不需要为 56/64/数百个替代入口分别生成响应。轨迹上的多个快照仍只有一条独立 query；插桩时间不能充纯查询 wall，真实时间标签须另核测量扰动。

它不再依赖稀疏入口 ID 的交叉查询监督，但状态统计是否可迁移仍待证。缓存旧终态、固定 checkpoint 的 C2 分支、NDC 标签都不能自动提供完整所需前缀/剩余时间监督。

## 5. 一手前作碰撞：不能把工程适配当新论文方法

- [ADSampling 原文](https://arxiv.org/html/2303.09855v1)：核对 §2 的距离比较、§3.3/§4 的随机误差与插件保证；已有省掉无效完整距离的框架。它的高概率保证不能直接变成当前 raw-IP/浮点实现的确定等价。
- [FINGER 原论文页](https://arxiv.org/abs/2206.11408)：作者摘要已明确用残差角度估计跳过不影响更新的距离；本轮未完成其全部代码复现。A 的大方向已有直接前作。
- [RaBitQ 原文](https://arxiv.org/html/2405.12497v1)：核对 §3.2 的式 14–16，包含随机失败概率；不能把统计置信区间充当确定安全上界。
- [Faiss ProductQuantizer 官方 API](https://faiss.ai/cpp_api/struct/structfaiss_1_1ProductQuantizer.html)：支持 inner-product lookup，训练重构偏向 L2 目标；提供编码计算组件，不替本项目证明筛选有效率或速度。
- [DARTH 原文](https://arxiv.org/html/2505.19001v1)：核对 §2.3/§3，搜索状态预测当前 Recall、控制调用间隔和提前终止已有完整方案；B 不能把停止框架、状态特征或低频预测说成新。
- [LAET 作者仓库](https://github.com/efficient/faiss-learned-termination)：已有学习提前终止实现；本轮读取仓库说明和 DARTH 对其比较，原论文 PDF 工具访问失败，未据此宣称逐式审计 LAET。
- [DARTH+ 作者说明](https://mchatzakis.github.io/declarative-recall/) 已包含质量保证方向；本轮只核对作者说明，不能将“再加校准”当独立新颖性。
- [QBAT 作者机构论文页](https://research.google/pubs/qbat-model-based-query-budget-autotuner-for-clustering-based-approximate-nearest-neighbor-search/) 也已覆盖不同 query 的预算分配目标；其聚类索引结果不是本项目 NSG 的性能预期。

以上属于定向前作核对，不是完整新颖性检索。没有采用网页/论文里的加速倍数作为 ACSG 预期。

## 6. 本轮决定与可证伪边界

优先候选 A，因为它把核心质量问题转成可证明的条件等价，将性能未知项集中到界宽度、可省完整组比例和净 wall。备选 B 有机会重新分配质量/时间，但需要新的状态泛化证据和严格质量控制，不能作为 A 失败后自动排队的下一实验。

若未来另行进入最小验证：A 首先检验确定界/浮点/原 batch4 状态等价及筛选的净成本；B 首先检验真实前缀是否存在满足两条收支式的空间，再判断预测能力。不能一开始生成全量动作标签或跑完整多数据集大矩阵。A 若界松且完整 wall 不降，不靠取消保护/换成概率剪枝把本版说成成功；B 若尾段节省不足或代价不可预测，不扩 checkpoint/模型队列救场。

这两项的定位是提高现有系统 Recall–QPS 的候选机制。A 同预算保 Recall、争取 QPS；节省时间能否用于更高预算提升 Recall，是另一个要实测的工作点。它们都不是已成立的新入口论文贡献。若任务严格限定“原搜索完全不动，只学更好的入口”，当前证据还不足以推荐一个新的学习分支。

本轮止于理论和重复核查。没有待运行的实验或默认替换。
