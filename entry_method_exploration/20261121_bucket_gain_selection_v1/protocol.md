# E218 入口桶净收益选择与双表动作

锁定 COCO K100、WebVid K1 的 E217 BKT8 代表空间，两窗验证和正式计时沿用真实 K。另对 WebVid K100 只测原 BKT8 短名单的双表动作上限。主图/路由/metric 沿 E211/E217。离线计分及合并复用 E216 四路 raw-IP 和严格 Top-K，任何动作逐条使用其 fit-only B32 实际精算数。

## 学习和口径

将 fit 以固定种子按 identity 切为三个近等规模折。每一折只用另两折构建 K100/L200 的 B32、K100/L184 的投票表、BKT8 代表及 16D 候选摘要，对留出折的每个代表动作实际合并。COCO 用 K100、WebVid 用 K1 的原真实 L184 返回；标签为相对该折 B32 的最终 Top-K 净命中，保留原 B32 是零收益。最终评估使用 E217 全 fit 冻结代表、预编表及 fit-B32，摘要投影由全 fit 独立构建。dev/cal 均只用于冻结后的验证。

固定三种 ridge 输入组合。ROUTE 用单位 query–代表余弦、三入口重叠。RETURN 加主返回前 min(8,K) ID 重叠。SUMMARY 另加首 16 个缓存 ID 的原向量均值在 fit-query PCA 前16维的投影，与当前主返回第 K 分数比较。摘要只用于估计动作收益。每个查询总训练权重相同，特征在训练折汇总后标准化，L2 正则 1（加权平方损失和），部署吸收标准化为线性系数。在线逐个算分，严格大于零才替换，平分选择较小代表序号。对照 E217 最近代表、B32-fit、CACHE 和 L192 参考，数值误差核对实际动作与原游标顺序。回放两遍 CPU15/T1，记录完整补点费用，离线标签不计在线。保留各窗救回和损伤。

## WebVid K100 双表

使用全 fit 冻结 BKT8，每查询固定短名单内枚举无序代表对。以余弦较高的代表先取最多8个，次表最多8个，排除主返回、原 B32 及先表已选 ID。维持原始前缀，按实际新 ID 数裁切旧尾，精算数逐条一致。若原尾少于16，第一张至多 ceil(名额/2)，第二张至多 floor(名额/2)。比较同预算单表、单表加双表的精确 oracle 及 L192 参考，两窗单列。用途为离线动作空间诊断。

## 端到端资格

学习动作 dev/cal 均至少达到同池 L192 B32-fit，且均相对 L184 B32-fit 正净增。多臂合格时优先较少特征。合格项用 E217 预先保留的公共 3072–6143 行（零基），CPU15 单线程，L176–256 步长8，每点两遍，含正常批次、统一六数组、入口、搜索和选择器，计时完整结束后读公共 GT。对照 GT10、完整 B32、fit-B32 及 CACHE，按离散达标最快 QPS 比较。此窗与 E216 首窗不重叠，保留其他历史曝光边界。学习阶段达标单元的后续推广结合独立查询和相邻目标上的同期前沿。
