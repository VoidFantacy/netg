# 改进方向：按证据排序，而不是按模型复杂度排序

当前没有获得稳定替换GT10的新方法。以下是研究方向及停止条件；未训练、未导出新策略、未读新鲜测试集，也未改变默认。特别是已停止的GT10画像调参、C8换点RL、WFree、多画像、E117树、E118/E119评分器、TargetKNN不能按新名字重开。

## 第一优先：把GT10本身做成可解释、可复现的强基线与理论结果

**具体问题。** 不再把“整个GT10系统胜NSG”当成“top10标签画像已被证明大幅胜GT1”。把H的选择、画像、路由图、入口数和主搜索内核分开。现有数据足以写出可信的阶段性结论；完整因果份额和跨来源稳健性仍未闭合。

**可交付贡献。** 一个无梯度、静态小索引的query分布压缩方法；一个明确区分代理质量、可达机会、可预测残差和完整成本的评价框架；一组可以推翻直觉的实证——更高覆盖/更准画像排名/更多入口都不保证更高实际Recall。这比宣称“新RL模型又提高0.1pp”更符合当前证据。

**下一份严格设计应回答三件事。** QGT选出的H与同容量不使用GT的H相比是否仍有稳定优势；在相同H上GT1与GT10的差异能否在新查询来源重现；在固定评分及一致层级的控制下，画像诱导的小图节省的邻边扫描能否稳定转成完整时间。每个比较内部保持同一底图/内核/K/L，避免将不同图或实现收益混入画像贡献。

**已有与缺失。** E107/108/115已提供强的同H和小图证据；E27/E106约束了“ESS就是原因”的说法。缺的是新来源下的完整因素核验与GT-inclusive离线成本账。这里不安排一套新的大网格，也不声称现在已经具备论文级新颖性。若GT10对GT1的增益仍不稳定，就把贡献定位在简单强系统与边界，而非强行证明“10”最优。

**理论主线。** 以[theory.md](theory.md)的闭式最优性、方向误差与排名间隔、有限搜索响应、候选/信息/估计三项分解为骨架。真正值得新增的是能事先预测“代理改进是否会越过搜索响应边界”的可检验条件；只重证球面均值最优不足以形成新贡献。

## 第二优先：只保留“原路由状态能否免费提供不同的信息”这一信息假设

记录126提出了上层终点z到四动作表：原top3或其rank-single。它仍是 `HOLD`，没有新增实施GO。本轮同批分解进一步说明，这四动作只覆盖全H oracle增益的21%–32%，所以不应继续把它当作大幅提升的主要承诺。

**若继续入口方法研究，值得讨论的新机制是：用原路由已产生的离散状态，在离线阶段编译一个真实hub ID，允许落在当前top3之外，在线只查表或回退。** 这是一个尚未成立的假设，不能立即宣布比旧方案更好。原图上层状态最多52，理想静态表可很小，但状态导出/分支/cache及不同入口的主搜索代价仍须计费。

它试图同时解决两个已测障碍：候选受限与全H在线评分太贵。与E117的差别在动作可超出原top3、信息是已有路由状态；与E118/E119的差别在查询端不做全H打分，而把选择离线编译。该状态是query与图的确定函数，所谓信息差别是廉价可用的结构摘要，非增加了超越完整query的信息。**这仍有GATE、算法选择和历史查询入口复用的前作，不能把组合本身当新颖性证明。**

**先证伪信息，不先训复杂网络。** 在角色冻结的历史开发query上，用真实路由状态与同预算真实动作标签对齐；比较默认、仅训练侧选出的全局固定动作、按z分组的简单均值表和保持组大小的打乱状态表。所有分组、动作提名及回退选择必须只用训练折；外折只报告，不能挑外折赢家。多K分别评价，不用K100变化替代K1。

这一步若只复用现有L128全H标签，最多证明L128局部信号，不能宣布R90改善；目标预算需另有对齐标签和完整计时。表只有52格意味着平均每格约79条query（4096/52，实际不均匀），但每格从约800个动作择优会产生明显选型偏差；不能因表小就认为统计可靠。不能通过增加格子、换节点/seed或更复杂分类器来回避第一轮失败。

**明确停止预测。** 若外折净成员增益不能超过强固定控制和打乱控制，或者只出现收益次数增加但损伤幅度更大，停止这个信息假设；若目标预算不保留收益，停止迁移；若完整成本吃掉节省，停止部署。数值门、数据角色与预算必须在任何后续实际试验前冻结，不能使用本报告的事后oracle定门后宣称预注册。

**当前缺口。** 没有现成对齐的z、目标工作预算全H响应与完整成本；本轮没有导出这些信息、拟合查表或启动试验。该方向是一个可反驳的研究提案，实施候选数仍为0。若这些缺口不能以合理成本补齐，应选择第一方向收口，而不是跳到MLP/双塔/RL。

## 第三优先：将“入口问题”与“底图/预算问题”分成两条研究线

本轮高预算七策略oracle较小，只能说明现有七种策略互补性不足，不能证明所有H或所有base入口都无效。全H标签目前仅L128；Web R90工作区间远高于此。因此，尚不能凭现有数字宣布“入口已经到天花板，必须改大图”。

若未来目标确实是较大的系统增益，可把“更适合query分布的底图”列为范围扩展方向，先核对RoarGraph、NGFix、CDMG与hubness研究。这里应研究同一查询分布下的可导航性、目标间连通和主搜索工作量，而非继续在固定H画像上扰动。也可以另立自适应预算方向，对照Ada-ef等已有方法；这会改变当前固定L约束，不能计作本轮入口改进。

**范围扩展前的判别。** 先分清目标工作点到底是“有可救回动作但识别不了”，还是“所允许入口族也没有足够空间”。前者优先处理信息/可索引性，后者才为改变图或预算提供直接动机。一次统一设计的诊断比在两条范围混杂的曲线上追小差值更有解释力。

## 目前不建议投入的方向

| 方向 | 不继续的具体理由 |
|---|---|
| 更深MLP、双塔、TabM或更多训练轮 | E119强控制能拟合但未迁移；目前没有新信息/监督桥梁。更多参数不是待解决机制。 |
| 再调GT10温度、GT数量、收缩、画像模态数 | 已停止的固定H画像/图增强分支；“10未被证明最优”不是重新扫描参数的正面依据。 |
| 再做同C8组合RL/直接奖励 | E32/E36已比较真实联合收益及同策略控制，开发/成本限制均存在；需实质不同的信息或动作机制。 |
| 只追更高画像top3精确率、目标覆盖率 | E109及精确排序控制表明，代理最优不等于实际搜索效用最优。 |
| 只优化TargetKNN推理速度 | 当前召回曲线即便在条件零新增费思想实验中，同召回收益也有限；没有新可迁移信息依据，压缩旧模型不足以构成主线。 |
| 宣称更多数据一定解决 | query数量确实有限，但E105已给出独立来源负结果；没有测过足够的学习曲线或统计条件。 |
| 根据平均度继续删小图边 | 省扫描不等于保持有效入口；E115混合候选已失败，路径/层级/评分存在交互。 |

我的排序是：**先完成GT10的机制与边界论证；入口算法只保留一个低成本信息假设；若追求更大收益，再将改图/改预算作为明确的新范围。** 这不是停止整个项目，而是停止用越来越复杂的学生模型反复逼近尚未证明可迁移的残差。
