# GT10的强项、代理断点与可以证明的边界

这是在历史记录100、112及126基础上的整理与补充，不是“GT10全局最优”的证明。所有在线量指固定底图、固定主搜索、固定配置K/L；忽略浮点的命题会明确说明。数值结果来自本轮只读分析，见[主报告](report.md)。

## 1. 构造本身为什么有一个很强的简单解

令x_i为单位化训练query，u_h为单位化真实hub，z_it为训练query第t个GT目标的单位向量。hard版本的权重为

\[
a_{ih}=\frac1{10}\sum_{t=1}^{10}\mathbf1\{h=\arg\max_j z_{it}^{\top}u_j\}.
\]

soft版本把指示函数替换为对所有H的softmax，温度已在旧开发阶段选择。每query的总质量仍为1。代码构造

\[
v_h=u_h+\sum_i a_{ih}x_i,\qquad p_h=\frac{v_h}{\|v_h\|}.
\]

当v_h非零时，由Cauchy–Schwarz，p_h精确最大化单位球上的

\[
J_h(p)=p^{\top}u_h+\sum_i a_{ih}p^{\top}x_i.
\]

因此，在相同权重、单位向量约束和线性亲和目标下，再加梯度优化不会改善最优目标值。它把20K个query的监督压缩到H个静态向量；线上只需原有一次小图检索。这里的“强”首先是目标明确、闭式聚合和推理形式便宜。目标是否足够接近真实搜索效用是另一个命题。

源代码：[E24 build_profiles.py](../20260910_gt_topk_profiles_v1/src/build_profiles.py)，`profile_from_weights`及每rank质量1/kgt；[原Fast builder](../../benches/run/build_fast_entry_variants.py)。实现有零范数保护；不能对v_h=0直接声称唯一最优方向。

## 2. 统计稳定性解释的正确限度

条件于已固定H，令Y_h=a_h(X)X。IID query假设下，样本平均估计E[Y_h]，其均方误差为tr(Cov(Y_h))/n。这个恒等式不需要vMF模型；但本项目没有凭该式验证query独立同分布。

对于非零v、w，有

\[
\left\|\frac v{\|v\|}-\frac w{\|w\|}\right\|
\le \frac{2\|v-w\|}{\|w\|}.
\]

证明是加减v/||w||后用三角不等式和反三角不等式。方向合力很小时，即使质量/ESS大也可能不稳定；支持量与方向一致性都需要看。对单位query x，画像得分误差至多为方向误差。如果第3与第4候选的真实得分差大于两者误差之和，精确top3边界稳定。**这只保证精确评分名次，不保证改变画像重建HNSW后走同一路径。**

E27观察GT10-hard的hub支持ESS明显增加；E106又观察到非随机的组内协方差。然而两者都没有证明ESS增加造成了最终增益。GT10的10个目标来自同一个query，它们相关，且权重和为1；不能说独立训练样本扩大十倍。后继4096-query全H标签也不等于数百万独立query样本。二者的监督类型、样本量和先验不同，不能把差异全归给“深模型弱”。

若要用vMF给出MAP分类解释，还需共同浓度、先验及条件分布成立；这些尚未验证。因此本报告采用不依赖该分布的闭式亲和结论。[球面聚类前作](https://jmlr.org/papers/volume6/banerjee05a/banerjee05a.pdf)。

## 3. 为什么代理更准仍可能不提高Recall

记S为真实入口集合，R(q,S;K,L)为原NSG实际Recall。目标所属hub的覆盖C(q,S)和R不是同一个函数：目标不属于S也可经多跳找到，属于S对应区域也可能被共享beam挤掉路径。

即使使用同一目标集合，可以定义一个严格但可能很松的误差：每个GT成员的“所属hub被选中”指标与“实际返回包含该ID”指标不一致的比例ε(q,S)。逐成员相减可得

\[
|R(q,S)-C(q,S)|\le\epsilon(q,S).
\]

所以代理改进到真实改进至少还要扣除新旧策略的两个桥接误差。GT10用GT10构造权重，而验收是GT1或GT100，另有目标集合错配；soft质量也非上述hard指标。仅证明代理回归/排序一致并不足够。

现有强反证是E109：Web的完美GT10覆盖代理把覆盖率35.42%升到68.93%，K1却比GT10Exact低0.6836pp（区间跨0）。Y有正值，说明断点随数据而异。这个结果不证明任何代理都无效，但足够阻止“先把同一代理学得更精确就会更强”的无条件推理。[E109原件](../../experiment_history/104_perfect_proxy_information_gate.md)。

## 4. 入口变了，响应为什么常常不变

理想精确算术下，对固定静态向量、图、规则及K/L，raw-IP比较只涉及q·(v_i−v_j)的符号；平方L2比较涉及仿射函数。排除同分并固定所有这些符号后，程序的分支、访问序列和结果ID不变。因此查询空间存在搜索行为相同的区域。实际浮点/并列规则需要额外处理，这里不宣称稳定半径可免费计算。

另一个不同的现象是：**同一个query、不同入口集合，可能汇合到相同返回。** 上面的分区论证不自动证明汇合率；汇合率来自本轮实测缓存。K100命中数相同也不保证成员、路径、NDC或wall相同。两种“相同”不能混用。

任何两策略的归一化Recall差D∈[-1,1]，都有

\[
|\mathbb E D|\le\mathbb E|D|\le\Pr(D\ne0).
\]

对K1，E[D]精确等于“救回概率−损伤概率”。对K100，还必须计每次救回/损伤的成员幅度。本轮全H统计中负幅度均值约为正幅度2倍；Y的正动作对甚至多于负动作对，均匀换单入口却仍使R100下降1.0116pp。胜率不是净收益。

全局不变性论证和这个简单界都是解释工具，并非新的高深定理。E113已有精确节点比较对跨query支持稀疏的事实；E118抽象比较方向仍未产生部署净收益。不能从分区结构直接跳到“训练一个更深树就能拟合好”。

## 5. 将oracle拆成四个问题

令a0为默认动作，g(q,a)=R(q,a)−R(q,a0)。大动作族H包括默认与每个单hub；候选族A(X)必须是线上信息X可确定的子集，并包含a0。定义

\[
F=\mathbb E\max_{a\in H}g(q,a),\quad
C=\mathbb E\max_{a\in A(X)}g(q,a),\quad
V=\mathbb E\max_{a\in A(X)}\mathbb E[g(q,a)\mid X].
\]

对只看X且π(X)∈A(X)的已冻结策略π，W=E[g(q,π(X))]。由子集关系、条件期望的最大值不超过最大值的条件期望，以及条件最优选择，得到F≥C≥V≥W，且

\[
F-W=(F-C)+(C-V)+(V-W).
\]

三个非负项分别是候选遗漏、信息不足、没有学到条件最优决策。成本暂未在这个Recall恒等式中出现。

本轮**只精确识别了旧4096-query经验矩阵上的第一项**：实际top3 singles加默认只能获得全H增益的21.23%/27.30%（Web K1/K100）、25.76%/31.55%（Y）。第二、三项还不能从E119失败中拆开；它既可能缺共享信息，也可能样本/模型不足。经验事后oracle不能替代总体F，且K、L和query来源变动都要重新定义这些量。

这个分解是标准决策论的具体应用，不声称前作没有。价值在于给下一步可检查的问题顺序：先候选能触及，再信息可识别，再查询外学会，最后成本可支付。

这里的信息不足是相对于指定线上表示X。固定库/图/GT规则后，完整原始query原则上决定所有精确响应；若X包含完整query、允许任意计算且A=H，则不能由小模型失败断言存在不可消除的信息噪声。真正限制的是廉价表示、可用计算和有限样本。路由上层状态是query和图的确定函数，其潜在价值是已经算好的结构摘要，不是产生了超越完整query的新信息。

### 有限动作也会产生选择误差

如果一个路由状态z的定义事先固定，在该状态内有n条IID训练query、M个预先确定的动作，且每个动作的真实净收益g∈[−1,1]都可观测，Hoeffding与union bound给出：以至少1−δ的概率，所有动作的经验均值误差不超过

\[
\epsilon_n=\sqrt{\frac{2\log(2M/\delta)}n}.
\]

用经验均值选动作相对该状态内最佳动作的期望收益遗憾至多2ε_n。这是标准有限类界，数值可能很松；不能拿它替代实测外折净收益。它说明小表并不自动意味着容易学：当M约800、每格平均仅约79条query时，选择自由度仍然很大。若状态划分或候选也是用同批结果选择，不能直接套这个固定类界；需额外控制选型或隔离角色。相关动作不违反union bound，但独立query条件仍不可省略。

对已冻结部署策略，若只看其确实改变命中的query，记正收益频率为p+、负收益频率为p−，对应条件幅度为m+、m−，净收益就是p+ m+−p− m−。本轮全H动作对中m−约为m+的两倍，不代表任何未来选择策略都有相同幅度，也不能直接据此预设统一置信阈值。

## 6. 没有完整时间，就没有吞吐结论

令T包括信息获取、选择器、原路由、NSG及输出写内存。串行QPS为1/E[T]，不是E[1/T]。在目标Recall r处应比较各方法满足R≥r的最小完整平均时间；缓存响应标签不足以估计选择器对cache和主搜索成本的交互。

若新策略在同预算质量更好，可能降低L，但新增费用必须小于降预算实际节省的时间。记录126的三点条件核算给出Web约92/46μs、Y约6.8/6.1μs的尺度；它固定了观察到的候选召回曲线和同L非新增费用假设，不是所有新方法的成本上限，也不是实测kNN单项费用。[原核算](../20260922_qps_first_theory_v1/report.md)。

不同效用动作在固定L下有非凸质量/时间组合，单一λ可能漏掉可行前沿；因此“成本敏感loss最优”仍不能代替Recall约束下的完整wall验收。记录126已说明此点，本轮不改写成新发现。

## 7. 六个必须保留的反例

| 错误推论 | 最小反例或项目证据 |
|---|---|
| ESS更大，画像一定更好 | 大量对称方向相消；样本多但方向合力接近0。E27 shuffle也不能完成因果归因。 |
| 精确top3必胜近似top3 | 精确的是画像分数。E107/E120 Y L128精确GT10的K1救回6、损伤8；本轮缓存复算。 |
| 多一个入口不会坏 | 多个入口共用有限池而非独立搜索并集；E107 GT10从1到3，18项里17个均值为负。 |
| 最优动作标签多，就有足够独立数据 | 4096×821是同4096条query上的相关反事实；E119每折拟合1792条query，非百万独立样本。 |
| oracle大，就容易学 | 每query各有一个随机优胜hub但X完全无信息，F可以大而V为0。 |
| CI跨0，所以收益严格为0 | E105 Web K1 125救回/126损伤，4096条的配对标准误约0.387pp；小于此尺度的收益难辨，仍必须保留原停止门。 |

配对精度说明采用D的样本分布：Var(D)=P(D≠0)−(ED)²，标准误为sqrt(Var(D)/n)。约80%检验功效的正态近似MDE可作设计尺度，不是本轮重新做显著性验收。该近似假设IID、固定策略和固定不一致率，不含多重比较、选型或来源偏移；不据此要求继续扩大失败分支的数据。

## 8. 能写进论文与仍不能写的句子

可写：GT10是GT引导的查询画像压缩；在固定代理上有闭式最优解；当前统一内核下有跨数据完整性能证据；多种更复杂后继尚未稳定超过它；响应稀疏、候选遗漏与成本可被分开核查。

不能写：GT10对Recall/QPS全局最优；十个目标是理论最优数量；ESS解释了全部收益；GT10小图减少了搜索路径长度；所有RL/MLP不适合入口选择；全H oracle就是可实现收益；若干候选同错就证明大图没有其他有效入口。
