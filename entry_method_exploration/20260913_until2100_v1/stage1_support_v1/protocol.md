# E60：固定 E53 动作的辅助支持与损伤约束

2026-09-13，今日独立 campaign 的第一阶段。用户已授权实现、训练、标签与查询；本阶段先完成有界实际诊断，全天目标仍待后续阶段推进。

固定两个数据集、E53 两 seed 20260921/22、各 step10/20/…/200 的动作前状态，共每集40状态。每状态只取原 C 与原 D25/D50/D100；不按新反馈选择状态、方向、半径、hub 或增加动作。保留全部负点。原训练反馈重建只用于核验及原 J 合法性；没有梯度更新、连续训练或模型导出选择。

辅助支持使用明确同源的旧 cal1024（router_train 局部行0:1024），迁移描述使用旧 audit1024（1024:2048）。两者均历史开发数据，不声称新盲集；前者被 E57 选型使用，后者亦有历史评估。当前 P 拟合 router_train10000:30000，包含原 train4096 与 monitor1024；原 Fast30K 更曾拟合全部 router_train。跨 namespace 的 validation 数值 ID 不参与重叠判断。最终 E34 validation2000 不进入本阶段向量/GT/响应输入、训练或动作筛选。未知全项目其余行暴露状态保持未知。

每状态先用原 train4096 的 d_rewards 验证 J≥当前；辅助约束为新增命中≥1、净命中>0、无新增 hits=0 查询。与昨日提案相比，此阶段仍执行原10/40支持门，采用严格正净值（昨日支持检查门本即如此）；候选接受诊断也使用该同一条件，避免净零动作满足支持计数。固定规则在三个点及不动中按原 J 最大选；同分优先不动，再较小半径。与原 J 接受逐状态比较辅助/迁移 gain、loss、净命中、救回、新失败及 NDC；约束用过的辅助标签计作选择训练信息。迁移结果不回改规则或候选。不同原状态的差值之和仅为诊断，不能拼成连续方法收益。

支持门：每集≥10/40状态至少存在一个合格动作才支持继续同动作机制的连续对照；任一集不足则停止双集相同机制预算扩张，并具体检查覆盖及收益保留。此门是投入判断，不是性能 GO。即使通过，连续对照另立版本/角色/预算，不能自动套用旧标签。门失败不否定全部画像、构图或 RL 方法。

冻结 P、B、H815/821、真实ID及插入顺序、M16/efConstruction200/efSearch10/seed20260828、raw-IP、原NSG、L128/K10。复用同 SHA 的 E46 原生缓存接口，只读旧源码与索引。CPU15，threads=1，OMP/OpenBLAS/MKL/NumExpr/BLIS 均1；一次只运行一个加载原生库的进程，不同时运行分析或其它训练/评测。
