# E213 四集 GT10+B32、固定单入口 NSG 与 GATE 同期复测

主比较三条链路。GT10+B32 复用 E212 的三入口画像和完整原 B32 表。NSG 复用同一个 NSG 图的固定单入口。GATE 复用 E200 冻结的 512 hub、W 与小 HNSW，沿用单位 query 路由、slot 到真实 ID 映射和 heap-pop 次序。小图选入口后以原始 query 进入同一 raw-IP 主图。三条链路均采用 E211 发布库的 SPAN4。另在相同时间表加入 GATE 标量臂，同路由同模型，量化主搜索后端的影响。

固定 COCO、Flickr30k、WebVid、Yandex official first10M，各取 E212 同一公开前 3,072 条。真实 K1 的 L 为 64/100/160/200/320/400/800，真实 K100 的 L 为 100/160/200/320/400/640/960。每点两遍，在 CPU15 实际单线程串行，轮换方法顺序并在第二遍反向。每批独立预热 256 条。完整 wall 包含正常 Batch 创建销毁、入口路由、主图搜索、相应补点及六数组复制。加载、预热、GT、核验、写盘在 wall 外。主 QPS 取两遍 N/wall 的算术平均。

主比较 168 点和 336 批，GATE 标量对照 56 点和 112 批。独立探针在各集的 K1/K100、L200 核验每臂实际 Faiss batch4 调用，正式二进制不链接计数探针。正式保存各点首轮返回，逐点核对两遍和 GATE 的两后端。正式计时全部完成后评分，NSG 与 GT10+B32 交叉核对 E212 原包，GATE 与 E200 可对齐的旧包核对。

报告逐点 Recall/QPS、同 L 差、实测门槛和 K100 低召回。门槛沿 E212 的 90/95/99%，WebVid K100 增加 70/80/85%。门槛 QPS 取各方法最快已测达标配置。主比较及曲线保留三条链路，GATE 标量作为后端对照。沿用冻结训练产物，费用仅计此次查询，保留原监督差异、公共查询窗口和计时边界。
