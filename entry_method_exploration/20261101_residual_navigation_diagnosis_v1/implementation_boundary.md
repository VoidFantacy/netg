# E195辅助队列的实际边界

以下澄清冻结源码已有行为，不改变方法、矩阵、预算或原协议字节。

辅助队列显式加入已选seed，所以seed即使已被主搜索评分，也可以主动展开。随后沿出边访问时，所有原main visited节点和全部C/已评分代表/本动作已见节点均跳过，不再精算，也不再作为新节点入队；未选C不因被再次遇到而自动获得展开资格。节点的新入队来自本动作新增精算。代码以只读主visited和局部seen实现，不是完整主状态续搜或全评分缓存。

因此，“未评分目标邻接某个已评分未展开节点”的离线机会，不保证本轮辅助策略一定会利用那个中间节点。跳过已评分节点既节省重复计算，也限制可走路径；E195未隔离测试保存所有评分、恢复被淘汰节点、扩展所有C或其他状态共享策略。不能把本轮静态代表/新邻接选择的结果外推到所有导航或续搜方法。

直接B32的已评分C无效重算证书，只讨论原有限标量分数/Top-L不变量下的答案合并。对导航而言，已评分但未展开的点仍可能是有价值入口，不能据该证书删除其导航资格。后继若导出状态或复用评分，需计实际保存/读取/队列费用并另冻协议。
