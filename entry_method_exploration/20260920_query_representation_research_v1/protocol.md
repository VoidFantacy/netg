# 查询侧非线性表示：最小证伪协议 v1

状态：**DESIGN_ONLY，尚未实现训练/评测 runner，未产生 pilot 性能结果。** 2026-09-20 研究阶段的建议方案。该协议把下一次验证做成可复核的有限任务，不代表已证明值得扩大训练或变更默认。

## 1. 假设与研究差异

H1：固定 hub/P 的 query 非线性表示比同参数量的 query 线性残差、更宽松的静态 W，在同一真实集合监督下更能兑现未用于梯度训练的查询收益。

H2：这种收益在一次 Micro-HNSW 路由及完整 NSG wall 中仍成立。只提高 exact hub 排名或降低 NDC，H2 均不成立。

H1/H2 不预设成立。旧 E28 变换 hub 后导出静态 W，旧 E36 在线枚举组合；本版 query 只变换一次。真实联合标签、set CE、GT10 anchor 都是继承机制，不列作新发明。

## 2. 固定对象与数据身份

- 首轮只 WebVid/Yandex。主 anchor 分别 E103 使用的 soft-t1/hard；另一个 GT10 作为固定辅助基线。原真实 H、映射、base/metric/NSG 及 Micro-HNSW 参数保持。
- 拟从 E24 fit 的原行序列取前 2048 条作为梯度训练；从 E24 cal 取前 512 条作为一次性开发门。实施前仅以 config/row IDs 核验数量、namespace、重复及历史用途，并生成新输入 manifest。若数量或角色不满足，停止准备并修订协议，不静默换数据。
- 这些都是历史开发资产。即使本次冻结后未训练在 cal 上，也不能把 cal 宣称为从未曝光的测试集；P-fit、旧训练监督的使用全部披露。
- 不打开 E94 最终失败 query、冻结 held-out 或 E103 test 载荷来选模型/子集。E103 汇总数据只用于已有证据定位。pilot 通过后另行审计新的 query 来源/时间或分布分组，并在获取结果前固定独立评估角色；没有干净来源时只声称开发结果。
- 新监督分别真实执行 K1、K100，均 L128。K100 有 L≥100；不执行新 K10。旧 E28 hits/teacher 仅供本轮历史几何说明，不作为新 utility 标签。
- 所有 NSG 方法共用 E103 span+batch4 ResearchKernel；生产 E99 不改。准备时核验输入/源码 SHA 与该 kernel 的输出一致性，不凭目录名宣布兼容。

## 3. 先检验联合效用余量

每条 query 的候选至多 8 个真实入口。先保留当前 anchor 的真实 HNSW top3，再加入另一个固定 GT10 的 top3，重复去除；不足 8 时按当前 anchor 的精确画像排名补齐。顺序、tie、去重规则在任何搜索前冻结。两 anchor 共用 hub 映射须先核验。

枚举至多 C(8,3)=56 个集合，分别在 K1/K100、L128 下实际执行原 NSG。候选上界只代表这批有限动作，不能称全 H oracle。候选构造不能利用 GT 或历史失败 query。

**入口顺序也是执行身份的一部分。** 先在各集预锁 16 个 fit 位置上检查六种入口排列、两个 K；若排列影响结果，当前“集合监督”假设不成立，本版停止并报告，不悄悄把 56 扩成 336 动作。若通过，采用固定候选序排列，并在实际评估时始终记录真正输入次序；小样本 parity 不证明所有输入排列等价。

每个标签保存 query/GT/base/metric/NSG/kernel 的身份，K、L、真实有序入口 ID、完整返回/距离、Recall 和 NDC。复用键含所有上述影响执行的字段；模型输出一个未测顺序/集合时，不能以近似标签或未知=0 代替真实测量。

对两个 K 分别报告 oracle−anchor、获益/损伤/持平比例及 anchor 零命中；另报告同时不损害两个 K 的候选覆盖。阶段判断依据各 K，禁止平均分掩盖其中一个 K 的损失。

**余量门：** 两数据集各至少一个 K 的有限动作 oracle 平均 Recall 余量达到 0.5pp，且至少 5% query 存在任一 K 的严格收益。如果不满足，不训练这条 C8/query 表示路线。门槛是本版投入标准，不是统计显著性或普适常数。失败可能源自候选不足，不推出全部入口学习无效；H 扩展需另立假设，不能自动启动。

## 4. 一次模型对照

| 控制 | 分数/模型 | 目的 |
|---|---|---|
| Identity | q₀ᵀP | 原表示，与实际 anchor 小图同时报告 |
| QLinear | (q₀+UVq₀)ᵀP，r16 | 与 MLP 同参数数量及同一次在线调用，检验是否仅线性调整就足够 |
| QMLP | (q₀+U ReLU(Vq₀))ᵀP，r16 | 唯一主候选，P 和小图冻结 |
| WFree | q₀ᵀW，W 从 P 初始化，不逐行单位化 | 静态线性表示控制；避免 row-normalization 把可表达范围人为缩小 |

q₀ 只为路由单位化；NSG 总是接原始 query。z 不再按 hub 分别归一化；若实现需给 z 乘共同正标量，先验证数值/路由影响。仿射折叠只用于代数诊断，不用来跳过上线一致性核验。零范数和非有限 query 沿原 API 行为，不静默增添新 metric。

三个可训练控制使用同一批标签、同一集合监督、seed=20260920、Adam lr=1e-3、40 epochs、batch256、float32、温度0.05；同一 shuffle 顺序。每个数据集各三次，共最多六次训练。隐藏宽度不扫网格；固定最终 epoch，不根据 cal 选 epoch。损失/gradient 非有限属于实现失败，保留原日志与修订身份，不能把重跑称为独立 seed。

主损失使用已有集合似然形式，但本版归一化范围只包含已测的至多 56 个候选集合：按两个 K 的真实 Recall 平均数找最大集合，tie 保留全部；损失为 logZ(measured triples)−logZ(teacher triples)，集合 logit 为三个入口分数之和。相同目标同时应用三个控制。两个 K 的权重均为 1/2，NDC 不混入 Recall 权重；teacher 是否损害某个 K 另报。未测三元组不自动充当负例或零收益；它们也没有受到效用监督，这是离线动作支持的明确限制。所有组合运算只在离线训练发生，线上仅运行一次 query 变换和原小图。

统一加入 10×训练 query 上相对原分数的均方漂移正则：mean[(sθ(q,h)−sP(q,h))²]，对 q/h 均取平均。用于继承 GT10 的行为，不宣称提供逐 query 安全保证。主损失改善、教师匹配提高都不等于真实 Recall 提高。

初始输出必须与 P 数值一致：QLinear/QMLP 的 U 零初始化，V 使用同 seed；WFree=P。训练前以独立的小规模枚举核验候选限定 logZ/多教师目标及梯度，检查线上/离线 score 和实际 route 的一致性。这些检查只验证实现。

训练成本上限合计 30 分钟、峰值 RSS 8GiB；准备/标签/训练总 wall 上限 2 小时。达到上限保存不完整状态并停止，不增加 epochs 或换 seed。预算合理性先由每阶段首批实际计时估计，拒绝无法在剩余预算内完成的新阶段。

## 5. 跨查询迁移与 HNSW 部署

冻结三个模型后，仅一次使用预锁 cal 开发门。报告所有模型在 fit/cal 的真实 K1/K100、净救回/新损伤及零命中；另报告精确 top3 与实际 Micro-HNSW 的差异、输出落在已测候选集合之外的比例。网络输出不在缓存中的入口集合/顺序须实际搜索；这些新增评估不能回流再训练本版模型。

**表示门：** QMLP 在两个数据集的 cal 上分别达到：相对 anchor，两 K 的平均 Recall 都不下降，至少一个 K 提高 0.5pp；同时相对 QLinear 与 WFree，各 K 平均 Recall 不下降且至少一个 K 有严格改善。512 条只有开发分辨率，报告配对区间和原始差值，不当最终显著性证明。这个门未过，则停止本版，不再扫宽度、学习率或 seed。

精确路由通过但 Micro-HNSW 未通过，归为近似部署失败，不能只保留精确数值作为最终成功。WFree 要独立普通 HNSW 构建并记录成本，其图改变意味着它是静态方法能力控制；QLinear/QMLP 的主比较才是相同图的非线性归因。WFree 的 exact 与 ANN 差异独立列出。

## 6. 完整 wall 门与规模上限

表示门通过才做性能阶段。所有保留方法统一串行、CPU15、进程和 OMP/BLAS/MKL=1 线程，无并发训练/标签/下载。禁止用离线批量矩阵乘法速度替代单 query 延迟；QLinear/QMLP 用同一 C++ 路由实现和内存分配边界。

两集各使用同一 cal512、K1 L={64,128,256,400,800}、K100 L={100,128,256,400,800}。固定方法为 NSG、两个 GT10、GATE、全量 HNSW、QLinear、QMLP、WFree，共 8 方法。每点 warm1/plain3/count1；保留全部 160 配置/480 plain，不隐藏失败点。实际 full wall 包含归一化、网络、路由、映射、底图搜索和返回；GT/count/磁盘 IO 在计时外。

标签上限 2×2560×56×2=573440 次真实 NSG；完整 wall 阶段最多 2×8×512×10×5=409600 次被测主检索。顺序核验、模型真实动作校验等另记账，主检索总上限 110 万次和 4 小时额外 wall；每次查询内部的小图路由另列调用数和成本，不把它漏记或混算成主检索。已有底图/GT 的继承成本记历史已知值或 unknown，不记零。未完成完整计划不宣布性能通过。

**性能投入门：** 两集各 K 在 L128、400、800 三点均不损害 anchor 的 Recall，至少两点完整 QPS 提高 ≥3%，新零命中数量不超过 anchor；其它预算全部披露。相对 QLinear/WFree 同时检查实际前沿，若简单控制同样或更好，不支持“非线性必要”。完整曲线/配对不确定性用于后续判断；这里的开发门不是录用、默认替换或正式五集优势证明。

通过也只进入扩大证据阶段：冻结单一主模型，在新协议下验证独立分布/来源、标签规模、离线成本、失效场景及最终相关工作；不按测试预算拼模型。失败保留全部记录，回到 GT10，不自动改默认或恢复旧 RL 分支。
