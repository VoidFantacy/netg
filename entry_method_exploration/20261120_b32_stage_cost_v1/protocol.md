# E207 原 B32 补点分段计时

2026-11-20。COCO hard 与 WebVid soft-t1，复用 E204/E206 同源完整16K B32、原图、画像、raw-IP和主搜索。公共10K固定取最前3072条作为配对诊断窗；真实 K=1、100，L=100、200、400。先锁定矩阵和判读。公共测试曾曝光，GT仅用于全部运行完成后的复算。

每个配置用原 E206 未插桩 GT10 和 B32 按方法/轮交替，预热256，每法两遍。随后用两遍分段版本回放 B32，六数组输出与同条件未插桩 B32 逐字节一致。两类计时都测完整 Batch 创建、路由、主搜索、补点、六数组复制销毁；分段路径增加阶段时钟，给出钟差和仪器影响，不用分段版替代完整性能。12个配置、48个正常批次、24个分段批次，共221,184次计时查询。CPU15 实际单线程串行。

分段分别保存路由批次、主搜索含 set_query/visited advance、补点输入检查加旧结果复制、三路查表去重排除主返回、额外精确距离含候选写入、原 K1/K100合并、写回结果ID。归并与精算调用顺序沿原实现。另在独立无阶段计时的第三条 B32 诊断路径检查每条查询的表位计数、候选重合、主保留池尾部精确分数逐比特相等及是否低于第K名门槛、任意被 visited 标记、精确通过原门槛数量、最终有没有新ID；诊断附加动作不计完整 QPS。测不连续阶段之间的分配及计时钟差，仅报告残差阶段份额，以及与同期完整时间差的描述关系。

附加打分的测量包含原向量访问和距离核计算，无法单凭这个阶段划分区分 DRAM、cache、算术所占比例。仅讨论可验证的优化优先级，不发布速度优化原型。原 B32/GT10、原封存及生产默认按现行合同。
