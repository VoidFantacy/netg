# E193 自适应补全开关最小验证（读取新结果前冻结）

问题：补全收益是否集中；实际跳过无收益动作后是否存在完整费用空间；廉价线上特征能否实现。
七集已有E191的K1/K100、L200实际返回只作收益异质性诊断。新正式测COCO、Deep10M、SIFT10M，各固定seed=19320261029随机2048个公共query，真实K1/K100。公共test已历史曝光，非新盲确认。
复用原base、图、metric、GT10、E191 SQ8与前12K标签建成的块表。开发角色：原合法16K residual query的[12000,14000)拟合、[14000,16000)校准；与新块表前12K分离；旧GT10监督可能覆盖16K，须披露。B32原16K仅作正式参考，不进入拟合/校准动作。
后端固定REUSE-SQ：三路hub各8块+主返回频率最高8块，最多32块，最多2048代码、96精确分数。L200。
开发实际运行GT10/SQ一次并保留返回；从实际主返回做三次单query补全微计时，复制/设置query在外，单次完整complete在内。微计时用于校准费用估计，不等同完整wall差。拟合目标是净新增GT成员数及补全微秒，而非单纯难度。
固定特征12项：三路profile分数排序后的最小、次小间隔、全跨度，query范数平方，跨度/(1+abs最小)，主返回D在0、1/4、1/2、3/4、K-1位置，末首差及其/(1+abs首)。K1相同位置允许相等。候选ROUTE前5项、POST全部12项。只读已有route/main及query，无额外probe。实际开关在主搜索结束后。
每组拟合两种模型：标准化岭回归(lambda=10)双头预测收益/费用；深度3 CART，以收益平方误差分裂，每特征16个拟合分位阈值、最小叶32，叶均值为双头输出。得分max(预测收益,0)/max(预测费用us,1)。阈值为拟合得分启用率[1,.75,.5,.25,.1,.05,.01]对应分位数（>=阈值，平分同启用）。只在校准集选择保留>=90%正收益的最低估计费用候选；费用=启用动作微秒均值+固定0.5us推断预算。全开与全关可作回退；没有正收益时回退全关。模型/阈值在正式结果前写入封存，不追测到通过。
正式GT10 L固定[200,202,204,208,216,232,256,272,288,304,320,400]；L200另测B32、全开SQ、GATE-OFF、GATE-ORACLE、GATE-LEARNED。合计102点、306个完整T1批次。ORACLE是GT导出的正净收益mask，真实付出分支/主搜索/补全wall，但GT读在外；它仅是保留全部正收益的理想参考，非全局最优成本定理、不可部署。
资格每组128query、6方法、1轮；正式每点3轮，256warm，轮转顺序。CPU15，OMP/BLAS/MKL/NUMEXPR=1，实际进程线程核查；不并发训练或性能工作。timer包含Batch分配/初始化、路由/主搜索、特征/推断/分支、条件补全、六数组复制和销毁。保存实际返回，三轮bits/SHA一致，逐query gated输出严格等于该query实际GT10或SQ，SQ全排序oracle另核。
结论：分别判定收益集中、理想潜力、廉价可预测性和付费完整收益；与同窗口更大L GT10及B32比较，不能将更快辅助阶段当净胜。小窗口仅探索、不改E99默认。结束固定矩阵即止；无新PDF，无改旧seal。空间底线/data>=0.65GiB,/root>=0.7GiB，新产物独立storage。
