# ACSG 下一阶段方向与实验接续

2026-09-12。E38已完成此前第一优先的既有反馈诊断；[历史27](experiment_history/27_offline_profile_diagnosis.md)、[报告](entry_method_exploration/20260912_offline_profile_diagnosis_v1/report.md)。E37训练/曲线原件不改，用户主意图仍是离线学习画像、在线一次普通HNSW。本文件以下新增搜索/训练均未执行。

## 当前依据

当前最直接的瓶颈是：真实命中反馈集中在少数查询，batch128给出的更新方向不稳定。两臂同样出现这一现象。它支持优先检查查询批次噪声，但尚不能证明增大batch就一定能学出更好的画像，也不能排除当前共享表示下的真实可改进方向本来就很弱。

RL每步能区分八动作命中质量的query中位数仅WebVid 9/128、Yandex 3/128；相同扰动下两半query梯度的余弦中位数为0.0078/0.0041，约半数步为负。命中梯度远大于成本/漂移项，总梯度与命中梯度余弦约0.999，不支持“惩罚压住学习”作为主要解释。

随机动作转确定均值有局部差距，但严格匹配仅覆盖80组、1188条重复query记录，每run只有126/128个独立query身份；区间包含0，部分差值受单条记录影响很大。共享画像表达不足仍未被单独验证。下一步建议固定μ与扰动，仅检验更多查询是否能稳定方向，暂不追加epoch、改表示或启动新训练。

条件query噪声检查和表示能力判断分开。RL/ES同参数空间均有方向不稳；实际收益集中性、惩罚项尺度、参数未撞边有直接证据，增大batch必然改善与共享表示不足没有因果证据。E37历史数据暴露仍保留，不能把此次复算称为新的独立性能验证。

## 第一优先：固定参数与动作，验证查询批次噪声是否可压低

E38既有反馈诊断已完成；最小接续为一个尚未执行的静态诊断，不直接重训。每数据集只固定两个参数点：μ=0和E37按cal冻结的主RL μ；各自沿用原轨迹中对应checkpoint后一步的八个扰动动作。这样函数、μ和方向都固定，仅改变用于评价这些动作的查询数量。

从E37已有train4096中另取1024行，排除这两个原128-query动作批次；按固定无标签seed均匀抽取、分成8个互斥128-query块，同一名单服务两参数点。它们仍有历史训练暴露，只是在该固定动作梯度估计中与原批次分开，不能称新盲测。真实执行八动作和确定中心，保留全部逐query命中/NDC/奖励。

核心比较为128、256、512、1024聚合后的条件方差与方向一致性，尤其两组互斥512是否建议相近方向；固定方向只检查query采样噪声，不能评估完整256维梯度或全部扰动噪声。奖励仍用原公式，不借诊断选择新μ、σ、rank或checkpoint，也不把被评估动作中最高者部署。

正常搜索预算为2数据集×2参数点×(8动作+1确定中心)×1024=36,864次NSG，另预留parity，建议总硬上限40,000；0optimizer更新、0新GT、0新validation/held-out、无QPS/默认替换。画像/小图仅按这36个冻结配置重建，调用、线程与计时合同须在新版本协议中落实。这是待执行建议，不是E38实际调用。

若更大互斥批次的方向仍接近无相关或经常相反，就停止扩大训练预算，回到表示/局部目标是否有可学习空间的问题；若方向能稳定，才讨论同总真实调用预算下的microbatch累计方案。增大batch会减少可用更新次数或扰动数量，后续必须保留预算匹配控制，不能把更多总标签费用当作算法优势。本控制尚未运行，无排队任务。

## 第二优先：仍保持离线画像学习，但只针对已确认瓶颈修订

用户主意图保持为“离线花训练成本，在线一次普通HNSW”。若第一步证明方向估计噪声主导，可先提出同总调用预算下批次/对称扰动分配的单项调整；若证明共享变换无法有效区分入口，再考虑入口各自可调整、带原画像锚定的表示。后者须先完整复核E22的自由低秩W、E28的free/linear以及E29–E32真实目标与等价教师经验，明确新参数空间、监督与部署决策的差别，不能将旧free-W简单换名重启。

新方案继续让每个候选画像实际构建HNSW并调用原NSG，或明确标记代理目标与真实部署差距；不得重新以旧C8未测组合充当完整反馈。至少保留原GT10、匹配表示/预算的非RL估计器、零更新恢复和完整确定模型部署。固定H/映射/大图/IP，并同时登记原GT依赖、画像/构图/真实反馈/训练/部署成本。

进入训练前先提交唯一主修订、数学目标、参数/图接口、数据访问清单、每项调用账与硬上限；不同时扩大表示、batch、σ和训练步数。先以独立的新协议和版本锁定开发门，再运行双数据集；实际质量不改善或损伤抵消收益时停止该版本。任何通过都要以冻结模型同机单线程完整Recall–QPS评估，不以训练reward或同L Recall替代。新训练与新的评估数据访问尚未安排。

## 第三优先：构图策略作为独立备选

只有证据指向微型图的候选覆盖/搜索效率时，再讨论学习插入顺序、邻居保留或有限补边。E33只删除原底层边的版本及E34成本结论保留；新构图方案必须说明它增加的动作能力与普通HNSW确定重建控制。E35“好点已评分却没选中”提示仅改连通性未必解决评分问题，不能从强连通或最短跳直接推导检索收益。

备选仍只改小入口图，固定大NSG、真实入口映射、在线距离与预算；控制同出度随机改动、相同画像普通HNSW以及保分数的图变化。额外邻居/边访问费用进入完整wall。若候选覆盖改善没有转为实际联合命中或共同Recall范围的QPS收益，停止扩图；此方向没有实现新动作或排队实验。
