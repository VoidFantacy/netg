# E198：条件残差导航具体做了什么

本文从主搜索完成后开始，不重复介绍GT10。实现和正式冻结见[协议](protocol.md)、[源码](src/benchmark.cpp)、[策略](src/policy.inc)、[训练](scripts/train.py)；实测结论见[报告](report_zh.md)。

## 先区分两种价值

残差点有两种用途。第一种是直接进入最终答案：某个点本来没有返回，但它离查询足够近。第二种是充当搜索入口：这个点自己未必进入答案，但从它沿图向外走，可能找到主搜索遗漏的好点。

原直接补点得到候选集合C。本轮沿用Q8残差表：每个路由行至多32个ID，三个路由行合并后至多96个，去重并排除主返回中已有的ID；这里Q8指编表的8K训练查询，不是8位量化。所有C先按原metric精算，其直接答案价值全部保留。后续只挑其中至多一个点作为额外导航入口，不会因为没选中某个入口就把该点从直接答案中删除。

完整16K表的OPT-B32和已有REUSE-SQ同时作为强控制。REUSE-SQ沿已有块来源及SQ近似筛选、精排补点流程；E198没有重新发明该后端。新模型只针对Q8训练和部署，不把Q8向完整表的迁移视为已经验证。

## 一次在线查询的处理过程

1. **保留主返回和全部直接补点。** 得到候选C的精确距离，以及主搜索visited等只读信息。
2. **先判断是否值得继续。** 深度3的小树读取12项便宜摘要，包括C距离跨度、相对主返回的距离间隔、路由分数差、query范数、候选数和K/L状态。门拒绝时，直接输出主返回与C合并后的Top-K，省掉后面的query投影、学生预测、教师重排及图扩展。它不能省掉已经完成的主搜索和C精算。
3. **快速挑出导航候选。** 节点的32维表示离线训练并预存；线上只编码一次查询，分别预测96/384预算的增量收益。全C通过两个32维内积和23项便宜候选特征打分。它避开了逐候选扫描邻接visited的重特征，但仍实际计入查表、特征构造、排序和分配成本。
4. **小名单重排。** 每个预算保留“离查询最近的1点＋学生排名前5点”，去重后最多6点。再用对应状态/预算的128轮HGB教师模型重排。保留最近点是一个距离参照；学生补充的点可能比它更适合导航。
5. **决定不展开、展开96或384。** 对两个预算各自最优种子，比较预测收益减去费用惩罚，选择最大正值。两者都不为正就不展开。惩罚使用固定预算比例96/384，而非逐query真实wall预测；λ只在开发集选择。
6. **沿原图做独立有界扩展，再合并。** 只展开选中的一个种子及其后继，最多新增精算96或384个向量，物理邻接访问另设64×预算上限。原主搜索visited只读，辅助队列/seen独立，按继承后端规则跳过已主访问点及已直接评分C。最后把新发现点、全部C和主返回按原metric合并成真实Top-K。

因此，本轮“前置”是放在重模型之前；整个残差动作仍发生在主搜索之后。没有修改主图、恢复原主beam，也没有实现主搜索pause/resume。

## 模型究竟学什么

对合法训练query、每个C入口以及96/384两种预算，实际执行一次辅助搜索。标签是最终答案的净新增命中数：

\[
\Delta(q,h,b)=|\operatorname{TopK}(A(q)\cup X(q,h,b))\cap G_K(q)|-|A(q)\cap G_K(q)|.
\]

A是主返回和全部直接补点合并后的答案，X是入口h在预算b下新发现的点。标签另存救回、损伤、实际精算量、邻接访问及动作微计时。微计时不充当线上QPS，也没有被包装成实测wall最优策略。

教师使用104维部署可取得的特征，包括距离/主状态、query投影、节点与出邻域摘要及交互；教师是学到的预测器，线上不读取GT。学生是双塔小网络，query为25维输入、节点为34维输入，分别经过64维隐藏层；节点输出32维预存表示，query输出两个32维预算头，另加廉价候选线性头。损失包含教师回归、真实收益回归及query内正收益加权排序。它没有训练GNN，也没有宣称只凭度数/密度就能找到好入口。

预算动作的形式为：

\[
(h^*,b^*)=\arg\max_{b\in\{96,384\},\ h\in S_b(q)}[\widehat\Delta_b(q,h)-\lambda b/384].
\]

最大值不大于0时选择无动作。门另学习当前自适应动作的正收益，再用独立校准样本选择阈值，目标是保留至少90%的校准正收益并减少启用。校准目标不等于正式窗口已经达到，报告按实测重新核对。

## 怎样判断是哪一部分有效

| 本轮名称 | 做法 | 用于隔离的问题 |
| --- | --- | --- |
| Q8-B32 | 全部C直接精算合并 | 直接答案的基线 |
| DIST96/384 | 全C中最近的单个种子，固定预算 | 学习选点是否优于简单距离 |
| FAST96/384 | 学生全C选1，固定预算 | 蒸馏是否省时、是否保留选点质量 |
| CASCADE96/384 | 学生短名单，教师选1，固定预算 | 少量精排是否值得付费 |
| ADAPT | 级联后选0/96/384，无前置门 | 预算选择的收益与费用 |
| POLICY | 前置门＋ADAPT | 拒绝是否能省完整耗时且保留收益 |
| TEACHER384 | 新状态匹配教师全C选1 | 新教师选点质量及完整费用 |
| MODEL1 / OLD-CACHED384 | 原E197模型/相同模型缓存共享特征 | 返回完全等价的工程省费 |
| OPT-B32 / REUSE-SQ | 原完整直接表/已有SQ补全 | 新方法是否胜过强残差基线 |

注意E198的DIST96/384是**全C最近单种子**，与E195同名的逐路由多种子DIST动作有实质差别，不能按名称拼接旧结果。新旧兼容控制另核实际返回包SHA。

每个数据集的K100/L100、200、400和K1/L200分别训练。本轮两集，每集沿固定角色使用2048查询fit、512模型/策略开发兼门fit、512独立阈值与费用校准。开发集在epoch、λ和门fit之间共享，已经披露；不称全部开发决策相互独立。正式A/B各512，都是旧曝光窗口。正式完整单线程wall包含正常Batch生命周期、全部选择/重排/扩展、结果复制及销毁；加载、GT评价、写盘及核验在外。三轮计时不是三个独立质量样本。

工作量中的邻接槽统计对应辅助扩展，不含主搜索及教师特征读取邻接的槽数；后两者的耗时仍包含在完整wall。额外精算量不是总NDC，六数组包里的零NDC占位也不代表没有距离计算。不同方法的总费用以完整wall比较，不能从局部计数独自推出瓶颈归因。

本轮收口以冻结矩阵的实测为准。局部救回、单纯模型加速、有限网格未覆盖都不能单独证明可以替换默认。历史条件有效的M5/B32/SQ不因本轮学习策略的成败失效。
