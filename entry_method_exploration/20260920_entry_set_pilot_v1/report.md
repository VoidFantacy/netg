# E117：四动作入口集合试验

2026-09-20。`STOP_ENTRY_SET_PILOT`。按用户“试试”完成独立版本。只选择主搜索开始前的真实入口集合，原GT10画像/小图、底图、raw-IP、L、展开及停止规则保持。Web soft/Y hard及生产E99没有替换。

**主模型未通过预先冻结的接受门，停止本版。** 不追加深度、阈值、λ、seed、候选数量或失败query定向修复；条件完整预算比较未启动。下表保留全部正负结果，不能把拟合收益或免费oracle称为可部署提升。

## 1. 实际做了什么

每集原E24 fit20K的前10000条拟合，最后4096条接受，源行分别[10000:20000]和[25904:30000]；query字节互斥。原GT10画像曾使用这些query，所有源均属历史开发材料，因此只称“本版选择器拟合外接受”，不称画像未见或项目盲测。E105那批4096条没有进入本版。两集模型冻结后才打开接受载荷。

一次原小图返回相同三个真实候选，按实际画像分数定义e1/e2/e3。动作仅为原三入口、e1单入口、e2单入口、e3单入口。选定后按原约定调用同一kernel；没有强制首展开、搜索中换点、剪枝、重启或调L。

六特征是两项画像分数间隔、三项真实入口raw-IP间隔和实际分数最优者的画像rank；真实分数额外3次点积计入成本。深度≤2、叶支持≥512的固定贪心策略树：CostTree使用等K召回差−0.1×相对时间差，RecallTree不含时间项，ShuffledTree固定打乱完整动作标签向量。量化分裂候选只由fit特征生成，未用接受结果调超参数。此算法不是全局最优树保证，也不把共享评分器宣称新颖。

训练时间标签按256条query的块轮换五种计时变体，每变体完成整块再换方法，共四遍。原GT10与计算特征后仍三入口的Feature3分开计时；single训练时间包含特征。真实树判断及返回输出成本最终以整批wall验收。训练K100同L首返回用于K1标签并经实际K1/原内核检查，接受K1/K100分别实际调用。

动作空间有余量与低成本特征能预测净收益仍是两回事。CostTree与RecallTree的拟合差别表明成本项是否改变实际决策；当前版本的负结果只约束这组特征、动作域和训练法，不能推出所有入口选择不可学习，也不支持转去修改主搜索。

更具体地，Web的CostTree与RecallTree学到相同入口决策；Yandex加入时间项确实改变了决策，并使主模型的完整速度均值高于RecallTree，但仍没有同时胜过GT10和固定Single1。成本已经参与学习，不能把本轮失败归结为“没有学QPS”。

固定Single1在接受侧的四项Recall均值均高于CostTree，也均略高于GT10；但对GT10的四个Recall区间仍跨0，Web K100的QPS均值下降0.708%。因此它是必须保留的强简单对照，尚不能凭这个开发点直接改默认。Web训练侧最强固定动作原为GT10、接受侧变成Single1，也提醒我们不能把训练排序直接当作后续query的稳定规律。

本轮最直接的结论是：这六项初始化分数特征与固定浅树，没有把四动作的逐query互补性转成可靠净收益。共享动作减少了按具体ID分割样本的程度，但没有自动解决增损相抵与预测迁移。停止本版，保留原默认；不将其包装成“需要更深的树”再开启调参。

## 6. 成本、核验和停止边界
