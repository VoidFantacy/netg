# E116：冻结GT10路由的H外入口绑定试验

2026-09-20，用户“测试一下看看”授权。独立新版本，不重启E22/E112或任何旧runner。仅改变画像label到真实入口的外部绑定；画像、小图、ef10、base、raw-IP、原三入口升序初始化、L及主搜索保持不变。采用已验收E103/E105 span+batch4 ResearchKernel逐字副本，smoke与链接E99核验；生产源码不变。

## 数据与候选

- 两数据集：WebVid GT10-soft-t1、Yandex GT10-hard。旧E24 fit20K的前10K仅用于候选提出，后10K用于收益/时间标注与选择；按向量字节去重，跨角色重复保留最早角色，不补行。后10K按原位置奇偶分成两半。路由使用实际冻结小图，不用exact排名替代。
- 每槽至少12条提议查询。其提议查询的GT100并集排除原H，先选4个按倒数log排名加权频率最高的节点，再选4个与单位query均值raw-IP最高的节点，全部同分按ID；不按收益结果改候选。后者只做提议，不假定几何代表真实效用。只从提议角色取GT；不使用标注或审计查询的GT产生其候选。
- 每个候选独立替换该槽，另外两个入口保持原样。全体标注查询均保留，包括原本成功的查询。未知候选不补0，不以单入口返回并集代替三入口搜索。
- 审计使用E105全部4096条/集，与本轮提议/选择物理分离且重新核验字节不重叠，但已有项目级曝光，明确不是新盲测。模型冻结后才读取审计payload。cal/held-out不读取，不新增GT。

## 标注、选择与控制

- 标注L128、实际K100完整返回；K1命中从其首返回获得，依据同一kernel只有输出循环依赖K的源码事实，并对预定16查询×前2动作实际K1核验ID/距离bits/NDC相等。该复用只用于训练标签；审计K1、K100均实际调用各自K。
- 每动作两次单线程plain搜索，轮换动作顺序，独立count pass全量核对ID/距离bits、三个初始化ID，保存全部返回和NDC。plain单次计时只标注搜索成本，不称为线上QPS，计数pass不参与成本标签。
- 每动作在两个选择半集分别至少8条受影响查询。分别要求K1、K100平均增量均不负，且二者等权平均增量严格正；不靠混合奖励隐藏某K退化。
- 主候选Cost要求两个半集配对平均搜索时间变化也均不正；控制RecallControl采用相同规则但不加时间条件。按两半较小等权召回净增量排序，每槽最多一个替换、全局新ID互异、最多16个槽位；同分按旧ID、新ID。0编辑也如实保留，不能临时降门。
- 选择只用提议/标注角色；不按审计挑模型。多个编辑最终一起调用原搜索，不能把单动作增量相加当效果。两控制同时冻结并保留，Cost是预指定主候选。

## 审计与进退

- L128先实际对默认、Cost、RecallControl测K1/K100，全部4096条、CPU15、OpenMP/BLAS/MKL线程1，方法串行，每点预热一次、3轮完整plain wall、独立count。wall包括原小图、映射/升序、主搜索和正常输出写入，排除GT/验证/计数/I/O/装载。轮换方法顺序，不与训练并发。
- 全量恢复E105默认同K/L的返回ID、距离bits、真实入口和NDC。main候选报告4个dataset×K配对召回差及98.75%区间、K1救回/损伤和K100零命中变化，3轮QPS全部保留。
- 仅当Cost在两集两个K召回点估计均不负、每集至少一个K的校正区间下界为正，且每个点平均完整QPS不降，才进入冻结同模型的K1 L64/128/256/400/800、K100 L128/256/400/800比较。L128即使负也完成上述小规模wall，不把一个预算的正值称为完整前沿改善。
- 主门失败就停止本版，不追加候选、阈值、slot数量、seed、网络、HNSW参数或只选一集继续。性能和统计无结论时也不当作方法成功；完成规定试验并报告负/不确定结果即完成本次测试请求。

## 预算与身份

总上限3M真实主搜索、搜索控制器2小时、单进程40GiB RSS、至少6GiB空闲盘；无新底图/小图/GT/神经训练。所有计时串行单线程；仅编译和离线统计使用已有工具。候选/模型/源/二进制与输入hash按阶段冻结。原生大索引沿用已验证SHA来源并核验size/mtime和base抽样字节，不假装本轮重新hash过全库。所有失败日志保留，不覆盖历史结果。
