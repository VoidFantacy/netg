# E117：同次实际GT10路由的四动作入口集合试验

2026-09-20，用户“试试”授权。依据[理论复盘](../20260920_post_e116_theory_v1/report.md)，独立版本，既有E116和所有停止runner不恢复。协议在标签/训练/接受前冻结。只改传入原主搜索的真实入口集合，底图、base、raw-IP、GT、GT10画像/原小图、ef10、kernel及L/停止规则不变。

## 动作与在线信息

一次原HNSW `searchKnn(q,3)`，保留相同三个成员；按实际返回的画像距离升序、同分真实ID升序定义rank1/2/3。四动作0/1/2/3分别为原三入口/仅rank1/仅rank2/仅rank3。三入口沿用真实ID升序；单入口传一个有效ID，其余存储槽填−1，不改变kernel或fallback，不强制首展开，不追加两入口、C8或其它节点。

六特征固定为画像分数gap12/gap23除以画像三分数L2范数、真实入口raw-IP gap12/gap13/gap23除以其三分数L2范数，以及raw-IP最优入口的画像rank(0/1/2)。分母加1e−12。画像分数从原heap取1−distance；真实入口分数由原NSG storage DC取负距离，付出额外3次点积。真实分数同分按ID确定rank。没有GT/节点身份/主搜索中间结果特征。新增排名保留不得改变小图成员/访问，逐query与原Router核验。

## 数据角色和标签

每集继承E24 fit20K的固定源序。positions[0:10000]训练，positions[15904:20000]接受4096条；对应原router source rows[10000:20000]、[25904:30000]。中间5904不使用，不按结果选query。全部源query为历史开发材料，原GT10画像还曾使用这些query，故接受只是不参与本版选择器拟合，并非项目盲测或画像未见query。核验唯一query字节与角色互斥；两集模型冻结后才物化/打开接受载荷。E105那批4096不进入本版数据。0新GT/图，未曝光held-out不读取。

实际标签只在训练10000生成：L128/K100四种真实入口动作。K1取同L首返回，仅在实际K1调用与原E99链接内核验收后用于训练；接受阶段K1/K100均分别实际调用。保存完整返回ID/距离bits、四动作NDC/入口/实际路由排名与分数、六特征。

成本标签共五个计时变体：原GT10无特征；Feature3计算六特征后仍用原三入口；三个single变体都计算六特征。质量只有四种动作。四次plain重复，按256-query块遍历，每块以(rep+block)模5轮换五变体顺序，各变体先完成整块query；不逐query连续执行所有动作。每次标签时间覆盖路由、特征、动作初始化和原搜索；GT/验证/输出写盘在外。成本预测用Feature3/single时间减无特征GT10时间；后续树判断/完整输出的实际总开销以整批wall验收，标签不能替代QPS。五变体每query均核验重复返回一致，count分支独立。

## 三个固定浅树与常数控制

动作效用训练目标：`u=0.5*ΔR1+0.5*ΔR100−λ*(t_action−t_GT10)/mean_fit(t_GT10)`。主CostTree λ=0.1；RecallTree λ=0。ShuffledTree按固定seed20260920一次排列query的完整四动作标签向量（两K/时间一起），特征不动，同主训练。只有这三棵树/数据集，不调λ/seed/特征/深度。

最大深度2、每叶至少512条。每个节点枚举六特征在该节点query上0.1..0.9分位数阈值（只由X形成），叶动作取该叶经验u总和最大，ties动作0优先。每节点选两个子叶总u最大的分裂，仅严格改善时分裂，再对两个孩子按同规则至深度2。这是固定贪心policy tree训练，不是全深度2全局最优保证。阈值和叶动作只在fit学习，不以接受结果选超参数；不会把四动作行当4n独立query。叶中另存各动作R1/R100/时间均值、支持与非零事件，预测收益不等于校准保证。

FixedBest仅按fit等K平均真实召回，从四固定动作中选最强，ties依次0/1/2/3，双集接受前冻结。接受仍全部展示GT10/Single1/Single2/Single3；Feature3是纯特征成本控制，CostTree为唯一主候选，其余模型不凭接受结果晋升。即使fit约束失败或树退化常数，也完整保存并进入约定接受比较，不把零动作称成功。

## 接受与主门

八方法×两K×两集=32点，L128；每点warmup+3轮轮换plain整批wall+独立count。CPU15、进程/OMP/BLAS/MKL线程1，方法和数据集串行。计时包含实际路由、需要的3点积/特征、树判断、入口构造、原搜索及返回写内存；不使用缓存入口/动作，不开count/GT/I/O。原三入口与同query旧E116基线完整ID/距离bits/入口/NDC恢复；所有方法plain/count/parity；Python/C++动作、特征及缓存四动作返回核验。

逐query独立GT评分，报告Recall@1/100、QPS三轮及N/平均wall、零命中救回/新增、非零增损、选择分布。实际K1/K100的首返回/入口/NDC逐位检查。原有源标签以同样GT核对，不生成新GT。

唯一主门：CostTree相对GT10及训练冻结FixedBest的四项K/数据均值召回均不降；每数据对两个参照的等K平均召回差，配对query bootstrap20000次，四个比较的98.75%双侧区间下界都>0；相对GT10及FixedBest四项平均完整QPS均不降；每数据CostTree的等K平均召回不低于ShuffledTree。全部条件同时满足才进入条件完整预算：冻结CostTree/GT10/FixedBest，K1 L64/128/256/400/800，K100 L128/256/400/800，L128复用本轮原测。条件阶段不再训练/选模型。若失败，停止本版，不扫阈值、λ、候选或seed，不用接受失败query拟合。bootstrap为历史开发条件下的描述性区间，不构成全项目独立泛化证明；无论结果都不自动替换生产默认。
