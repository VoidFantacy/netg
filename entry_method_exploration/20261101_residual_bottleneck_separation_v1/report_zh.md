## 1. 主线怎样更正并落实

原设计将学习强入口列为主线，现改成三个可分辨的问题：候选内有没有好入口、部署信息能否识别、路径限制/初始化方式是否是瓶颈。单点GT最好不证明可学习，零增量不等于永久坏节点，提前入口会改变初始集合与轨迹，不能简单归因于时机。

离线前8K合法query编独立Q8-B32，后8K固定2048入口fit/1024 cal；新表与选择器角色分离、排除完全相同向量。COCO/Flickr身份组跨新表/fit/cal及公共测试交集均0。旧GT10画像监督重叠披露；其余五集按原角色与行/向量身份核验，不声称语义IID。旧16K B32保留强参考，模型在Q8上训练/校准后固定迁移FULL，不冒称在FULL上重新校准过。

先生成全C、真实K1/K100、L200/384的实际单seed标签，比较24维ridge与104维固定128轮HGB；按合法cal选择模型/拒绝阈值。公共新响应前冻结所有模型、预算、控制和停止边界，未按正式质量调参或追加到通过。L100/400和完整16K表均为冻结迁移，未在相应状态重新拟合/校准；这些位置失效不能当成该状态下的可学习上限。

## 2. 旧方法与本轮动作的具体区别

| 方法 | 入口/答案选择 | 本轮隔离了什么 |
| --- | --- | --- |
| M5/B32 | 训练遗漏编直接候选，原metric精算合并 | 继续保留答案价值，旧16K OPT-B32为强控制 |
| E174/E195 DIST | 逐路由行query-best最多3个seed | 保留REF-DIST384；新增DIST1/FULL匹配单入口数量 |
| E195 NOVEL/REP | 未访问邻居数/静态度数代表 | 不把度数/密度当准入证书；本轮按真实搜索标签识别 |
| MODEL1 / MODEL-FULL | 每query全C预测净增量，选一个seed | 与距离单seed同池/同预算比较；FULL为固定模型迁移 |
| MODEL-GATE / FULL | 保留直接C，按冻结阈值允许不展开 | 核验每query完整包严格等于全开或直接返回 |
| CBRIDGE / SHARED | 放开未选C或主评分未展开中间点 | 同适配层AUX384-FAST作控制，捕获空动作另测 |
| EARLY-MIX / ALL | 仅用预先可用路由/残差表替换初始化入口 | 保持最多3入口合同；报告救回与损伤，不冒称同状态注入 |
| E193 / 旧Atlas | 固定SQ整体开关/几何top8局部平均效用 | 当前是残差后置seed识别和执行干预，仍不代表所有学习器 |


完整C直接答案始终保留。种子来自已评分C或已付主评分集合，本轮没有新增独立代表精算；辅助新增来自后续路径。SHARED是保存实际分数后的独立辅助队列，原生产search_new没有完整pause/resume。GNN、组合教师、多个学习导航代表、修图均未在本轮实现。

## 10. 实际费用与实现核验


| 阶段 | 实际费用/规模 | 解释 |
| --- | --- | --- |
| 入口标签 | 672.13秒 | 实际单seed搜索，离线；不能当query QPS |
| 模型拟合进程 | 117.40秒 | 含失败系统Python启动；不以训练费否决 |
| 旧捕获cal v1 | 952点 / 1851.01批次wall秒 | 原件保留，不混入正式QPS |
| 精简捕获cal v2 | 1120点 / 2120.89批次wall秒 | 事前选择费用邻近预算 |
| 正式完整T1 | 9434点 / 28302批 / 16018.96秒 | 正常完整batch生命周期 |
| 候选/路径教师诊断 | 1191.01秒 | GT特权、非部署、非正式QPS |
| 新增GT/主图构建 | 0 | 沿用原base/metric/GT/图，不重置历史投入 |


费用是嵌套口径：正式batch wall已包含在native进程时间内，整个public pipeline还包含诊断/归档/校验；不能相加称完整项目成本。全部查询比较CPU15、实际T1、库线程1、单方法串行，无并发训练/编译/其他性能任务。正常路由/主搜/C精算、状态保存、模型/选择、扩展、严格合并、输出分配/复制/销毁均计wall。加载、GT、hash、写盘和oracle在wall外。

首窗详细证据量触发存储峰值保护：COCO B一次运行在286.94秒停止，原始文件完整无损保留；随后复制24,856文件并逐一核对SHA/mtime，固定点表完整重跑B，不混入中断点。COCO A输出原在磁盘，其后输出在RAM暂存，均在query wall之外；比较以各同窗口共同条件为准，不把存储介质变化归为算法收益。所有新证据最后无损压缩并持久化，旧科学原件不动。中断实际进程费计入成本账；重启后的pipeline outer只覆盖最后一次调用，不冒称全程日历时长。[存储迁移](reviews/storage_RAM_staging.json)、[持久化证明](reviews/persistent_storage_delivery.json)。

关机后的恢复与GIST新测均逐窗验证并持久化后才进入下一窗。[恢复资格](reviews/recovery_qualification.json)、[恢复完成](reviews/reboot_recovery_complete.json)、[存储修正](storage_amendment_20261102.md)分别保存依据。已完成11窗的原计时不由恢复速度替代；原生恢复进程费用另列。旧GIST关机中断仅能从日志给出已观察时长下界，完整进程时长记未知。原日志中的已完成正式批次计时、恢复新增费用和这段未知费用分开，不称完整项目总耗时。

本轮主分析核验9434个点的三轮六数组hash，2768568条候选witness的ID/float字节与全排序，5403128条诊断探针的GT hit-mask救损和教师选择。原持久/新测/哈希恢复身份按前文区分，恢复窗候选与动作证据为重放来源。旧实际包对齐728点。14个选定模型的native/Python推断逐训练标签行检查；另对正式query重新无GT提取可用特征，核对7419518行推断及85728组全开/拒绝导出ID。恢复窗的该项证明对应重放入口，不声称原丢失seed文件独立字节身份。拒绝输出逐query核成全开或直接分支，FULL模型增量不超过同池单seed教师，两个Q8教师输出精确等于离线预期。

第二份std-lib实现独立核9434点/28302批的GT整数、包hash、wall/费用覆盖、全部训练标签结构与原始query/GT行转换。它不导入主分析/NumPy；属于同执行者不同实现，不是独立人员审查，也未重跑所有图标签或独立bootstrap。详见[主核验](analysis/analysis_receipt.json)、[std-lib核验](analysis/stdlib_audit.json)、[成本账](analysis/cost_ledger.json)。
