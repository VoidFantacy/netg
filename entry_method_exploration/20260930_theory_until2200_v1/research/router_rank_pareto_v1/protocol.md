# 原路由状态与查询相对入口：目标预算联合收益证伪

2026-09-30，读取本版逐查询反馈、拟合或启动搜索前冻结。用户今日授权理论、论文与小实验，并明确重点为完整QPS与Recall综合改善。本版承接这一授权；不依旧提案的历史待授权措辞重复索取许可。旧结果与门保持。

## 唯一问题及实质区别

固定原GT10小图上层结束节点z，是否能将**这条查询实际返回的rank1/2/3单入口**相对默认三入口的目标预算召回与时间差，归并成可迁移、足够便宜的四动作规则？E121已检验z→全H中的固定真实ID；本版为z→查询相对rank。两类策略不包含对方：同一z内rank对应的真实ID可随query变化；任意固定ID也可能不在本条query的top3。此区别形成可反驳假设，不构成新颖性或收益证明。

E117有相同四动作与六关系特征，但主要监督L128；E126曾提出相对rank表而没有目标预算与完整成本。E136的256-query目标预算记录显示Web K1四动作oracle余量0、其他格很小，故本版也可能只关闭该缺口。E120/E125的TargetKNN同时有信息与完整成本问题，不作为本版主方法或教师。

## 冻结输入、角色与动作

- 两集各E118历史fit4096，原source positions [2048,6144)，原query/GT100字节。E117 fit10000中的对应行提供原排名和六特征；E121提供已有z和四折角色。逐query字节、source行、图/画像/ID及排名成员关系须全部一致。
- 采用E121原四折：每折3072拟合、1024查询外评分；所有4096均是历史曝光开发数据。既有E136抽样256也在其中，不能称未见测试。今日157的新来源不参与本版，held-out不访问。
- 动作0为原默认三入口联合搜索；1/2/3为原路由按(distance, real-ID)升序排名的对应单入口。入口0按真实ID排序，单入口保持原核语义。完整原路由仍全部执行，ef10、top3、原排序和tie不变。
- 固定工作点：Web K1/L1000、K100/L1250；Yandex K1/L128、K100/L256。每个K独立拟合与评价，不能以等K平均掩盖损伤。不增加L、动作、阈值、状态层、特征或种子。
- 原raw-IP/base/底图/画像/小图/生产E99和主搜索核保持。使用E121已审计的searchKnnObserved导出上层状态；不新增主搜索探针、query塔或全H评分。

## 预锁规则：经验召回约束下选更快动作

在每个训练组，对四动作分别统计相对默认的**召回命中整数总差**及完整query时间均值。仅在整数召回总差≥0且平均时间比默认更小时，选择平均时间最小动作；否则默认。时间精确同分按0/1/2/3顺序；空组默认。每K独立，不用任意Recall/时间权重，不加结果驱动的支持阈值。此为经验条件约束，**不是样本外无损证书**；细胞内选择偏差必须由外折和独立wall检验。

四个同监督拟合器固定如下：

1. StatePareto：按z分组，每组一个字节动作。每折、每K各一表，表绑定原图内部ID映射及配置。
2. GlobalPareto：所有训练query一个组，同规则，检验是否只学到固定rank更好。
3. ShufflePareto：使用E121预定训练状态置换，保持训练占用数、破坏对应关系；外折与线上仍使用本query真实z，同规则、同标签。原E121的外折置换不在本版预测中使用，避免把其他query状态缓存当成可部署信息。
4. FeaturePareto：E117原六特征、深度2、min-leaf512、分位点0.1至0.9。每叶用上述同一动作规则；贪心选择使训练总时间进一步下降的有效分裂，按特征/阈值迭代顺序打破同分。不加深、不调参。它是原特征族的固定简单控制；胜过它也不等于超过这六特征的全部函数。

拟合只能读本折训练响应。可共享本版预定全输入特征/状态，不用外折GT、动作反馈来选组/阈值/动作。四折分别产生部署规则，在线按既有折ID使用对应模型；这是开发OOF成本，不是单一最终部署模型。

## 按顺序执行与计量

1. **准备与缓存审计**：不读取旧全H响应做本版选择。核对E117排名/六特征、E121状态、折与E118query身份，保留manifest。已有目标预算四动作仅256行，不充作4096完整监督；Y K1旧全H返回可作一致性参考，旧graph-only费用不冒充本版在线时间。
2. **原生与导出成本**：全4096路由原接口/观察接口的heap ID、distance bits、NDC及旧排名、状态恢复；每工作点默认和强制动作0的状态导出版本各128 warm及3次完整wall，交替次序。强制动作0确实执行byte表查找与排名整理。所有返回ID/距离bits相同，另每动作每K固定前16条原E99/plain/count一致性。先纠错再判断方法。导出费用实测，不预设免费；缺乏可靠毛收益上界时不凭该费用独自宣判信息假设失败。
3. **四动作目标响应**：每点四动作各3次完整query实现的逐query计时，按128-query块轮换动作先后；完整路由/固定动作整理/主搜索/输出写内存在时间内。第一遍保存全部返回ID、距离，重复逐位核对；随后独立用原GT评分。该插桩时间仅是拟合代理，不能拼成候选QPS。所有标签产生后只按冻结规则拟合一次。
4. **固定规则完整wall**：不以拟合代理、信息门或Recall正负跳过速度。默认、强制默认、StatePareto、GlobalPareto、ShufflePareto、FeaturePareto在全4096原顺序分别测每点128 warm、3次完整wall，轮换先后、串行执行。每query在timer内真正跑原路由、状态/规则推理、选入口、原主搜索和输出；不查离线动作表。Feature控制真实支付3个base点积与树遍历；State只付原状态、表访问和rank整理。重复输出、在线动作与冻结模型、所选动作的标签输出全部逐位恢复。可保存动作及输出摘要hash并引用已保存逐动作返回，不重复落盘相同ID/距离。

计时外：GT评分、数组分配、模型/图加载、I/O、对照核验、bootstrap、计数插桩。完整wall不能由逐querylabel时间合成，仍可能有OOF模型切换及cache交互。所有正式查询CPU15，实际进程与OMP/BLAS/MKL线程=1；无并发训练/标签/其他性能作业。

## 预定分析、结束与证据限度

每格报告默认/候选真实Recall、救回/损伤query及质量、完整三次QPS与范围、pooled吞吐；同query配对95%描述bootstrap 10000次，种子2026093025，按原折分层重采样，K同query配对。壁钟三重复不当成独立Recall样本，不从三次wall虚构总体置信区间。报告候选相对所有控制的四格差异、训练与外折差距、动作占比和状态支持；四动作oracle仅诊断，不作为部署收益。

本版没有默认替换门。探索信号需先看各K的效应与区间、两集差异、完整时间及相对控制，而非只看一个平均标量。任何Recall/QPS取舍如实报告；正均值区间跨零记证据不足，不改成已证无效。若State与固定/置换/六特征控制未形成增量或完整费用吃掉收益，本固定状态/rank版本停止；不加状态、trace、支持阈值、深度、L、样本或新seed重跑。正信号也只记录该冻结开发版本，后继另立协议，不自动用新源/held-out追验。
