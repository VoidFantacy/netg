# 近似目标监督保持默认行为的条件链

2026-09-30，纯理论及随后冻结的合成核验。没有新真实数据、训练、搜索或模型。本页补全先前[固定温度推导](theory.md)，不将保真界称为优于默认的性能保证。

## 1. 真正被画像消费的是平均归属

固定H个hub行向量组成矩阵B，目标预处理函数f沿实际unit合同冻结。对目标x和温度T>0，定义z=f(x)/T，p(z)=softmax(Bz)。把一条训练query的K个目标及其温度视为z空间上的均匀经验分布μ，画像消费的权重向量是a(μ)=E_μp(z)。两个不同目标ID可以有完全相同的p；相同目标ID在不同T下则可以有不同p。

定义d(z,z′)=osc(B(z−z′))，以及c(z,z′)=2tanh(d/4)。osc是最大值减最小值，消去所有hub共同的logit平移。d是半范数诱导的伪度量；c保持三角不等式，因为tanh(a+b)≤tanh(a)+tanh(b)，且tanh单调。其零距离关系是B(z−z′)为常数向量，并非必须z=z′。

[Cohen与Fausti，定理5.1、式39](https://arxiv.org/html/2309.02413v2)直接给出||p(z)−p(z′)||₁≤c(z,z′)。论文的TV范数采用L1口径，本页不采用带1/2的概率TV口径。该锐界不是本项目新定理；二分类logit向量(−r/4,r/4)与(r/4,−r/4)达到等号。

对μ、ν的任意耦合π，用相同边缘重新表示均值差，再用三角不等式，可得

    ||a(μ)−a(ν)||₁ ≤ W_{L1(p)}(μ,ν) ≤ W_c(μ,ν)
                        ≤ 2tanh(W_d(μ,ν)/4) ≤ W_d(μ,ν)/2。

最后的tanh界取d最优耦合并用凹性；c最优耦合未必与d最优相同。等K均匀边缘时，最优运输可由一个排列达到；小K可枚举，大K可做指派。**这些是离线比较量，需要两侧目标信息；不是无需精确标签的部署特征。**

这里允许两侧温度不同，因为z已经包含1/T。相同ID匹配只有T相同或投影退化时才一定零代价。与先按固定T分解标签项、再加温度项相比，联合logit式没有忽略交叉作用；但它只是一个上界，不保证比实际误差或分解式更紧。原温度分解的平方交叉项仍然存在，不能被这个记法消除。

若p是hard one-hot，同类目标间运输费0，跨类费2，则W_{L1(p)}恰等于两个完整归属直方图的L1距离。先逐类匹配共同质量即可达到下界。soft下等号通常不成立：在两个hub上，μ的两份概率为(0.9,0.1)/(0.1,0.9)，ν两份均为(0.5,0.5)；均值相同但最小运输费0.8。不能将大的运输上界解释为大的实际权重误差。

## 2. 从权重到归一化画像：必须保留分母

训练query方向u_i和hub先验v_h^0固定，精确/候选合力分别为v_h=v_h^0+Σ_i a_ih u_i、v′_h=v_h+e_h。每条query的权重差δa_i给出

    E=ΔAᵀU，
    ||E||_F ≤ Σ_i ||δa_i||₂ ||u_i||₂ ≤ Σ_i W_c(μ_i,ν_i)||u_i||₂。

该三角界丢弃跨query抵消。画像恢复的真实风险应优先计算实际E及各hub方向，不能只根据每行运输量排序后声称近似最优选样。今天Energy实测已经说明个体误差能量与最终检索收益的连接需要另外验证。

对非零v_h=m_h w_h，分解e_h=α_h w_h+t_h，t_h⊥w_h、r_h=||t_h||。只要v′_h非零，精确弦长平方为

    b_h²=||w′_h−w_h||²
        =2[1−(m_h+α_h)/√((m_h+α_h)²+r_h²)]。

当m_h+α_h>0时，b_h²≤r_h²/(m_h+α_h)²。径向误差通过分母起作用；m_h+α_h<0时，即使切向误差为0也可能完全反向。v′_h=0必须交给实现的零向量合同，不能使用单位向量恒等式。故一个控制总和MSE的无偏估计器，不会自动控制归一化风险。

## 3. 从评分二阶矩到精确top-r集合稳定

对任意给定query分布Q，使用非零query的归一化q，令参考/候选精确分数s=Wq、s′=W′q，S(q)=||s′−s||₂²。参考第r与r+1名分数间隔为m(q)≥0。若两个精确top-r集合不同且m>0，总能找到参考内项i和外项j被倒置，故

    m ≤ (s′_j−s_j)−(s′_i−s_i)，
    m² ≤ 2[(s′_i−s_i)²+(s′_j−s_j)²] ≤ 2S。

因此1[A′≠A]≤min(1,2S/m²)；m=0时使用平凡上界1。固定ID并列规则能定义集合，但不能将零间隔除掉。该关系不需要训练/测试独立；它对固定查询集合的经验分布也逐项成立。

D_Q=E_Q S=tr(ΔW C_Q ΔWᵀ)，其中C_Q=E_Q[qqᵀ]是未中心化二阶矩。对任意τ>0，拆开小间隔与其余query，再用Markov界，得到

    P_Q(A′≠A) ≤ F_Q(τ)+2D_Q/τ²，F_Q(τ)=P_Q(m≤τ)。

这个式子使评分均方误差和间隔分布同时出现。若另有F_Q(τ)≤Cτ^α（C>0、α>0，仅在0<τ≤τ₀成立），可取τ*=(4D_Q/(αC))^{1/(α+2)}，前提τ*≤τ₀，得到

    P_Q(A′≠A) ≤ min{1,(1+α/2) C [4D_Q/(αC)]^{α/(α+2)}}。

D_Q=0时评分相同，固定tie规则下集合相同，直接处理。若零间隔有正质量，不能假设上面的无常数项幂律。C、α和分布迁移都不是当前数据已经证明的事实；本页不拟合这些参数，也不将它写成真实泛化速率。

间隔条件连接回归误差与决策误差已有成熟前作，例如[Audibert与Tsybakov，2007](https://imagine.enpc.fr/~audibert/AudTsy_AOS0231.pdf)。其对象是分类的超额Bayes风险；这里给的是固定参考top-r集合不一致率，公式由上面的集合倒置与Markov直接推出，不借用其指数或分类一致性结论。

## 4. 到实际路由和有限搜索还差两个事件

令R、R′为两个物理小图实际返回并按真实ID排序的入口集合，A、A′为各自数学精确top-r。定义η=P(R≠A)、η′=P(R′≠A′)。不要求这三类事件独立，集合并集界给出

    P(R′≠R) ≤ min{1,P(A′≠A)+η+η′}。

η和η′必须分别属于各自的画像、图及路由实现；重新构图后不能沿用旧η。即使ΔW=0，只要物理图或实现改变，也不能不经核验就令两个实际路由相同。相反，η较大并不证明两套路由彼此差异大，这个上界可能完全无信息。

固定query、底图、主搜索kernel、K/L、初始状态以及canonical完整入口时，实际入口相同就给出相同NSG结果。因Recall取值在[0,1]，所以

    |E_Q Recall′_K−E_Q Recall_K| ≤ E_Q|Recall′_K−Recall_K|
                                  ≤ P_Q(R′≠R)。

这闭合的是“对既有默认行为的绝对偏差”条件链。没有任何一步给出收益符号，也没有保证主搜索入口变化一定改变返回；今天已核实入口变化大部分被主搜索吸收。数学理想分数还须加浮点误差/并列合同，才能谈原生实现认证。

## 5. 为什么不能据此直接改方法

提高教师目标ID召回，未必减少实际平均归属误差；减少平均归属误差，未必减少每个hub的方向误差；减少总评分风险，未必减少小间隔query的决策错误。即使所有误差都变小，这条链仍只支持接近参考策略，不支持超过它的Recall。

完整费用也没有被界住：取得目标、计算运输/评分诊断、构图、路由、主搜索和输出都需计入各自阶段。相同入口可复用确定性主搜索行为的逻辑，不可复用另一个方法的完整wall。应保留已经测得的低构建成本/小质量取舍候选，而不是把这份推导改名为新最优运输路由器。

本页用于论文的机制解释和误差合同；全部通用工具都有前作，系统改进主张仍需独立的完整成本与真实质量证据。
