# 从画像方向到有限预算搜索：能证明什么

本页的目的不是把方向误差包装成Recall保证，而是给出可核验的连接条件，并定位下一步应观察的误差。当前H、底图、主搜索和L固定。画像估计、近似小图路由、联合入口主搜索是三个不同环节。

## 1. 方向误差必须经过分数间隔

令s_h(q)=q̂ᵀw_h，候选分数s'_h=q̂ᵀw'_h，q̂为单位query，ε_h=||w'_h−w_h||。Cauchy–Schwarz给出|s'_h−s_h|≤ε_h。若A是原分数的精确top3，且

    min_{h∈A}(s_h−ε_h) > max_{j∉A}(s_j+ε_j)，

则候选精确top3仍是A。证明是任意原内外对的分数次序均不会倒置。用实际|q̂ᵀ(w'_h−w_h)|替代范数可得更紧的事后证书，但后者需要计算候选分数，不能称免费线上判定。

所有hub平均弦长MSE变小不推出每个ε_h变小；即使逐hub范数变小，也未必令每条query的分数误差朝有利方向变化。实际起作用的是竞争入口对、query协方差和小间隔查询。可比较Σ_h Δw_hᵀΣ_QΔw_h与均匀方向误差，但这是分数风险，仍未成为搜索效用。

## 2. 精确排序稳定仍不保证原Micro-HNSW稳定

令A/A'为两套W的精确top3，R/R'为各自物理小图ef10返回并按真实ID排序的三入口。逐query集合逻辑给出

    1[R≠R'] ≤ 1[A≠A'] + 1[R≠A] + 1[R'≠A']。

这是并集界，不需要独立性；只说明必须计入两个近似路由误差事件，不能把它们忽略。重建小图会改变边，两个路由误差还可能抵消或放大分数变化。数学精确排序与native浮点排序需分开：诊断使用原float32 W/query转float64评分，并标注3/4名间隔接近保守浮点舍入包络的行。

## 3. 相同入口是主搜索不变的充分条件

本项目非GATE路由在注入前按真实ID排序。因此相同三入口集合意味着相同有序输入。固定query、底图、kernel、L、线程和初始visited状态后，主搜索确定性地给出相同返回、距离bits和graph NDC。可以逐行验证，且有

    |Recall_K(R')−Recall_K(R)| ≤ 1[R'≠R]。

相同入口不保证相同完整wall：小图路径/距离计算和缓存费用可以不同。不同入口也不说明返回会变，许多不同入口会进入相同搜索区域。统计须同时报告入口变化、实际返回变化、救回/损伤和完整wall。

## 4. 路径存在与有限beam实际选择之间还有缺口

[Oguri与Matsui 2024](https://arxiv.org/abs/2402.04713)的§3.3、§4讨论k-means真实候选和B-MSNET下的路径跳数上界；适用条件含图路径性质及区域几何。它比较的是上界，并不自动给出本项目raw-IP、画像分数、有限L多入口算法的Recall或完整QPS保证。上界中若最小非负前进量为零，不能未经补充条件视作有限数值界。本次已读原文v1的本地留存及来源清单。

一个强连通有向图即可反驳“入口离目标更近一定更好”：较近入口通向一串高分诱饵，再通向一个低分桥点；较远入口经另一路直接到目标。有限beam可丢弃桥点，因此近入口失败而远入口成功。在远入口旁增加近入口还可能先用诱饵挤掉远入口，说明多入口集合包含不提供单调Recall保证。这是有限beam的一般边界，不证明当前NSG经常发生该模式；将以当前原生kernel运行固定合成图核验，不更改生产图。

## 5. 改进依据应该落到哪里

GT10方向目标和真实搜索收益不同。如果用可加画像评分代替真实入口集合效用，必须额外控制代理误差；E123/E124已说明有价值的特权教师和更低代理MSE也可能不能改善实际选择。本轮先用固定模型分解“画像分数改变 / 近似路由改变 / 主搜索吸收”，不根据这些已曝光查询重加权训练或扫描候选。

可落地的下一问题是：低成本目标替换能否保留对实际搜索重要的入口决策，同时减少完整离线费用。若只改善几何而没有稳定质量恢复，应保留成本取舍边界，不再用同批性能微调m、温度或收缩系数。
