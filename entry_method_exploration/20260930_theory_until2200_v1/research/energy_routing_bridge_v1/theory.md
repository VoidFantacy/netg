# 可对齐的四层变化与精确计数

令A为全H数学精确top3、R为原小图实际返回三入口、O_K为固定主搜索的返回ID集合、H_K=O_K∩GT_K。K1只以精确top1为GT。上标撇号表示另一个固定模型。实际注入按真实ID排序，故R=R′蕴含O_K=O′_K；本阶段还核验完整顺序、距离bits和主NDC。

对每query定义g=|H′_K\H_K|、l=|H_K\H′_K|、d=g−l。绝对Recall差满足

    |mean(d)/K| ≤ mean(|d|)/K ≤ mean(g+l)/K，
    |d|/K ≤ 1[H′_K≠H_K] ≤ 1[O′_K≠O_K] ≤ 1[R′≠R]。

其中g+l可能大于K，但|d|不会；不要将第一行的成员对称差当成更紧的概率界。总救回与总损伤分别为Σg和Σl；Σmax(d,0)和Σmax(−d,0)只累计每query的净改善／净损伤。它们之差一样，但前一对各自多出Σmin(g,l)。K1时不能同query同时救回和损伤，二者相同；K100时需要区分。

定义c=2·1[A′≠A]+1[R′≠R]，四格互斥且穷尽。d的各格总和恢复全体ΔRecall；c=0与2的实际入口相同，所有d都应为0。c=1允许精确排名相同但近似路径产生入口差异，c=3允许两者同时变化；这样的分组不等于干预小图拓扑，不能把差值因果归给构图。

若S(q)=||ΔW q̂||²，则E_nS=tr(ΔW C_Q ΔWᵀ)，C_Q=n⁻¹Σq̂q̂ᵀ为未中心化二阶矩。精确top3改变需要原内外至少一对分数发生逆序，因此原3/4间隔m>0时1[A′≠A]≤min(1,2S/m²)。这只是变化频率的上界；它既不决定变化的收益符号，也不免除两个近似路由误差事件。完整条件与数值注意见145后补理论。

本诊断可以解释改善为何没有等比例传递，但不能证明低画像误差的模型必然有更高Recall。没有新增在线计算，所有全H分数只用于离线解释。
