# E37：真实 HNSW→NSG 反馈的离线画像优化

2026-09-12。用户在区分 E36 在线换点与离线构图/画像训练后明确回复“可以，推进吧”。本版本执行离线画像学习、成对扰动控制、静态索引导出和真实单线程评测。原 NSG/base/raw-IP、H815/821 与真实入口映射不变；不更换默认、不访问 validation/held-out、不重启旧实验。

## 研究问题和历史差异

E28 学全 H 教师代理目标；E32 直接奖励但训练/部署局限在旧 C8；E33 只删固定画像图的原边；E36 在线计算组合模型。本版本每个候选画像都实际重建原参数的小 HNSW，由其 direct top3 进入原 NSG 获得反馈，不使用固定 C8、全 H oracle 或近似监督替代实际部署决策。

RL 明确定义为一次构造动作的 Gaussian 参数策略（one-step policy search），不是多步 PPO/在线路由策略。策略采样整份静态画像参数，一份图服务同一批查询；训练后部署确定的均值参数。成对扰动 ES 使用同参数化、同目标、同样本批次、同更新/构图/真实调用预算。两者同属高斯平滑黑箱目标，区别主要是梯度估计和方差控制，不能称为完全不同的模型族。

## 参数化与构图

锚点为当前 WebVid GT10-soft-t1 / Yandex GT10-hard。只用本轮 train4096 的单位 query 二阶矩取前16个正交方向 B(d×16)，特征向量按绝对值最大坐标为正定符号；没有秩搜索，不声称16最优。固定 PB=P B。

令动作 X∈R^(16×16)，A=tanh(X)/4，W=normalize(P+0.25(PB)A Bᵀ)，float64生成、float32导出；X全零时直接复制原P字节，另验收重归一化数值差。限制均值 μ 在[-2,2]；每个动作 X=μ+0.3ε，ε为标准高斯，采样动作不裁剪，tanh提供有界输出。

每份 W 从零构建 HNSW，M16/efConstruction200/seed20260828/原映射插入顺序/efSearch10。无独立删边/换边动作，原始 query 不变，HNSW一次返回3个唯一真实ID，升序进入原 NSG L128/K10。图的拓扑会随画像重建而变化；最终大图保持冻结。记录每次 W SHA256、层级/入口/全部有序邻接的SHA256、构图次数与时间。

## 数据与奖励

原 E24 fit20K 以 PCG64 seed20260912 排列取4096 train和1024 monitor，其余不用。每次训练相同固定train前512作为曲线诊断；B仅train生成。cal/audit沿用各自历史1024，模型全部训练冻结后才准备cal、按cal选seed冻结后才准备audit。四部分源行互斥；所有源数据均有历史使用，P本身来自历史fit，**非全管线盲测**。本轮不读取或hash validation/held-out原始输入。

每个候选都运行真实小HNSW及原NSG，C++不读取GT。Python在返回后按GT10集合交集评分。每query

U = hits−hits₀ −0.1(totalNDC/totalNDC₀−1) −0.1(1[hits=0]−1[hits₀=0])。

候选奖励为批均U−mean_h||W_h−P_h||²。原GT10基线按相同行一次计算并核验。旧三元组标签复用0；每次查询实际执行，不把未知组合当零标签。单入口收益不相加。NDC用于低噪声训练约束，最终五轮完整wall另测，NDC不是时间。

## 两臂训练与冻结

两集×RL/ES×seed20260921/20260922，共8次。每次200次更新、每步8份画像×同128个无放回train查询。RL八个独立ε，使用其余七个候选奖励的均值为leave-one-out baseline；gradient=mean((R_i−b_i)ε_i)/0.3。ES四个独立方向及其负方向，gradient=mean((R+−R−)ε)/(2×0.3)。两者Adam上升，β1=.9/β2=.999/eps1e−8，梯度L2裁剪1，lr从.03 cosine到.003，μ逐元素限[-2,2]，不按结果加步数或改σ。

step0及20..200，评测确定性μ的train512/monitor1024，保存完整真实结果。checkpoint只在非零更新点中选择monitor meanU最高且graphNDC≤基线+1%的最早点；若全部不可行，保存最高U已训练点并标记成本门失败。选中与末点单独导出W和物理HNSW，未训练锚点始终独立列示。cal按meanU选各臂seed（同分更低总NDC、再较小seed）；audit不改选。

开发门预定：主RL每集cal ΔR≥0.10pp、audit ΔR>0、总NDC≤+1%，并报告对ES的配对区间及全部seed。门只决定后续研究判断；无论正负均完成下面预定的历史audit成本/曲线，不能用结果放宽门。

## 真实部署与完整成本

复用已验收、无训练hook的E34评测binary，原NSG/Fast30K/当前GT10/主RL/主ES，共两集50点，L64/128/256/400/800，audit1024。每点完整warmup一次、五轮轮换独立plain wall，count/原kernel16行核验在timer外。L128另测route-only/graph-only，不相加成全wall。所有方法CPU15/进程及OMP/OpenBLAS/MKL1线程、串行且无并发训练或重分析。Fast30K的历史训练量/seed另列，不把其差别归给本轮。

保存完整Recall/QPS/失败率、配对挽救/新增失败、图/路由NDC、五轮原始wall。不同L必须同一模型/微型图/入口。原始非支配曲线与共同区间log-QPS插值分开，插值不是新测点。历史audit曲线不升级为独立正式性能GO。

## 预算与执行保护

真实NSG硬上限2,800,000，正常预估约2.20M，余量仅修复/验收不扩网格；每个job启动前完整预留，失败预留不释放。8次优化共1600更新/12800份采样画像，中心评测构图另计。构图硬上限15000，0新GT。每个训练进程≤7200s、总训练进程≤14400s；单正式评测≤1800s；RSS32GiB，产物≤600MiB、余盘≥10GiB。数据集和方法均串行。

训练仅保存系数、全部动作/奖励/返回/计数及图身份，不保存12800份重复大画像；相同构图可由冻结系数、B、代码重建。选中/末点的W和图永久保留。独立版本内无冻结输出覆盖；临时计算对象只在内存，原工作区/旧源/图/标签/模型保持。
