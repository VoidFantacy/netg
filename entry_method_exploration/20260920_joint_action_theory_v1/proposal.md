## 1. 改变推进方式

此前连续诊断已确认很多局部现象，却没有收敛到具有明确干预对象的方案。后继不应再把解释更多失败当成方法进展。本方案只选择一个改变：**把线上路由的对象由单个hub改为一整组三个真实入口，并直接预测这组动作相对现有GT10的实际召回增量。**

固定大图、真实H、raw-IP、原搜索内核、最多三个入口。新变量是一个小型完整动作库及其路由分数。每次查询仍只执行一次原NSG。

理论支持分为三部分：完整动作解除单hub分数之间的部分约束；真实收益的动作库选择有标准次模近似保证；实际部署收益有直接的误差界。后两项分别约束经验oracle覆盖和给定分布下的策略收益，不能互相替代。

## 3. 方法定义

先固定一个真实K、L以及完整数据/图/kernel/并列规则。以下推导分别适用于K1和K100，不能把两者平均提升说成分别提升；改变L也必须重新说明标签和保证范围。

令S0(q)为原GT10实际ANN三入口，R0(q)为它经原NSG得到的Recall。一个动作a保存三个互异、合法的real ID，按原canonical顺序传入搜索；R(q,a)必须由这三个入口共同执行原NSG得到。

定义实际增量：

`Delta(q,a) = R(q,a) - R0(q)`，以及`Delta(q,0)=0`。

动作0的意思是调用原GT10完整流程，不是某个固定三元组。负增量完整保留。不能用三个single返回的并集、区域覆盖或教师ID准确率代替Delta。

### 离线

1. **提出有限完整动作池C。** 只从训练侧的合法完整三入口提出候选；可复用兼容的既有C8真实标签提出动作。提出动作所用query与后续拟合/接受角色分开。每个动作的三个ID冻结后不再自由重映射。不能由E105最终坏例挑动作。
2. **形成稠密、同身份的query×动作增量矩阵。** 对所用训练行，每个保留候选都须有真实共同搜索响应；未知项不可补零。历史C8标签只覆盖某query的局部组合，不自动提供全局动作池对其他query的标签。
3. **压缩成小动作库D。** 用第5节的真实正增量覆盖目标贪心选固定数量的动作。选择阶段与模型拟合阶段的来源和实际成本分账；不能以动作库oracle通过代替策略通过。
4. **冻结D，拟合每个动作相对GT10的增量。** 首版使用`f_a(q)=w_a^T x(q)+b_a`，其中`x(q)=unit(q)`仅用于路由；原raw query仍进NSG。用完整有符号Delta做岭回归，不训练query网络，不拟合唯一teacher ID。
5. **保留动作0及固定拒绝规则。** 只有最大预测增量超过预先指定的非负阈值tau才用新动作，否则用原GT10。tau不是已知逐query误差上界，fallback自身不保证实际不退化。

训练目标为：

`min_(W,b) sum_(i,a) (w_a^T x_i + b_a - Delta_ia)^2 / (n M) + lambda ||W||_F^2`。

固定D和lambda后，这是凸问题，可用线性代数求解；bias单独处理。全矩阵中的小MSE仍不自动控制最大动作误差，不以训练loss下降宣称召回提高。固定动作和每列完整监督旨在减少自由重映射、未知动作和优化不确定性，不能消除统计误差。

K1、K100分别拟合增量分数；动作库可以分别建立并计成本，不能以等权teacher掩盖某一K损伤。第一版理论锚定L128，固定导出模型跨L使用；理论界不能未经验证扩展到全部预算。

### 在线

```text
x = unit(raw_query)
a = argmax over the fixed action bank of f_a(x)
if f_a(x) > tau:
    entries = frozen_three_real_IDs[a]
else:
    entries = original_GT10_router(raw_query)
return original_NSG(raw_query, entries, K, L)
```

建议首版把部署库固定为64个动作，精确计算64个线性分数。64是一个有界、可检查的初始工程选择，不是理论最优容量；若覆盖不足，不自动扩库调参。这样没有新小图构建和ANN选错项，也不在线枚举三元组。512维的64个float32权重约128KiB，每次约32768个乘加，另有归一化/bias/argmax；这些是运算量，不是已测wall。

回退query需支付新评分加旧GT10路由，但仍只有一次主搜索；不能把新评分开销忽略。若未来改用ANN动作索引，必须另加实际动作选择误差，不能继承本版精确路由保证。

## 4. 一个可证明的表示区别，以及它不能证明什么

取四个二维query `(1,1),(1,-1),(-1,1),(-1,-1)`，希望依次输出四个完整动作：

`{a,b,c}, {a,d,e}, {a,d,f}, {a,b,g}`。

假设每hub一个仿射分数，且目标集合与非成员之间严格分离。前后两query必须满足`score_b > score_d`，中间两query必须满足相反不等式。差函数为`v^T q + c`。前后两query求和给`2c>0`，中间两query求和给`2c<0`，矛盾。

若四个完整动作各有独立key，分别取四个query方向作为key，则每个query对自己的动作内积为2，对另三个为0、0、-2，能直接得到全部目标集合。

因此存在完整动作线性路由可表达、单hub线性top3不可表达的映射。**这是决策类的代数例子，不是当前NSG真实最优三入口呈现该模式的证据，也不是全部模型之间的包含定理。** 非线性query模型或多画像也可能表达它；E36已经有非加性集合评分。提出此例是说明本方案改变了哪些约束，不是宣称找到了E105失败的唯一原因。

## 5. 动作库怎样有理论依据地保留改进空间

对一份完整测得的训练矩阵，定义

`Fhat(D) = (1/n) sum_i max(0, max_(a in D) Delta(q_i,a))`，`Fhat(empty)=0`。

它是知道每条query最佳动作时，动作库相对原GT10的经验平均提升。对某query，当前最大值为v；加入动作a的边际为`max(0,Delta_ia-v)`。D变大时v只增不减，边际只减不增。因此Fhat非负、单调、次模。完整三入口内部怎样相互干扰不影响此结论，因为一个完整共同搜索已经被视为不可拆分动作。

在固定候选池、完整矩阵、每次精确最大边际、容量M条件下，标准贪心保证：

`Fhat(D_greedy) >= [1-(1-1/M)^M] max_(|D|<=M) Fhat(D) >= (1-1/e) OPT_empirical`。

这是[经典次模贪心保证](https://thibaut.horel.org/submodularity/papers/nemhauser1978.pdf)在真实动作矩阵上的应用，不是新定理。它不表示任意三入口搜索是次模的，不提供路由器收益，也不提供新query泛化保证；缺失响应、动态更改动作或贪心只近似求边际时不能直接套用。

## 6. 从选错动作到真实Recall的直接界

固定一个动作库D和一个已经训练好的评分器，令

`G_D(q) = max(0, max_(a in D) Delta(q,a))`，

`epsilon(q) = max_(a in D) |f_a(q)-Delta(q,a)|`。

对第3节阈值策略pi（tau >= 0），有逐query保证：

`Delta(q,pi(q)) >= G_D(q) - 2 epsilon(q) - tau`。

证明分两种情况。选新动作时，最大预测分数的动作比真实最佳动作至多损失两次epsilon；若真实最佳是baseline，仍有选中动作Delta大于tau-epsilon，故弱界成立。回退时全部预测值不超过tau，因而G_D不超过tau+epsilon，实际增量0也满足上式。

对任意固定查询分布取期望：

`E[R_pi] - E[R0] >= F(D) - 2 E[epsilon] - tau`，其中`F(D)=E[G_D(q)]`。

所以**实际动作库在该分布中的可保留空间，大于选错动作的误差损失及拒绝代价时，期望Recall严格提高**。这里直接用真实搜索增量，不再需要“区域覆盖近似Recall”的额外桥接假设；但预测误差和动作库覆盖仍是真正未知项。

举例仅为读公式：若真实F为2个百分点、2Eepsilon为0.6个百分点、tau为0.2个百分点，则界给至少1.2个百分点。当前项目没有测得这些数值，不能把这个算例当预期提升。

另有条件性逐query保留结论：若确实已知所有动作在该query的误差不超过e，且只接受预测增量大于e的动作，则接受的动作真实增量为正。当前没有这种线上有效的误差证书；训练残差、softmax概率和一般置信度都不能冒充它。

第5节Fhat与这里F不是同一个量。字节互斥、历史cal或训练拟合均不能把经验值直接升级为分布期望。WFree已拟合训练最优集合但复验失败，正好要求保留这个区别。本界是条件性充分保证，**尚不能据此断言当前两数据集必然改善**。

## 7. 速度需要另一条条件

令A为采用新动作的query集合，B为其余query；Tbank为本次精确评分/决策费用，Troute0为原GT10路由费用，Tg0/Tga为同一原NSG从默认/新入口出发的耗时。则逐query相对基线：

`Tnew-T0 = Tbank + 1_A (Tga-Tg0-Troute0)`。

平均完整wall下降需要

`E[1_A (Tg0-Tga+Troute0)] > E[Tbank]`。

这解释了为什么“只调用一次NSG”和“64个分数”仍不能直接宣布QPS提升。新动作可能让主搜索更贵；旧路由仅占局部wall约0.5%，单靠省路由很难获得大幅收益。首要质量目标和完整wall约束分开，不以NDC加权奖励的正值代替Recall/QPS分别通过。

## 8. 风险、成本与否决点

最主要的风险是：有用完整三元组可能高度query特异，64个动作只覆盖少数query；其次是增量函数在当前query特征上依然难预测。这两点都没有被代数示例或次模保证解决。另一风险是新动作Recall略升、主搜索成本更大；还可能出现主L128好、别的L退化。

离线稠密响应有实际成本。例如每集2048条query、256个提议动作、两个K，单遍就需1048576次主搜索；两集2097152次，尚未加baseline、身份/parity/count检查和独立验证。不能称“只复用旧标签”或把它排成自动下一任务。动作库确定后64个部署动作的回归列更少，但候选库选择已经支付的成本必须保留。

理论方案的继续价值取决于**完整动作的共享结构能否保留足够空间，以及这个空间是否能由低成本评分实现**。若只能扩大库、增加网络/标签或改阈值才能维持叙述，就停止本具体版本。若按相同动作监督比较，分解式hub模型已经同样达到效果，则不能将增益归于完整动作表示。

将来若授权最小验证，应只回答上述结构问题，包含原GT10、同动作标签的单hub分解控制、本完整动作模型；每K报告救回/损伤和真实完整wall。先给出证伪结果再决定是否扩大，不自动建立新的模型/超参队列。所有新执行另立协议和数据角色；本文件未批准任何具体样本访问或调用预算。

## 9. 一手前作和定位

- [Nemhauser–Wolsey–Fisher 1978](https://thibaut.horel.org/submodularity/papers/nemhauser1978.pdf)：已核对max-column形式和单调次模基数约束贪心保证；第5节是标准应用。
- [Fast Slate Policy Optimization](https://arxiv.org/html/2308.01566v1)：已核对其决策函数与MIPS部署讨论；一般集合决策、策略优化、动作向量索引都不是本项目的新概念。
- [GATE](https://arxiv.org/html/2506.15986v1)：已核对hub表示与高层导航流程；不能将离线学表示、线上轻路由本身称新。
- 本地最直接的先行方案是[A+B R0](../20260909_ab_joint_r0_v1/theory.md)，最直接的已执行非加性控制是[E36](../../experiment_history/25_query_swap_policy.md)。本提案是明确承接后的结构变体，不能宣称从未有人或本项目从未考虑动作码本。

现阶段可主张的是一个具体、有限、能推导收益条件的候选：**完整三入口动作 + 相对GT10的有符号效用 + 固定小库精确路由 + 保留原策略**。它的实际提升和论文贡献都尚未验证。下一次推进应以这个具体假设是否成立为中心，不能再以增加诊断条目替代方法进展。
