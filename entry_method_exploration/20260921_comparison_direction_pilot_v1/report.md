# E118：共享比较方向入口预测实验报告

本版检验从真实搜索比较方向提取查询特征、预测全部现有单入口相对GT10三入口收益。底图、画像、小图、主搜索、展开和停止保持；默认仍Web GT10-soft-t1 / Yandex GT10-hard，生产E99。

**最终判断：本版未取得净收益，实验与审计已完整完成。** 主方法20个预算匹配点逐query命中与GT10相同，QPS全部更低；L128下降2.28%–2.81%。训练标签仍存在显著的逐query事后选择余量，当前32方向ReLU ridge未把它转成可靠的查询外选择。具体诊断和研究范围见[最终判断](decision.md)。

## 方法和监督

比较超平面、方向近似的margin充分条件、有限加性表示及预测误差到regret的推导见[方法与理论边界](method.md)。这些是条件论证，不作为真实有效性证明。
从独立方向角色的真实比较节点对构造单位base差向量；每query至多64个比较、总权重1。正反方向等价，固定32组projective spherical k-means和20轮迭代。单位query对32方向投影，正负ReLU共64维。全H单入口与原GT10三入口均有真实R1/R100和两K各三重复时间标签。
以同query原GT10为基准，预测召回变化和图搜索时间变化；GraphCost采用ΔR−0.1ΔT/Tref，最大预测收益不为正时沿用GT10。训练为标准化多输出ridge，fit内固定四折从五个alpha选择；折内标准化/Tref、置换和拟合均只用折内训练数据。模型/方向/固定动作全部先于接受冻结。
GraphRecall去掉时间项；RandomCost使用同容量随机方向；GraphLinearCost只用图方向线性投影；RawLinearCost使用完整单位query；ShuffledCost在训练折内整行置换响应。GT10、实际画像Single1、fit冻结BestFixed、NSG和计算全部新增特征后仍用GT10的FeatureDefault提供控制。在线每query只执行一次原NSG，全部路由/投影/全H评分/搜索/输出计入正式wall。

## 完成后的诊断与判断

图表、全部控制、配对结果和[匹配Recall的最快实测点](results/matched_recall.csv)已复核。GraphCost及GraphRecall在28项共同可达预设门槛上均更慢；保留GraphRecall在Yandex较大预算的召回均值增益及相应速度损失，不能以固定L显著性代替曲线判断。Single1的85%门槛跳档现象也在最终判断中单列。

主模型回退率为Web K1 99.8535% / K100 100%，Y K1 99.5850% / K100 100%。两集六种学习臂均按fit内CV选alpha=10，弱正则没有更好的out-of-fold净效用；独立重算全部H分数和原生动作完全一致。去掉时间项后，Yandex K1换入口91.4063%，L128召回+0.170898pp（区间跨0）但QPS−12.752%，不能归因成只要放宽回退就可获得净收益。

全H训练召回oracle的R1/R100余量为Web +17.822266/+5.944580pp，Y +8.056641/+4.240967pp；图方向CV召回MSE相对截距基线下降约0.23%–0.42%，并未转成稳健的正收益动作选择。这两类证据都保留，不能从本版负结果推出所有共享方向方法不可能。追加[只读诊断](reviews/review_diagnostics.json)用了0次新搜索/训练。
