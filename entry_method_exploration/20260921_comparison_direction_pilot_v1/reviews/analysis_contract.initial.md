# 接受结果分析口径（在模型训练/接受之前确定）

主表QPS采用三轮N/wall的均值，同时保留N/平均wall及三轮最小/最大值。只以实际K1/K100和完整在线路径计时；fit回放和标签速度不是主表QPS。GraphCost对GT10的四项主召回差报告98.75%配对query bootstrap区间；其余L128控制同样给区间但解释为诊断，多控制探索不产生额外主假设通过声明。

召回差是每query整数hit差除以K。bootstrap可以按这些差值的经验分布作多项式重抽样，其均值分布与逐query有放回采样完全相同；不把GT100成员当独立样本。每比较20000次、固定seed，保留正/负/相同、成员得失、零命中恢复/新增与回退。

匹配Recall速度仅选择达到预定50/60/70/75/80/85/90/95/99%门槛的最快实测点，不插值，不跨数据/K或按L重新训练。共同不可达的目标明示无比较。五个预算点的分辨率有限，此表不能替代稠密前沿；主报告同时展示原始Recall-QPS五点。

四个主区间均为正、学习表示胜过同监督/强固定控制、匹配Recall的完整成本有支持，才具备扩大替换结论的依据。任一项不足时描述具体不足；区间跨零记未确认，不能推成无效或等效；强负面只约束本版本。无论符号如何，完整曲线、错误审计和报告均须完成，默认不自动切换。
