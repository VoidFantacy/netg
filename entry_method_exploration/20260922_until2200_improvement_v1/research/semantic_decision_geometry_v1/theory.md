# 特权选择有效，不等于特权评分是正确学习目标

本节在E124负结果后提出解释性命题，不改变其停止结论。基础最大化不等式、条件期望投影和预测后优化不是新的算法贡献；新增价值在于把它们同本项目已经测出的反例和误差位置对应起来。

## 1. 两种误差不能混在一起

固定数据集、K、L、同一外折。记实际入口净效用为u_a(q)，默认u_0=0；E123服务代理为g_a(q)=A(q)S_a，E124便宜预测为ĝ_a(q)=Â(q)S_a。令a*=argmax g、â=argmax ĝ，并保留默认和真实ID的相同tie规则。

恒等式为：

    u(a*)−u(â) = g(a*)−g(â) + r(a*)−r(â),  r=u−g。

第一项是学习器相对特权评分的决策损失，非负；第二项是两个动作处的服务代理残差差值，可以正也可以负。第一项变小，第二项完全可能变大。因此，即使更准确地预测区域、提高服务评分的MSE、甚至降低对服务代理的真实决策损失，也不保证真实搜索收益提高。

例：三动作真实u=(0,0.1,0.2)，代理g=(0,0.3,0.2)。特权代理选择动作1，比默认好；一个学生选择动作2，真实效用0.2。另一学生准确拟合g，代理遗憾从0.1降为0，真实效用反而从0.2降到0.1。故“特权门通过”只证明这一条特权策略有价值，不是所有接近它的评分或策略都按比例获益的校准定理。

本数据中19k对3k的语义MSE和去公共偏移后的服务MSE四格均下降，服务代理决策损失也四格均下降。真实效用却只在Web K100、Y K1上升，在Web K1、Y K100下降；等K均值双集下降。恒等式中的服务残差对比变化可逐query精确解释该算术差异，但不能唯一归因为模型容量、有限样本、rank池化或区域条件缺失。

## 2. 真正有关的是动作差值方向

令e=ĝ−g。由两次最大化直接得到

    0 ≤ g(a*)−g(â) ≤ e(â)−e(a*) ≤ max_a e_a−min_a e_a。

极差界比2||e||∞更直接，且对所有动作共同分数偏移不变。默认必须作为一列参与；只给非默认加常数会改变回退决策，不能删除。

对某动作对a,b，误差仅为(Â−A)(S_a−S_b)。若δ=Â−A且Σδ=0，则

    |δ·v| ≤ ||δ||₁ (max_g v_g−min_g v_g)/2,  v=S_a−S_b。

证明：从v减去最大最小中点，再用Hölder；对合法概率，这就是总变差乘函数振幅界。E124线性质量虽可能有负值，但Σδ≈0，因此代数界仍可用；不能因此将其解释成概率总变差。中心化服务MSE是δᵀSCSᵀδ/(H+1)，C为动作去均值投影，它衡量的方向不同于普通区域MSE。两种误差本身仍不等于实际u遗憾。

协议中的合法概率反例已经说明，负分量不是“MSE更好却决策更差”的必要条件；禁止据负分量比例直接得出裁剪/softmax能成功。

## 3. 为什么服务表不自动是条件价值

对K100，令J在一条query的100个目标rank中均匀取值；D_{J,a}为该成员相对默认的实际命中差减去同query的时间惩罚，G_J为目标区域。训练表估计的是 E[D_{J,a}|G_J=g]。将它按当前query的GT区域比例平均，得到 E_J[S_{G_J,a}|q]。

这一般不等于真实查询效用 E_J[D_{J,a}|q]。严格差别是先按区域平均，再按query目标区域平均，丢失了区域内query/rank/搜索状态的变化。两个条件期望的组合没有任意交换或自动恢复原目标的定理；不能未经条件充分性就称其为真实效用的Rao–Blackwell改进。K1另有GT100池化到GT1的rank分布差异和同分ID包含代理，E123已经单独披露。

即使Â能收敛到正确的区域条件均值，学生在无限样本下趋向的也可能只是这个区域服务平滑代理，而非实际条件动作价值。需要验证代理在学生实际会选择的动作上是否保持价值关系；单看特权最优动作表现不足以验证这一点。

## 4. GT10学的不是这个后验

实际代码为 p_h=unit(u_h+Σ_i a_ih x_i)，每query对所有h的总质量1。它是单位方向上加权亲和目标的闭式最大值，也可写成归一化线性核投票。它学习“给定目标区域关联，哪些查询方向共同支持该入口”，没有query协方差求逆，也没有将区域概率再乘一个效用服务表。

忽略有限prior且π_h=E[a_h]>0时，E[a_h x]/||E[a_h x]|| = E_h[x]/||E_h[x]||，其中E_h按a_h重加权。总体质量π_h在方向归一化中消去。这不是一般的P(h|q)分类器：后验通常还需要区域先验、方向浓度和分布形状。有限prior也使质量不能被完全忽略。除非相应条件成立，不能把归一化画像解释成精确后验或真实Recall最优。

因此E124预测后验式质量的失败不是GT10闭式画像的自相矛盾，也不能说明“同样是线性模型就应该一样好”。两者的监督、归一化、估计偏差及最终决策均不同。GT10的统计稳定性是已有支持；它与有限搜索效用之间仍缺无条件保证。

## 5. 对下一方向的实际约束

更大的语义预测器、改成决策损失、剪掉负质量，都不能绕过服务代理残差这一关。继续本版调参已停止。后续若提出实质新方法，应先给出学生可选动作上的服务校准或可检验偏差界，明确该条件为何在真实目标预算成立，再证明在线成本可负担。若只有更好的语义MSE或特权oracle，应保留为机制证据。

全部GT/搜索响应在固定base与query下可由昂贵计算得到；“特权”是训练/计算预算意义，不代表原query之外的新Shannon信息。此边界继承record126；不能由学生失败推导信息论不可学习。
