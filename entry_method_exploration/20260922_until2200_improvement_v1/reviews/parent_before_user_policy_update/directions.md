# 改进方向与明确停止边界

本轮没有可以直接晋升的入口算法。默认继续Web GT10-soft-t1 / Yandex GT10-hard、生产E99。下面按当前证据和研究价值排序；不是把负结果改名成待训练新模型，也不产生22:00之后的后台实验队列。

## 第一优先：以GT10为主方法，完善有条件的机制理论

目前最可靠的主线是：GT监督选真实入口，把目标关联压缩为稳定的query方向，再用廉价小图接原有限搜索。固定亲和目标的闭式最优、单位方向的扰动界、本轮真实画像稳定性、正确语义对应的跨半价值，以及E125特定近似目标下较小的方向变化，能够组成一条可检查的解释链。

接下来理论应把“估计什么”与“保证什么”写清楚：画像估计加权query方向，不是精确目标后验；十个目标相关，不是十倍独立样本；稳定性支持代理评分，却还需要排名margin、近似路由和有限搜索的条件才能连接到Recall。采用明确可被反例推翻的条件结论，避免证明一个代理最优后称整个系统最优。

论文中的三个比较要分开：整个GT10系统对固定NSG；同QGT候选下GT10对GT1/单位hub；新学习方法对当前默认。原单位hub控制继承了GT选点，不能写成无监督基线。GT10图扫描邻边更少，也不能改写成路径必然更短。

可执行的后续证据任务是跨来源检验同一稳定性/亲和预测，并整理已有H、评分、小图、联合初始化控制的覆盖矩阵。新的消融只补当前矩阵确实缺少的格子，不能重复E107/E108/E115。先核原协议与源码，再决定是否值得额外运行。关键否决条件：若GT10在新来源上不比GT1更稳定，或正确对应相对保持质量的置换没有额外价值，就必须缩小统计机制主张；不能因总体Recall表好看忽略该失败。

理论工具本身不是新颖性。与GATE的静态路由表示、方向聚类、学习路由及图搜索前作的区别，应落在监督压缩、相同系统口径和实际证据。当前资料可以支撑严谨的方法解释和边界分析，尚不足以保证论文级别或声称一条普遍ANN理论。

## 第二优先：先找到可支付的目标预算信息，再提出线上算法

新全H诊断已排除“高预算完全没有入口余量”这个简单解释：固定256条样本上，Web/Y的R100余量仍有1.586/2.641pp；当前top3只覆盖10.34%/24.85%。但Web的L128最佳入口迁移后只取得目标预算oracle的15.76%，说明直接沿用低预算标签很危险。这个结论没有撤销E120目标预算kNN的停止。

E123还证明真实目标区域含有有用的服务结构；E124则表明预测该区域更准确，并不保证预测出来的服务代理适合学生决策。下一研究的具体缺口是：**能否给一个便宜、可观测的表示，以及它在真实工作预算上保持动作价值关系的证据？** 当前我没有一个已满足这个条件、值得立即扩大训练的具体模型。

任何未来提案在实现前应交出四项可核验内容：

1. 与E119能力表示、E121路由状态、E122动作平滑、E124语义编译的实质区别；不能只是改维数、网络或损失名称。
2. 在指定K/L的实际服务或成本标签上，解释代理偏差为何小；特权oracle通过不足以充当校准证明。
3. 同信息、同监督的简单查询外基线胜过默认及置换控制；不能只有拟合内收益或平均MSE改善。
4. 完整在线费用可支付，最终用真实K1/K100、完整wall和来源外结果检验；任何额外读取图状态的费用都计入。

没有这一证据，就停止“再学一个更强入口评分器”的实施。现有结果不证明所有RL/MLP不可行，但也没有依据继续试它们。若研究目标必须是显著的线上提升，长期可以重新定义允许改变H或底图的任务；那是不同的图构建/导航问题，需要与RoarGraph、NGFix、GATE等重新排重，不能沿用本轮固定图结论或自动实施。

## 第三优先：把离线监督费用作为独立工程目标

本轮补齐了GT-inclusive账本：固定配置下核心入口构建约404/1780秒，其中exact GT占97.9%/99.4%。E125把20K画像目标获得时间降到64.6/28.0秒，画像中位偏移约1°/2°，线上QPS变化均小于0.22%；这是具体的费用信号。但Web K1的预锁非劣区间没有通过，当前近似目标版本已经停止，不能追加教师L、样本或阈值把它救回。

若以后独立立项降低构建费用，优先研究能保留精确监督或明确控制其偏差的计算办法；先看部署是否频繁重建、GT是否可合法复用，再评估这一步的实际价值。不能把本来可复用的GT每次重复计费来夸大收益，也不能把GT10单次构建的几十分钟与整套后继实验数小时的响应标签费用混算。

新提案需重新定义成本合同：包括QGT5K、画像标签、共同底图前置、内存/硬件与缓存条件；恢复旧GT/目标归属或给出明确偏差控制，然后用冻结的质量风险门验收。精确计算加速和缓存复用通常属于工程贡献，不应仅凭“训练便宜”声称新检索理论或线上前沿提升。当前没有未完成的E125继续验证分支。

## 今晚之后保留什么、停止什么

保留GT10原默认、全部历史图/GT/模型/日志，以及E123特权正值、画像稳定性、全H高预算余量和E125费用信号。E121/E122/E124/E125当前版本均停止，不调状态、图正则、网络、教师预算或损失补过。E123不是可部署方法。下一个真正的线上候选仍需一个新且可证伪的机制，不以本轮反复曝光数据作为新盲测。

本轮推进了理论与成本认知，尚未得到新的稳定线上替代。最有把握的近期工作是把GT10作为强简单基线讲清楚、证明能证明的部分，并准确标出剩下的桥接缺口。
