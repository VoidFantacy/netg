# E121 路由状态信息表：执行前冻结

## 机制与范围

z为原GT10小HNSW结束所有level>0贪心下降时的内部节点ID。原图和画像固定；不是query GT、主搜索trace或新计算的全H打分。先机械复制原searchKnn并只增加z观察，验证原heap的ID/距离bits、距离次数和原E118三入口均一致。两集各4096 query，每条原/观察两次，共16384路由调用；无NSG、GT或新图。

动作0是原GT10三入口，动作1..H是全部真实候选各单入口。复用E118 fit4096真实K1/K100/L128标签及原三重复graph-only wall。二者均是历史曝光开发信息，不含E118接受、E105新源或任何heldout。本轮L128不能代表目标R90预算。

## 冻结学习与控制

seed20260922将4096 query排列为四等份。每轮3072训练/1024外折，只用训练折估计任何动作均值、时间尺度和表值。z来自标签无关的固定原图；空状态回退0，不合并或细分状态。

每个K分别定义g=R_action−R_default、t=(T_action−T_default)/mean_train(T_default)、u=g−0.1t。这里T仅旧graph-only标签，不包含原路由/选择费，最终不得当完整QPS。0.1预先继承E118/E119的固定权重，作为本信息检验的成本代理；不宣称它是R90最优乘子。

StateRecall按状态训练平均g最大且严格正选择动作；StateCost按状态平均u最大且严格正选择。均无网络、阈值扫描、收缩或额外特征，tie先默认再真实ID小者。GlobalRecall/GlobalCost分别在全部训练query上做同样选择。

ShuffleRecall/ShuffleCost控制：在每折训练与外折内部各做一个独立、预先seed固定的z排列，保持每部分的状态计数；按打乱z拟合并预测，不用外折标签选动作。该控制只用于信息证伪，非拟部署策略。原z、四折、打乱映射在读取响应统计前冻结保存。

报告所有7臂、各折、两K的净成员增益、救回/损伤、旧graph-time变化和u，以及训练与外折差。报告表状态占用、训练表换点比例、选中真实hub是否在原top3；最后两项只解释不选型。

## 信息门与停止

对两个预定候选分别核对：两集外折等K平均u均正，整query bootstrap的98.75%描述区间下界均>0；各K的Recall均值损失不得超过0.1pp；每集平均u均胜对应Global与Shuffle，合并等数据集的两项配对差各自98.75%下界>0。20000次bootstrap、seed固定；不将共享训练折的区间当正式泛化显著性。两者通过时优先StateCost，否则唯一通过者；均失败则STOP_ROUTER_STATE_TABLE_V1。

这比只看正均值严格，但不要求每个固定L的Recall区间全部为正。门不通过则不访问新测试、不补全H高预算、不增状态或模型继续调本版。

通过仅授权下一阶段的具体协议制定：先目标K/L下同候选真实响应和完整费用验证，再冻结模型/样本量与新来源身份，最后完整Recall–QPS比较。在线可在得到z后查表；若选择固定单hub，可以跳过小HNSW的base层，主NSG保持不变。此跳过尚未实现，也未计入旧标签，不能预支加速结论。
