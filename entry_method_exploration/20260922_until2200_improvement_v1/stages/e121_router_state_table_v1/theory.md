# 原路由状态的条件决策：理论、成本与可推翻预测

## 1. 新信息假设的准确含义

原GT10已经计算小HNSW上层下降，令其结束节点为z(q)。本候选不增加query信息，而是使用一个原流程已经计算的结构表示。E117使用三入口关系和rank-single动作；E118/E119在线给全H评分。本候选将全H动作选择预先编译为z到真实ID的小表，可选择原top3之外的ID。

这种编译不构成新颖性证明。GATE已有静态入口表示与小图，算法选择/ALORS已有条件响应预测，EDBT 2026已有查询历史入口复用；我们检验的是这份固定路由状态的实际增量信息和完整成本。参见[前一轮一手文献](../../../20260922_gt10_strength_review_v1/literature/review.md)。

## 2. 路由状态为何能表示非线性区域

忽略浮点/同分，在raw-IP画像路由中，一次比较是q·(p_i−p_j)的符号。对于一个固定上层访问路径，所有分支条件组成有限个齐次线性不等式，其可行query集合是一个可能为空的多面锥。上层移动只接受严格更近节点，因此每层不重复下降到曾离开的节点，访问路径有限。

同一结束节点可能由不同路径到达，所以z的一格一般是若干锥的并集，不必是单一凸Voronoi区域，也不保证是全部上层节点中精确最近者。以z查表可表示沿这些区域变化的动作选择；这不是新的额外query信息，更不是它必然对应NSG服务区域的证明。实际float32与同分边界以原程序为准，本轮先做逐位观察一致性。

## 3. 这个表示的理想价值与学习误差分开

固定图、K/L，g(q,a)为动作a相对动态默认三入口的真实Recall差，含默认a=0、g(q,0)=0。定义μ_a(z)=E[g(q,a)|z]。可见z的理想表收益为V_z=E[max_a μ_a(z)]；全局固定动作的理想收益为V_0=max_a E[g(q,a)]。由max的凸性，V_z≥V_0≥0。

这个不等式只是可表达策略类的包含关系。有限训练表未必有V_z的收益，更不保证胜GT10。若训练估计在状态z的所有动作均值误差至多ε_z，则经验最优表的条件遗憾至多2ε_z；总体遗憾至多2E[ε_z]。固定状态内n_z条IID query、M个固定动作及g∈[−1,1]时，Hoeffding/union bound给ε_z≤sqrt(2 log(2M/δ_z)/n_z)。

这里M≈800而n_z可能很小，表字节少不等于统计选择容易。状态、动作或回退如果按外折收益修改，上述固定类分析失效。4096×H反事实不等于4096×H独立样本。本轮四折只作历史开发检验，且这些query曾用于原GT10画像；不能据此宣称新来源泛化。

固定raw query及整个索引原则上决定响应，不把负结果解释成不可消除的信息噪声。若表失败，可以是z过粗、条件动作没有共享优势、样本有限或成本代理不准，需要用固定/置换/训练差及真实测量分辨；不能自动扩状态继续选型。

## 4. 费用为何必须从完整流程重算

设T_upper为原上层路由，T_base为其base层，T_main为原NSG，T_lookup为查表。默认时间为T_upper+T_base+T_main(default)。若表选静态单hub，可实现T_upper+T_lookup+T_main(single)，回退则继续原base层。小图base层的省略只是一项可能的路由节省，主搜索更慢会抵消它；必须测全流程。

E118缓存T仅graph-only，阶段u=g−0.1ΔT/mean(T_default)没有支付上层/查表，也没有包含条件省去base层的费用。它只能用于一个预锁的信息检验，不能算QPS或当R90最优效用。

真正部署目标仍为固定每配置L下满足R_K≥r的最小完整平均时间。若同LRecall正增益允许降低L，需测实际降低预算后的主搜索和全部路由费用；不能沿用L128动作排序或用单λ宣称找到整个非凸前沿。达到信息门后才锁目标预算的响应/费用实验，不能把信息门通过当理论与性能目标完成。

## 5. 可推翻预测

H1：真实z能在外折预测比全局固定和打乱z更高的净收益。对两数据集和两个K按protocol检验；若仅训练内正、外折负，则本版没有可迁移证据。

H2（仅H1后）：目标工作预算保留收益，完整原生流程的新增/节省费用可支付。若目标K/L或完整wall失败，即便H1成立也不称性能提升。

反例：若每个z内不同query的有益hub近乎随机，事后oracle可以很大，而μ_a(z)都≤0，理想表只回退；增加训练拟合能力也无法改善这个固定表示的理想价值。另一个反例是μ正但主搜索成本大幅增加，Recall变好而QPS变差。

本轮理论进展应由这些条件与证伪结果构成；多面锥、Jensen和有限类界都是标准工具，不宣称单独具有论文新颖性。
