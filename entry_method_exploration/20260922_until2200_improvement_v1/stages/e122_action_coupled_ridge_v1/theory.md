# E122：从动作响应的局部性到可否改善选择

## 已知结构与需要避免的跳步

历史4096查询上，真实hub的8近邻，其去均值Recall响应平方差低于同谱节点置换关系；双数据集、真实K1/K100通过冻结的结构门。它支持对动作间响应作平滑约束的试验，不证明线性可预测，不证明任意正则强度有效，更不证明GT10可被替代。该诊断已看过全部开发查询，随后四折结果仍属开发证据。

记查询向量x、动作a的条件平均响应m_a(x)。即使m_a(x)≈xᵀw_a，响应差控制的是 E[(xᵀ(w_a−w_b))²]=(w_a−w_b)ᵀΣ(w_a−w_b)。除非Σ有严格正的最小特征值，否则它不能控制||w_a−w_b||²：若差向量在查询分布的零空间，两动作响应完全相同而参数差可任意大。因此直接由响应局部性推出欧氏参数平滑是不成立的。这也是本版同时保留CoefficientSmooth诊断的原因。

响应扣除各动作训练均值；截距独立估计且不作图平滑。这样不会把“所有查询上一个动作始终较差”的均值偏差误作查询相关的动作结构。查询自身的公共难度分量在动作差中抵消，但仍可能主导全动作预测MSE；后者不能单独用作选择门。

## 固定目标与精确求解

X为训练查询单位化后减训练均值的n×d矩阵，Y为各单入口相对GT10动态三入口的训练效用、再逐列减均值。默认动作效用精确为0。图L由已冻结的真实hub余弦8近邻对称化而得，L半正定且tr(L)/H=1。

本版目标为

    J(W) = ||XW−Y||²_F + α||W||²_F + β tr(WᵀXᵀXWL),  α=10, β=1.

第三项等于β/2 ∑ab A_ab ||Xw_a−Xw_b||²（这里A和L使用同一平均度归一化），直接约束训练查询上的预测函数；这与观测结构对应，但仍不是总体分布保证。α>0使问题严格凸，唯一正规方程为

    GW + βGWL + αW = C,  G=XᵀX, C=XᵀY.

令G=P diag(λ)Pᵀ、L=V diag(γ)Vᵀ，则

    W = P { (PᵀCV)_ij / [λ_i(1+βγ_j)+α] } Vᵀ.

即使G奇异分母仍≥α。β=0退化为独立ridge。CoefficientSmooth的分母为λ_i+α+10γ_j。PermutedFunction只重标图节点，保留谱与正则强度，检验收益是否来自正确动作关系。原图和置换图的谱一致性纳入实现校验。

上述多任务正则、输出核与谱求解本身均是已有方法；本项目检验的是固定NSG、全H动作真实有限搜索响应是否适合这种关联，以及其决策收益能否覆盖在线费用，不能将标准正则包装成方法创新。见[相关工作](../../literature/action_coupling.md)。

## 何时有收益：条件偏差方差表达

仅在固定设计且Y=XW*+E、E独立同方差的理想模型下，联合模式θ_ij=(PᵀW*V)_ij的估计期望为 λ_i θ_ij / d_ij，方差为σ²λ_i/d_ij²，其中d_ij=λ_i(1+βγ_j)+α。训练设计上的平均预测风险每模式为

    [ λ_i ((α+βλ_iγ_j)/d_ij)² θ_ij² + σ²λ_i²/d_ij² ] / n.

较强图收缩降低方差，却增加相应模式的偏差；只有信号在高图频模式较弱，才可能净获益。相关动作残差会改变噪声协方差，本式不可直接当成真实搜索响应的精确风险。有限NSG输出还具有离散跳变，线性条件均值假设需要数据检验。

因此，“响应局部性为真但模型失败”并不矛盾：局部性可能只解释动作共有成分，线性模型可用的差异信号很弱；也可能正则抹平关键但稀少的入口优势。冻结版本失败后不能根据结果改α、β、邻居数或非线性特征继续补过。

## 从预测到入口选择的桥与缺口

将默认0和H个单入口组成有限动作集，真实效用u_a(q)、预测û_a(q)，a*为真最大值动作，â为预测最大值动作。如果本查询所有动作误差≤ε(q)，则 u_a*−u_â≤2ε(q)。这是由两次误差界和预测最大化直接得到的，不依赖模型名称。若真最优和次优间距>2ε，选择保持正确；若只知道平均平方误差，则不能据此保证最大化后的收益正，更不能得到未付路由费用的QPS增益。

一个反例是：默认始终0，所有单入口真实效用均为−δ；对很多动作各有很小、均值为0的预测误差，最大值挑选仍可能频繁选择错误正值。在δ很小时全动作MSE也很小。动作约800时，这一选择偏差不能靠报告平均拟合优度消除。

本版直接用外折实际选择的u与每K Recall门检验这一桥，并要求正确图优于无图和置换图。u的时间项仍是历史graph-only时间；新路由尚未实现，没有完整性能结论。

## 静态可编译性不是零费用

训练均值为x̄、ȳ时，û(q)=q_unitᵀW+b，b=ȳ−x̄ᵀW。因此可用查询[q_unit;1]和动作[w_a;b_a]的内积实现静态评分。不能把动作向量再单位化而声称评分不变；不同范数恰是此目标的一部分。精确扫描代价O(dH)，近似索引还会引入动作排序误差。只有开发门通过后，才值得冻结实际路由实现、完整费用和选择外验证。
