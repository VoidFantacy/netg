# 改进方向与下一步

2026-09-22按最新用户意见调整。当前默认为Web GT10-soft-t1 / Yandex GT10-hard、生产E99。今晚没有新的线上Recall–QPS稳定替代，但近似目标已经形成有价值的构建费用候选。新源单组复测完成，后续不受旧单点门的永久禁止，也不启动未经设计的参数扫描。

## 1. 先保留最具体的改进：低成本GT10

E125将20K画像目标获得时间从原exact搜索312.9/1417.3秒，变为近似完整作业64.6/28.0秒；前者CPU0–7、后者单线程，不能宣称同资源加速比。QGT5K精确监督仍存在。原12点完整QPS几乎不变，画像中位偏移约1°/2°，这已经是一个值得保留的工程结果。

追加源码追踪确认：Web温度0.016201138496398926由原20K精确GT1的hub分数间隔标定，E125直接继承；Y-hard没有温度依赖。因此费用改进限定在**既有H和参数固定时的近似标签获取**，尚未完成新数据集从零构建的低费用验证。原脚本还读取exact GT做控制/诊断，不能将研究作业宣称为完全不需旧GT的部署流程。这个范围不改变新查询Recall/QPS，但冷启动需要单独解决温度来源。 详见[源码与条件](research/approximate_supervision_scope_v1/report.md)。

Web K1/L1000旧批−0.0977pp，新批−0.1465pp；新批救回6、损伤12，95%描述区间[−0.3418,+0.0488]pp，QPS−0.1044%。这表示目前更适合定位为降低构建费用的质量取舍，不是完全无损或线上加速。若构建频繁或标签成本重要，价值较高；若GT可以长期复用且必须接近无损，原GT10更合适。不要重复计费可复用GT来夸大节省。

下一项值得做的是**固定现有模型的成本—质量确认**：先按真实用途选最关键的K/L与来源，给出可接受的实际损失和测试预算，再补一组能影响选择的证据。已有两批Web K1、原双集K100等结果必须同时呈现。不是要求每点显著，亦不是增加样本直到通过。本次新批已曝光，不得拿来选择教师后再充当确认集。

若要进一步减少观察到的质量损失，先利用原训练侧精确/近似目标统计区分：漏掉目标是否改变目标所属hub，还是仅目标ID改变；加权扰动是沿原画像方向还是使其转向；大偏移是否集中于少量弱支持画像。该诊断可以指导一个有限的训练侧纠偏假设，例如只对预先识别的不稳定训练子集做精确监督，并明确计入筛选和追加标签费用。**这些诊断和混合监督尚未实现**，不得依据新测试失败query选择补标，也不声称它必然有效。

一种值得比较的最简单纠偏，是在预先随机抽取的m条训练样本上补精确GT，用“全量近似贡献 + N/m倍抽样精确减近似残差”恢复原画像向量总和。固定教师/H/参数时该向量估计设计无偏，方差取决于残差；归一化方向和Recall仍无无偏保证，少量稀疏残差可能反而加大误差。这是经典差值估计，不是新颖性声明，也尚未执行。应和相同m精确样本单独构建对照，不能先挑新测试损伤query。 [推导与前作](research/approximate_supervision_scope_v1/report.md)。

只读训练缓存已补核算：随机残差校正要在合力归一化的向量总和MSE上优于直接近似，Web/Y解析临界m约3269/8517，占20K的16.34%/42.58%。残差方差虽小，直接近似偏差也已部分抵消，少量补标不必更好。没有据此训练模型或选择m；这不是Recall门或否定混合监督，只用于评估投入。 [残差诊断](research/approximate_residual_variance_v1/report.md)。

## 2. 把GT10为何有效写成有条件、可验证的理论

最稳固的解释链是：GT监督选真实入口；十目标归属形成稳定的加权query方向；归一化均值在固定亲和代理上有闭式解；静态画像与小图把监督压缩为便宜在线选择。两半画像稳定性和正确语义对应的额外亲和支持这条链，但不能保证有限搜索Recall。

论文应分别陈述估计对象、偏差与方差、方向扰动、排名margin、小图近似误差和有限搜索效用。十个目标相关，不能宣称十倍独立样本；unit均值不是一般的目标后验分类器。近似目标ID准确率也不直接决定画像方向误差，小方向差更不保证召回无损。可证明的条件命题与未满足的前件并列写明。

比较必须分清：整个GT10相对固定NSG；同QGT候选下GT10相对GT1/单位hub；新方法相对当前默认。单位hub也继承GT选H，不能叫完全无监督基线。小图扫描邻边少，不必等于路径或访问节点更少。

后续先整理已有H/画像评分/小图/联合初始化的消融覆盖矩阵，只补真正缺项。GATE静态路由、方向聚类、学习导航等前作不应重新命名为创新；研究价值应来自确切机制、可迁移证据和适用边界。

## 3. 线上大幅提升仍需找到便宜的决策信息

目标预算全H诊断说明还有空间：固定256条上Web/Y K100的single+默认oracle增益为1.586/2.641pp，当前top3覆盖10.34%/24.85%。但Web L128最佳入口迁到目标预算只取到该oracle的15.76%，低预算标签不能直接代表工作预算。oracle免费、样本历史曝光，不能视为可实现收益。

E123证明真实GT区域经过服务表有价值；E124表明预测区域更准不必提高决策，因为服务代理不一定等于查询条件下真实效用。当前优先问题是：什么廉价表示能在工作预算上保持入口动作价值关系，并且节省的主搜索时间足以支付它？

后继可以从已有响应检查遗漏的信息与预算关系，提出一个简单对照能区分的具体假设。先用便宜、固定范围的实验判断是否有信号；不要求探索阶段先获得全部显著性，也不因模型名更先进就扩大训练。RL/MLP/双塔不是被证明不可行，但模型复杂度本身不填补信息、代理偏差与在线费用缺口。

## 4. 今后怎么判断“继续”或“停止”

遵循[研究判定策略](research_decision_policy.md)：探索与默认替换分开；单点区间未过不一票否决；非劣证据不足不等于有害；成本收益可以成为独立目标。对接近边界且有实际价值的旧候选，允许先冻结范围再复测，不必改名或先发明新机制。

同时保留数据角色、计时口径和全部结果。明显且可复现的质量损伤、不可支付的在线成本，仍是停止具体实现的有效理由。复测固定样本和结束边界，不连续加批直到过线，不在确认数据上调参。旧E125的STOP保留历史身份，当前定位为RETAIN_LOW_COST_CANDIDATE，原默认与全部历史资产保持。

今晚没有额外实验队列。最具体的近期方向是把低成本候选的取舍讲清楚，并用训练侧误差结构指导有限纠偏；理论方向则完善稳定性到实际搜索的条件连接。
