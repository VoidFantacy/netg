# 残差收益、查询失败与空间分布：冻结诊断范围

2026-10-24。用户授权回顾当前项目，研究残差与空间分布、失败比例及改进比例的关联。本版本是 E183 之后的离线诊断，不是新性能矩阵，也不恢复旧 runner。

- 主分析固定 E183 简版沿用的七集/家族：Deep、SIFT、WebVid 为 soft，其余 hard；B32；K1/K100、L200。全 L 与其他已测家族仅作敏感性表，不按结果换赢家。
- 读取 E183 实际计时返回、原 GT、16K 合法训练 GT 和未裁剪残差源，重新计算查询失败及成员救损；逐项对照已审 CSV。K1 失败是未命中 GT1；K100 同时报告未满100、少于90、成员遗漏，三个分母分开。
- 新几何诊断覆盖全部既有测试查询及其原 GT100 向量；不重新生成全库 GT，不改 GT 顺序或原始 metric。确定性 PCG64 seed20261024，每集均匀无放回抽8192个 base 向量，保存 ID；样本仅用于背景分布矩、范数与有效秩，不把它当全库。
- 对实际 metric 的 GT1/GT100 距离用 float64 重评分，记录 top100 相对分离度、GT100方向集中度、query范数，以及 GT100 相对均匀 base 样本背景距离的标准化分离度 z=(背景均值−GT100距离)/背景标准差。IP 用负内积，L2 用平方距离；z 不是论文中原始 relative contrast，IP 不套 L2 半径或内在维数估计。
- 对合法训练 GT100/遗漏目标统计目标重复、singleton token占比、有效目标数、测试遗漏源覆盖；区分真实图入口 H 和近邻高频目标（hubness 的 k-occurrence 意义）。覆盖链的乘积是记账恒等式，不是相关性证明。
- 关联在每个数据集内分析：固定特征四分位，报告失败/改善/修复与基线难度；保存 Spearman 描述系数及控制原遗漏数分层的高低几何组差异。小样本/稀有事件不强作显著性结论。跨七集相关仅描述，留一数据集范围另报；同数据的多L不当独立样本。
- 只作离线解释，无训练、构图、ANN、新查询时序测量、测试调表、在线门控或默认替换。几何/GT特征是事后诊断，尚不能当作免费在线预测器。所有新输出写新目录，保留旧科学字节；完整大 base 身份继承 E183，另记当前 stat 和本次实际读取样本的 SHA，不声称重 hash 整库。
- 线程环境固定1，诊断wall单列且不是QPS；核对整数、覆盖链和代数背景矩，输出 CSV/NPZ、中文报告和图。结束后同步主文档中的新诊断入口及证据边界。

理论参考：Radovanović et al., [Hubs in Space (JMLR 2010)](https://www.jmlr.org/papers/v11/radovanovic10a.html) 用 k-occurrence 描述近邻目标频次；He et al., [On the Difficulty of Nearest Neighbor Search (ICML 2012)](https://icml.cc/2012/papers/580.pdf) 讨论相对距离对比与检索难度。它们提供诊断动机，不证明当前 NSG 的残差或 Recall–QPS 因果关系。
