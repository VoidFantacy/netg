# E224 B32 与 P64 的逐查询分流

COCO 真实 K100，沿 E223 同图、硬画像、SPAN4、完整 B32、Q8-cert 和 P64。共享 GT10 主搜索，主返回之后、组查找/投影/补点之前判断。每查询只执行完整 B32 或完整 P64 的既有分支。使用 E223 真 GT10 返回的三路画像分数、前三路最大分差、首名/第50名/第100名原分数、末端分差和 L。标签为同查询同 L 的 P64 正确成员数减完整 B32 成员数。训练 Ridge(alpha=10) 和 CART(max_depth=4,min_samples_leaf=512)，分数大者优先。普通推断不需要GT、查询向量新投影、代表查找或 B32 候选评分。

门模型训练与阈值校准使用 E223 已保存的公共第 3072–6143 行，按身份和 seed 224 固定为 2,048 训练、1,024 校准。公共 6144–9215 行为本轮完整评测，核对真实数据准备身份与其余模型训练角色不交叠。该评测窗口用于历史研究，属于 E224 留出窗口。正式 GT 在所有批次计时结束前不参与训练、阈值选择和输出。按 L 分别校准阈值，在 E223 完整墙钟估计预算下最大化留出校准净正确数。参照为不小于 L+8 的最小已测 B32 L。尾端不足时沿用最近非零 B32 实测时间差作为探索预算。预算预留 1 微秒/查询给门，P64 增量用 E223 同 L 平均完整时间差。并列选择更少启用，保留全关。每个点原版 B32 的更高 L 召回门槛另列。两种分流均测完整曲线，包括未达目标的探索点。

固定 L176/184/188/192/196/200/208/224/232/236/244，六臂 GT10、B32、Q8-cert、P64、GATE-LIN、GATE-TREE，共 66 点和 132 批。CPU15 实际单线程，每点两遍，旋转及反向轮序。预热、GT、加载、哈希核验与写盘在计时外。完整 wall 含路由、主搜、分流、所选补点、六数组复制与批生命周期。独立 Python 复算预测门位，核对每查询返回 ID 和距离等于所选分支，保存正向救回、损伤、启用率和事后最优分支的质量。事后最优只用于质量诊断。正式采用真实输出及 GT、完整 QPS 和同期 B32/P64/Q8-cert/GT10 对照。L184→B32 L192 为主问题，其余预算用于检验曲线范围。当前生产合同按 E99/E211。
