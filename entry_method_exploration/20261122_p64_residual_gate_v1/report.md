# E224 B32 与 P64 的逐查询分流

GATE-LIN 7/11 个点快于同期 B32 达标点；GATE-TREE 8/11 个点快于同期 B32 达标点。

## 实验范围

真实 COCO K100，GT10 三入口和 SPAN4 主搜索相同。分流读取三路画像分数及已完成的主返回摘要，只执行原版 B32 或 E223 P64。对照另有纯 GT10、Q8-cert、P64 全开。E223 已保存的公开查询按身份分成 2,048 训练、1,024 校准。正式窗口为公开行 6144–9215，角色身份与训练、校准和原模型训练来源均隔离。正式公开窗口曾用于历史研究。

66 点、132 完整批次、405,504 次计时查询。CPU15 实际单线程，每点两遍。路由、主搜、分流、补点和输出生命周期计入完整 wall。正式批次结束才评分，另用 Python 逐查询复算模型决策、分支输出和 Recall，核验 67,584 个门状态。

## COCO K100 · L184 主比较

| 方法 | L | Recall@100 | 完整 QPS | P64 启用 |
|---|---:|---:|---:|---:|
| B32 | 184 | 96.3271% | 2,927.6 | 0% |
| P64 | 184 | 96.5417% | 2,730.7 | 100% |
| GATE-LIN | 184 | 96.5410% | 2,752.5 | 85.8% |
| GATE-TREE | 184 | 96.4782% | 2,810.7 | 53.7% |
| B32 | 192 | 96.5446% | 2,772.6 | 0% |

| L184 分支 | 较 L184 B32 净正确成员 | 新增 / 丢失 | 距 L192 B32 目标 |
|---|---:|---:|---:|
| GATE-LIN | +657 | 990 / 333 | -11 |
| GATE-TREE | +464 | 675 / 211 | -204 |

L184 事后仅在 P64 增益为正的查询启用，共获得 1038 个净正确成员，追平本轮 B32 L192 需 668 个。事后选择只诊断候选分支质量，不计作在线曲线或吞吐。
校准窗 linear 在 866/1024 条上启用，净增 192，同窗目标 254。
校准窗 tree 在 536/1024 条上启用，净增 127，同窗目标 254。
