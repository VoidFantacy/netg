# E225 P64 候选探针与查询分流

COCO 真实 K100，E223 P64 与原版 GT10+B32。共享冻结图、入口和 SPAN4 主搜索。对已完成 GT10 返回，复用 E223 的代表选择，先查最多八个新候选。预编探针优先保留 E222 组内短表头，再从完整池按等距位置补足，按 ID 排序，跳过主返回和原 P64 所用 B32-fit 候选。仅对可用探针进行 E223 64 维粗分，同时最多投影一次。新增特征为池大小、探针数、相对主图第 K 名的粗分均值、最大值、范围、非负数量和正差和。用 E224 的 11 维主图特征加此七维做岭回归，目标为 E223 的 P64 相对完整 B32 净正确成员数。阈值前移至全池扫描之前。触发时复用已有投影及探针粗分，按 E223 原 P64 算法继续。未触发时完成原版 B32。推断无 GT。

复用 E224 的合法 fit/cal 身份与 E223 第二公共窗输出。模型池和预编码均冻结。校准以同 E223 L+8 或更高的最小原版 B32 实测 L 的时间差为预算，上端沿用最近跨度。两次真实主返回回放分别测 B32、探针后 B32、探针后 P64，给校准提供费用估计。先以 E223 公共查询对应旧包核对回放完整 B32 和探针后 P64 不改变分支结果。分流阈值选择在预测预算内净增最大的校准配置，并保留全关作为候选。阈值全关时实时直接运行 B32。正收益识别依靠探针；推断的所有开销均计入完整计时。

正式公共前 3,072 行，身份与 E224 fit/cal、原画像与残差训练角色互斥。该窗口曾用作历史评测。按 L176/184/188/192/196/200/208/224/232/236/244 逐项测 GT10+B32 与候选探针分流两种方法，各两遍 CPU15 单线程完整 wall，共 22 点、44 批。主比较 L184 对 B32 L192。路由、主搜、探针、分流、补点及结果生命周期进 wall。输出与探针后 P64/B32 两个分支逐条独立核对，校验另行运行串行批次并排除在时钟外。计时结束才读取正式 GT，按冻结模型逐查询核对分流位、最终命中、P64 增量收益和达标 QPS。图只画两条端到端实测曲线。生产合同按 E99/E211。
