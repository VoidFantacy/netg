# 从完整 QPS 到可执行入口决策

研究推导，2026-09-22。不是新性能结果，也不将以下恒等式、Bayes 决策或信息价值称为原创定理。本文的作用是把已有理论落实到当前固定图、固定主搜索、固定配置 L 的入口问题，并据此筛掉不值得实现的结构。

## 1. 先定义完整问题

数据集、K、底库、metric、底图、搜索核和返回规则固定。动作 a 是一个完整的合法入口策略或入口集合，a=0 为原 GT10。不能把三个单入口响应相加当成三入口结果。q 来自指定查询分布 D；L 对同一配置中的所有查询相同。

令 X=phi(q) 为决策表示，pi 为选择规则。信息提取、模型推理和动作执行都是算法的一部分，不是假定免费的统计条件：

```text
T(pi,L) = E[C_acquire(q) + C_score(q) + C_route(q,a)
             + S_pi(q,a,L) + C_output(q,a,L)]
R_K(pi,L) = E[R_K(q,a,L)],  a = pi(X)

minimize over implemented (phi,pi) and global L: T(pi,L)
subject to R_K(pi,L) >= rho,  rho = 0.90.
```

串行整批吞吐为 N / wall。若将同一计时区间分成无遗漏、不重叠的 query 时间 t_i，则等于 1 / mean(t_i)，不是 mean(1/t_i)。该恒等式不允许用另一次插桩逐 query 计时替代独立整批 wall。三次整批重复可以报告各次 QPS、中位数及 pooled N_total/wall_total，不能把重复当新增 Recall 样本。

S_pi 的下标不能随意丢掉：评分器扫描大矩阵可能改变 cache，进而影响同入口的主搜索 wall。因此旧独立搜索时间只有在执行上下文可比时才能作为在线时间估计；NDC 相同也不建立这个条件。上式要求时间段互斥记账，若有共享工作只计一次。

更严格地，串行第 i 条查询的费用可写 t(q_i,a_i,h_i)，h_i 包括进入查询前的 cache/分支预测/分配状态，它可能受前面动作影响。对已执行整批，分段相加和 QPS 恒等式仍成立；但把各动作在不同批次测得的 t 拼成一个“新策略平均时间”一般不成立。即便把 h_i 并入统计状态，策略可能改变后续 h 的分布，不能因此直接把整批平均成本优化化成独立逐 query 贪心问题。下文条件动作价值的严格结论要求执行费用在所用上下文中可比较、且已覆盖这种干扰，或明确只对不变的代理费用成立。当前标签不具备该证明，最终完整 wall 不能被缓存拼接取代。

K1/K100 分别满足召回和速度要求。一个等 K 平均收益不能掩盖其中一个 K 退化。本研究不实现按 query 改 L，也不通过混合不同 L 获得看起来更好的前沿。

## 2. 精确收支式与局部近似分开

比较满足同一召回要求的默认配置 L0 和候选配置 L1。令 C 为主搜索以外的完整在线费用，S 为主搜索费用，则严格有：

```text
T1 - T0 = E[C1-C0] - E[S0-S1].
QPS1 > QPS0  iff  E[S0-S1] > E[C1-C0].
QPS1 >= (1+g) QPS0  iff  T1 <= T0/(1+g).
```

这里 C1-C0 是增量，可以为负。例如新结构替代了旧路由，不应同时计两份本来不执行的路由。反之，先执行旧路由再决定回退，其已付信息费不能消失。当前 record125 只测到 T1/T0，不能从差值识别 C_acquire、C_score、C_route 或 S 中某一项。

在 R0(L)、T0(L) 可微且 R0'(L)>0 的局部，设同 L 入口干预产生 delta_R 和完整 delta_T：

```text
delta_L ~= -delta_R / R0'(L)
delta_T_at_matched_R ~= delta_T - tau * delta_R
tau = T0'(L) / R0'(L), in microseconds per unit Recall.
```

额外决策费用必须已包括在 delta_T 中，不能漏计或再重复加一次。tau/100 是每提升 1 个百分点对应的局部时间尺度。这只是局部一阶式；离散 L、平台段、非单调响应、斜率变化或大干预均可能使它失效。

当前表使用更明确的分段线性描述模型：分别以原三点插值 R0(L)、R1(L)、T0(L)、T1(L)，求各自 R=0.90 的 L0*、L1*。定义

```text
budget_credit = T0(L0*) - T0(L1*)
combined_penalty = T1(L1*) - T0(L1*)
matched_excess = combined_penalty - budget_credit.
```

这是插值模型内的精确恒等式，不是实际测得的分项归因。条件思想实验为：后继保持 R1(L)，且同 L 的非新增费用等于 T0(L)，只加平均费用 c。它加速的条件为 c < budget_credit；达到 5% QPS 增益需要 c <= budget_credit-T0(L0*)/21。后继若同时改变同 L 主搜索成本或 Recall 曲线，此上限就不适用。

## 3. 不能把任意成本权重当成约束问题的答案

在某个固定 L 可用拉格朗日量组织决策：

```text
loss_mu(q,a) = B(q,a,L) + mu * (1-R_K(q,a,L)),  mu >= 0,
```

B 包含在决策后执行动作必须支付的所有费用；共同已付费用单列。这个非负形式避免对负效用直接套用要求非负损失的定理。mu 的单位是时间/Recall，不能把 API 美元权重或任意归一化常数当作微秒权重。

正的 mu*delta_R-delta_T 不是全局 QPS 保证：它可能只表示更高 Recall 值得更慢。最终仍必须同时检查 Recall 可行和完整时间降低。离散/受限策略族不保证强对偶，单一 mu 也可能遗漏非凸前沿上的配置。例如三个固定配置 (R,T)=(.89,1),(.90,2),(.91,2.1)，rho=.90 时中间点可行且最快，但任何 mu 都不能使它唯一最小化 T-mu*R。混合两个 L 可凸化，却不在本任务范围。

已有 E117/E119 使用的是共同参考均值归一化的时间差，不能误说它们都忽视了成本。逐 query 相对时间、log(time)、胜出概率则可能改变目标。例：99 条查询各节省 1 微秒，一条慢查询多花 200 微秒，平均完整时间仍恶化；平均相对改善却可能为正。

## 4. 信息价值：值得看什么，而不只是怎样打分

固定 L、mu 和动作族。X 是当前已经获得的表示，Z 是拟议获取的一组新信息。假定信息获取不改变动作的潜在损失分布；若它改变 cache 或动作可用性，必须把这些效应并入状态/动作费用，不能直接套用下面的简式。

```text
m_a(X) = E[loss_mu(q,a) | X]
J(X) = min_a m_a(X)
V(X;Z) = J(X) - E[min_a E[loss_mu(q,a)|X,Z] | X] >= 0.
```

证明很短：观察 Z 后总能忽略它，继续采取观察前的最优动作。若最多只允许再获取这一组 Z，且其条件期望增量成本为 c_Z(X)，理想决策只在 V(X;Z)>c_Z(X) 时获取。实现还需支付获取判据本身的费用 g(X)。若后续预测分别有遗憾，V 应替换成两套实际决策规则的条件风险差，不能把理想 V 当成模型已获得的收益。

在实际规则比较中，c_Z 必须包含新增信息计算、富信息评分器推理、额外路由及其他未在动作损失中计入的工作，并只抵扣确实因升级而不再发生的旧费用。已经执行的便宜评分不能再次作为“被替代费用”减掉。g 是作出是否升级判断所额外花的费用，两者与动作费用互斥记账。

一个重要上界是完美信息价值：

```text
V(X;Z) <= J(X) - E[min_a loss_mu(q,a) | X].
```

它可以用于排除昂贵信息源，但右端也需要可靠的同域响应/成本，不能以同一训练集上的事后最大值假装已知总体上界。现有仅 Recall 的 oracle 没有完整动作 wall，不能直接代入作为微秒收益证书。

把两套实际决策器的条件遗憾分别记为 e_X、E[e_XZ|X]，则付费信息的实际条件净价值是

```text
w(X) = V(X;Z) + e_X - E[e_XZ | X] - c_Z(X).
```

信息可能有价值但新决策器利用不好；也可能因为旧决策器很差，新决策器虽非 Bayes 最优仍有实际改进。不能仅用 V 大小替代 w，更不能将模型的不确定性直接当作 V：若新信息只改变所有动作共同的费用、不改变相对排序，预测方差可以很大而 V=0。

二元获取门若估计 w 为 hat_w，规则为 hat_w>0 时购买，其相对理想获取规则的条件遗憾严格为 `|w| * 1{获取方向错误}`。在 |hat_w-w|<=epsilon_g 时，方向错误只能发生在 |w|<=epsilon_g，因此平均门控遗憾 <=epsilon_g*P(|w|<=epsilon_g)。整个付费信息模块相对不获取的净值为 `E[max(w,0)] - gate_regret - E[g]`。这解释为什么把门控也堆成昂贵评分器可能吃掉全部信息价值。这里仍是固定 mu/费用条件下的结论，不自动满足硬 Recall 约束。

这与 [Selecting Computations, UAI 2012](https://aima.eecs.berkeley.edu/~russell/papers/uai12-meta.pdf) 的元决策思想相通。本文只应用最简单的单组信息情形，不借用其独立臂/采样模型去证明当前确定性 ANN 的收益。多组信息可能互补：两个 XOR 位单独价值为零，合起来有价值，因此逐组贪心判停一般不全局最优。

### 已付费用与稀疏升级

若所有 query 都做小门控 g，只有 p 比例升级，升级平均费用 c，且升级相对未升级决策的条件毛收益为 b，则净收益为 p*(b-c)-g，而不是 p*b。若 p=0，仍损失 g；“几乎全回退”不是免费安全措施。若升级信息揭示应继续默认，升级费也已支付。

### 计算表示不是 Shannon 新信息

原始 q 已在内存中，而且固定搜索可能是 q 的确定函数；条件于完整 q 的无限能力 Bayes 动作可能是完美的。真正约束是从 q 计算可用决策所需的时间、模型表示和样本外估计误差。复用路由状态没有增加 q 之外的 Shannon 信息，它提供的是已经支付计算费用的表示。不能把旧模型失败解释为原 q 不含所需信息。

## 5. 误差要在选中动作与切换边界上算

以毛收益形式写 u_a=mu*(R_a-R_0)-(B_a-B_0)，默认 u_0=0。令 m_a(X)=E[u_a|X]，理想 X 策略价值 V_X=E[max_a m_a(X)]。

```text
actual scalar net gain = V_X - selection_regret - extra_decision_cost.
```

这是条件期望恒等式，前提是动作费用已一致定义。它把三种缺口分开：X 不足、模型选择错误、线上决策过贵。V_X 不是 E[max_a u_a]；两者之差是该表示下的事后/可实现差距，而不必是原 query 的不可消除噪声。

若所有动作分数误差满足 |hat_m_a-m_a|<=epsilon，贪心遗憾 <=2epsilon。这是已有的简单界。与动作平均 MSE 相比，应进一步看 gap 加权的实际选错损失。设最优与次优差 Delta，若 Delta>2epsilon 就不会选错；因此期望遗憾 <=2epsilon*P(Delta<=2epsilon)，允许 ties 的 Delta=0。没有统一误差事件或 margin 条件时不能声称这个界小。

构造 1000 个动作，只有一个错误动作被高估 .12，其他全准确。平均 MSE 只有 .0000144，却可每次选错并损失 .11。继续添加预测准确、从不选中的动作还能令平均 MSE 趋零，而决策损失不变。

### 预算迁移也属于误差账

若低预算条件价值 m_low 与目标预算 m_target 在同一动作族/表示上满足最大偏移 <=delta，而低预算模型最大误差 <=epsilon，则其目标预算决策遗憾 <=2*(epsilon+delta)。这是三角不等式，不是对真实数据的数值保证。成本和两个 K 都必须放到各自相容的价值定义里。

即使各动作 Recall 都随 L 增长，动作相对默认的好坏仍会反转。E120 已实际发现 K100 迁移损失，因此不能把目标区间只当最后画图的横轴。也不能靠改目标预算标签就宣称解决了可预测性。

### 有限样本与选择后乐观

固定模型/分组在独立样本上评估，和在同一批 query 上挑最高分组再报区间，是不同问题。多动作最大化与挑模型/阈值都会选择误差。交叉拟合不能抹去全项目历史曝光或训练折重叠。Recall 有界可以建立集中界，wall 若未给尾部/有界条件则不能照搬；截断 wall 得到的是另一个目标，不是完整 QPS 保证。

## 6. 对廉价表示的具体结构要求

用实际路由状态 X 构造有限分组 z=h(X)，每组只存一个入口动作。它能达到的信息价值为

```text
V_z = E[max_a E[u_a | z]],  V_X-V_z >= 0.
```

这是同一问题在粗表示上的最优值，不是查表模型必然达到的值。细化分组在无限数据、免费计算下不会降低 V_z，但有限样本方差、表大小/访存和推理费用会增加。因而应优化“分组遗漏的决策价值 + 估计/动作选择损失 + 实际查询费用”，而不是以教师动作模仿准确率为唯一目标。

若一个表示单元内每个动作条件均值相对组均值的偏差均 <=eta，组最优动作相对 X 最优的遗憾 <=2eta；再加估计误差 epsilon，得到 <=2eta+2epsilon。证明仍是插入组均值、利用组动作最优、再三角不等式。这提供可反驳要求：组内必须能共享相对默认收益，不能只有画像几何接近。

对固定实数 IP 图搜索，固定入口和固定 tie 规则下，一个完整执行分支由有限的距离比较决定；保持所有严格比较符号就保持离散执行结果。原路由只覆盖这些比较的一小部分，不能由“路由轨迹一样”推断主图响应相同。浮点实现还需留出舍入误差裕量，实数超平面论证不是原生 bit 保证。

因此本轮优先保留审查的结构是：从原 GT10 路由已计算的状态提取极小表示，直接决定原 top3 的保留方式，不追加全 H 扫描。其目标不是证明“轨迹一定有效”，而是检查它是否在最终 top3 分数关系之外解释可迁移净收益。若没有，就不能继续扩树/扩 trace 或用新模型名字续跑。这不是对所有其他信息结构的不可能性判断。

### 直接保留约束，而不是只调一个权重

对于预先冻结的有限分区 z、有限动作族和一个全局 L，可在离线直接组织如下问题，而不是宣称某个 mu 必然对应 rho：

```text
choose a_z for each cell z
minimize T_common + sum_z p_z * t(z,a_z)
subject to sum_z p_z * r_K(z,a_z) >= rho.
```

t 必须含动作执行的完整增量费，T_common 包括状态提取/表访问等公共费用。动作互斥、每格只选一个；在线仅返回预编译动作，不在线求解优化问题。若同一策略需同时服务 K1/K100，应有两个召回约束；也可分别冻结两个 K 的表，不能以等 K 平均掩盖单项失败。该有限组合优化是一般方法，不是本文新算法。

该离线可加形式还要求 t(z,a) 不因整张表改变而发生未建模的执行上下文漂移。否则它是选提案用的代理优化，不是完整系统目标的精确改写；对同一冻结策略实测得到的整体 T 误差界才有资格用于下面的证书。

误差条件可直接转换为约束保守量。假设固定候选族中所有策略均满足 |R-hat_R|<=e_R、|T-hat_T|<=e_T，则选择 hat_R>=rho+e_R 的策略可保证 R>=rho；若它还满足 hat_T+e_T<T0 的已知下界，就有速度收益证书。比较一个估计默认时，应使用 hat_T+e_T<hat_T0-e_T0。证明只是两次不等式相接，但它比“scalar utility 正”更贴合目标。当前没有这些数值误差界，不声称已经满足。

如果仅有细胞内估计，必须另外计入 p_z 的估计误差和分布迁移；同一数据用于挑分区、挑动作、再按单策略区间验收无效。有限类统一界需要明确类规模/选择规则及样本条件；wall 无已知界或尾部假设时，不可直接用 Recall 的有界集中界。完整串行 wall 最终仍须实测。

### 同轨迹仍可能没有决策价值

设两类 query 等概率、原路由状态相同，对某替代入口的净收益分别为 +b、-b，默认收益 0。该状态的条件最优价值为 0，而知道 query 类别的价值为 b/2。因此路由轨迹共享支持再密，也不保证其分区保留动作收益；它必须降低的是相对收益的条件混杂，而非只把相似 query 聚在一起。

## 7. 当前不能跨越的证据边界

- 已知：record125 的所有同 L 召回均值正、完整速度负；成本核算给出了小额有条件预算。
- 已知：原小图实现内部有上层结束节点、距离和已有比较，但现有公共 searchKnn 只返回最终 heap；新增导出并未实现。
- 未知：这些状态在目标预算上相对 E117 六特征是否增加 query-out 决策价值。
- 未知：导出/查表的真实额外 wall，以及其对主搜索 cache 的影响。
- 未知：符合这些结构约束的策略能否同时通过两集两 K 的完整 Recall-QPS 门。

下面的候选设计仅是由约束导出的研究对象。没有新训练、查询、GT 或默认替换；没有把一般决策论包装成 ANN 新定理。
