# 候选收敛与下一次最小证伪

截至本次研究：**没有通过信息、完整成本和新颖性三项审查的实施候选。** 只优先保留 A 的一个具体假设，B 暂不立项。不启动模型、标签或性能实验。

## A. 原路由上层状态的离线动作表

状态：`HOLD_MISSING_TARGET_STATE_RESPONSE_COST`。这是唯一优先研究问题，不是已授权实施 GO。

### 明确操作

保持 GT10 画像、小图、ef/top3、原排序/tie 和整个主图搜索不变。一次普通路由结束时保留其进入 base 层前的 `currObj`，称上层结束节点 z；原 top3 仍完整跑完。以 z 直接索引一个离线冻结的字节动作表，动作 0 返回原三入口，动作 1/2/3 返回这次实际 top3 中对应 rank 的单入口，然后调用原搜索。K 与 L 在配置级固定，不能按 query 改预算。

线上信息仅为上层结束节点及原 top3 的 ID/排名。不新算 query 投影、真实入口距离、第二路由或完整 trace，不扫全 H，不以主搜索失败状态探测决策。缺表项/未获支持格回原三入口，但仍支付导出和查表费用。当前公共 `searchKnn` 不返回 z；上述导出及动作表都未实现，不属于现有 API 能力。

从原源码可见 z 已作为 base 搜索的起点；旧拓扑元数据中两集 level1 均为 52 个节点，因此可能状态最多 52 个，不是 H 的 815/821 个都可达。采用内部 ID 直接索引时，单配置 uint8 动作表为 815/821 字节，避免为了省几百字节增加动态哈希。该大小不含任何拟合器，也不证明 CPU cache 或导出费用为零。旧图元数据与 record125 图 SHA 记录相同，详见 [事实核验](reviews/router_state_facts.json)。

表必须绑定原小图 SHA、内部 ID/真实 hub 映射、画像、metric、top3/tie 规则及 K/L 身份。图重建或这些条件变化即使 H 数相同也不能继承表。z 可能合并多条原路由路径，不代表凸几何簇或同质主图响应。

### 监督与离线目标

需要同一 query、实际 z、完整四动作、实际目标 L、分别 K1/K100 的响应和可比动作时间。按 [理论第 6 节](theory.md) 的有限分区约束目标选择动作：最小化平均完整时间、保留召回余量，而非追求教师动作模仿准确率或逐 query 相对耗时。在线不解优化问题。

现有 E117 的四动作主要在 L128；E120 的七策略目标预算标签不是同一次实际 top3 的三个 rank-single；旧路由工作量 CSV 只有计数，没有 z。不能拼接它们伪造本候选的目标预算监督。本次没有穷尽每个历史二进制格式，也没有重新运行路由恢复 z；当前缺口明确为“尚未找到已对齐缓存”，而非证明所有旧缓存均不存在。

### 收益假设与旧方法区别

唯一实质假设：原小图上层进入哪个局部区域，能在最终 top3 分数关系之外，区分某个 rank-single 相对原三入口的目标预算救回/损伤及时间。最多 52 状态提供了一个有限共享单元，但不保证支持均匀、收益同质或查询外迁移。

这不同于 E117 仅用最终画像/真实距离关系分树，也不同于 E118 另算主搜索比较投影；但与 E116 的 ID 绑定、E35 trace 分析及一般算法选择存在明显亲缘。A 的动作不换 H 外入口，状态是路由内部上层节点而非最终画像 hub。**这些区别足够写出不同的可反驳问题，尚不足以称论文创新。** 若 z 无增量收益，不允许改成更多层/长 trace/更深树或另命名继续。

### 完整成本与三项可反驳预测

`T_A = 原路由 + z 导出 + 表访问/动作整理 + 所选动作主搜索 + 输出`，并包含 cache 交互。状态已计算不等于导出免费。沿用当前 KNN 的 Recall 曲线时，Yandex 只能容许约 6-7 微秒新增费，但 A 的 Recall/同 L 搜索成本尚未知，不能直接把该条件预算当它的真实上限。

1. 强制默认的状态导出版本应逐 query 保持原路由入口、搜索返回及距离 bits；若不一致，先修实施错误，不能算方法负结果。
2. 使用同一监督，z 表必须在查询外优于最强固定动作，并提供超出旧六特征控制的增量决策收益；只在拟合内挑区域有效或按 z 置换同样有效，则假设不成立。
3. 在配置固定 L 的真实完整 wall 中，决策费用必须被搜索节省/召回换预算收益覆盖；仅 Recall 正、仅 NDC 低或极少数 query 换入口均不通过。

## B. 只在值得时追加一组评分信息

状态：`DO_NOT_IMPLEMENT_NO_NEW_INFORMATION_CASE`。

具体审查实例：先跑原 GT10，用已返回 top3 的画像距离关系决定是否再算这三个真实入口与 q 的点积；随后仍只在上述四动作中选择。监督必须同时有“未付费规则/已付费规则”的查询外动作损失、额外三次点积及评分 wall。全部 query 付 gate，部分 query 再付真实点积，即 `net = p*(b-c)-g`。

本例有清晰入口操作，却复用了 E117 已检查的真实入口距离信息，条件升级又与 E25、CP2003/SATzilla 重合；没有证据显示这组信息在目标预算上具备新的条件净收益。用更强置信评分代替上述 gate 不填补这个缺口。故不作为第二个待运行实验，也不绑定/压缩现有 TargetKNN。

## 下一次最小证伪设计：仅供另行授权

下面不是运行协议批准，也没有 runner 排队。允许停止在任一门，不要求先训练完整模型。

| 门 | 最小问题、控制和停止条件 |
|---|---|
| 0：只读缓存清单 | 查是否已有与目标预算、query 身份、四动作和 z 对齐的缓存；无则列精确缺项，不自动补全 H，不把旧单入口/旧 L 近似成所需标签 |
| 1：成本与原生一致性 | 只导出 z、强制原三入口，对照未改 GT10；两集两 K 各一个已覆盖 90% 的固定 L，三次完整 wall。预锁原生 parity、计时区间/线程和成本判据。若导出改变返回先审计错误；若付费明显超出该动作族可信收益，不训练。没有可信收益界时只能报告未知，不能用旧 KNN 的条件预算当 A 的普遍上限 |
| 2：信息及同监督控制 | 将有限 z 表与最佳固定动作、原六特征简单控制、训练侧 z 置换对照放在同一监督和身份下；六特征控制保留 E117 的深度 2/min-leaf512，不作调参重启。必须同时检验目标预算 Recall 约束、绝对平均时间及相对控制的收益，不以平均 MSE 过门。优于这个固定控制不等于证明超过六特征的所有可能函数 |
| 3：只对通过者测完整曲线 | 模型先冻结，仍每配置固定 L，以覆盖目标召回的少量点比较完整 wall；有成本计入的强制默认控制；只有过门后另定新的测试身份。曝光旧 query 只能作开发证伪 |

建议的资源外框，不是本次授权：首次信息试验最多复用两集各 4096 条已曝光 query，按源/字节角色核验后固定为拟合与证伪两部分；每集两个实际 K，各仅一个目标区间 L、四动作，全四动作上限 65,536 次 NSG（不假定 K1 可由 K100 替代）。拟合/证伪各半仅是最小开发设计，不保证统计功效，更不是新鲜测试。L 可先候选 Web K1=1000/K100=1250、Y K1=128/K100=256，这些是 record125 既有默认达到 90% 的最小已测点；新样本未必达到同 Recall，必须重新核验可行性，不能追调 L 来救门。

成本门若三次、三个方法（默认/强制默认/A）全执行，在两集两 K、每集 4096 条的一点上最多再有 147,456 次 NSG；首次原生 parity/warm 可单列至多 32,768 次。首次一点证伪合计上限 245,760 次 NSG、10 分钟受控作业、单进程 CPU15/一线程、32 GiB 峰值；任一限制不足即停止并报告，不自动加预算。门 3 的完整曲线不在此上限内，不能自动接续。这些均需未来再次审批并冻结，当前计数全部为 0。没有必要为一个尚无信息证据的表，再先付全 H 标签和大模型训练费。
