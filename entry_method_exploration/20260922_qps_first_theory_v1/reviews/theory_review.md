# 推导与候选自审

本文件是同一会话中的逐项自审；独立数值实现不代表独立人员评审。不启动新搜索/训练。

| 检查 | 结论与边界 |
|---|---|
| 完整 QPS | 分段时间总和与批量 wall 必须相等，QPS 是 N/wall。三重复只描述运行波动，不增加 Recall 样本数 |
| 成本恒等式 | 完整差值 = 非主搜索增量 - 主搜索节省，严格成立；当前没有各分项，不能声称 scorer 单独耗时 609/633/287/293 微秒 |
| 插值推导 | 只在各自同一批的相邻点内插值；模型内 credit/penalty/excess 恒等式与旧 record125 的 R90 比例独立恢复。插值 L 可以非整数，不是新测配置 |
| 零新增费思想实验 | 固定现有 Recall 曲线且令同 L 非新增部分等于默认；小于 5% 的结论只对这个条件族成立，不是所有入口方法的上限；5% 是敏感性参考，不新加用户门 |
| 条件动作价值 | 需要可比较的潜在损失。cache、跨 query 干扰可能令费用依赖整张策略；并入状态也不自动消除未来状态效应。明确降为代理，最后测完整 wall |
| VOI | 单组信息、理想条件风险下降、信息不改变潜在损失时非负；门控和查询表示的计算费单列；一般多组贪心不保证最优 |
| 准确率与决策误差 | 胜率/MSE 不能替代幅度加权遗憾；2epsilon 需要统一误差事件；gap 细化不凭空提供 margin 分布 |
| 预算迁移 | 2(epsilon+delta) 是条件上界，未估计 delta；各动作自身 Recall 单调不能保证相对优劣不翻转 |
| 召回约束 | 非凸有限策略不保证某个 mu 找到约束最优；保守 Recall 与时间界直接推证书，但当前没有可用数值界 |
| 论文迁移 | 不把 API 单价当 latency；RouteLLM 确实计入了路由开销；多专家风险转换保留有界损失、假设类与 gap 条件，非自动部署保证 |
| 候选 A 的新颖性 | 上层节点映射属于一般离线算法选择；仅有不同可检验信息源，尚无新颖性 GO。原 top3 动作、时间监督和小模型均已有前作 |
| 52 状态 | 旧 level1 节点数给可能上层结束节点数上界；不证明每个节点可达、样本量足够或同格动作一致。单格平均等于 0 的相反响应反例仍成立 |
| 未实现能力 | searchKnn 未导出 z，动作表未实现；spec 仅登记只读工具，不登记候选为生产能力 |

## 数值检查

[独立检查 JSON](independent_verification.json) 使用 Decimal 重写插值、无导入原分析实现；核对 24 方法点、12 匹配点、4 个当前可达阈值和 4 个原文件 SHA。每组 729 种记录时间组合均保留 R90 更慢及条件零新增费增益小于 5% 的方向。这是波动包络，不是置信区间。

12 类算术检查覆盖用户四种必查情形，并增加回退成本、XOR 互补、胜率/幅度错配、相对时间/平均时间错配、非凸约束点和 QPS 口径。统一误差/margin/迁移界有 5000 组有限数值检查，VOI 有 1000 组；它们用于捕捉实现/符号错误，不能替代数学证明或真实方法验证。

[补充核验](supplement_verification.json)直接从 E103 三轮原 wall 和 query 数恢复 8 个覆盖判断/6 个可达阈值的时间及斜率，并检查跨 query cache 和同路由状态相反收益两类反例。[证明笔记](../proof_notes.md)另给付费信息实际利用误差与二元门控的代数推导；此处不把它们标成已做真实数据验证。

## 审查后修订

- 将“唯一值得保留”改为“本轮优先保留”，不外推其他结构无效。
- 明确离线动作时间表的可加性也有上下文条件；跨 query cache 影响不能由独立动作标签证明消失。
- 候选收窄为单个已存在的上层结束 ID，不再笼统追加完整 trace/计数器/多特征。
- 未来方案只是开发证伪外框，不是已经批准的下一轮；当前实施候选数为 0。
- 付费信息的实际增量费用明确包含富信息评分器推理，不仅包含特征获取；已付便宜评分不作为被替代费用抵扣。
