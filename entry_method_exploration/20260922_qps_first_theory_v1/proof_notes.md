# 条件推导的证明笔记

目的：检查本轮理论链的符号、量纲和适用范围。均为已有决策论/基本不等式的具体应用，不宣称新定理。除第一节逐段记账外，动作风险结论要求动作集有限、期望存在、潜在费用在所用上下文中可比较；跨 query 执行干扰未覆盖时，只能解释代理风险。

## 1. 收支与吞吐

对两个满足召回约束的已实现配置，令 T_j=C_j+S_j>0。则 T_1-T_0=(C_1-C_0)-(S_0-S_1)，所以 QPS_1>QPS_0 等价于 S_0-S_1>C_1-C_0。要求 QPS_1/QPS_0>=1+g，等价于 T_1<=T_0/(1+g)。对于 g=.05，必须减少 T_0/21，而不是 T_0*.05。

在条件插值思想实验中，T_new=T_0(L1)+c，T_ref=T_0(L0)，所以 c<=T_0(L0)-T_0(L1)-T_ref/21 才能达到 +5% QPS。新方法若改变自身同 L 搜索成本，须重新定义 T_new；该条件数值不能越域使用。

## 2. 单组信息与实际利用误差

记 m_a(X)=E[ell_a|X]、m_a(X,Z)=E[ell_a|X,Z]。由塔式期望和逐点 min，

```text
E[min_a m_a(X,Z) | X] <= min_a E[m_a(X,Z) | X]
                             = min_a m_a(X).
```

从而 V>=0。同时 min_a E[ell_a|X,Z]>=E[min_a ell_a|X,Z]，再次条件期望得 V<=min_a m_a(X)-E[min_a ell_a|X]。这两个不等式不要求 Z 是随机采样；确定性特征在总体 query 分布上也可使用，但计算该特征的费用不能省略。

实际便宜策略的条件风险为 J(X)+e_X，实际富信息策略观察前条件风险为 E[J(X,Z)+e_XZ|X]。相减再扣获取费即 w=V+e_X-E[e_XZ|X]-c。只有一个可选信息组时购买阈值是 w>0；若存在后续组合信息，必须计其继续决策价值，一步阈值不保证全局最优。

此处 c 在实际路径上包含信息获取、后续评分器推理及任何尚未计入动作风险的增量工作，不仅是点积/特征费用。只有确实不再执行的便宜路径工作可抵扣；已经付出的费用不能减。购买判据自身的额外费用 g 另计，避免漏计和重复计费。

## 3. 二元获取门的误差

理想门获得 max(w,0)，估计门获得 w*1{hat_w>0}；相减恰为 |w|*1{方向错误}。若 w>epsilon_g 且 |hat_w-w|<=epsilon_g，hat_w>0；若 w<-epsilon_g，则 hat_w<0。故错误只发生在 |w|<=epsilon_g，遗憾至多 epsilon_g，得到边界概率细化。估计门自己花费 g，不管是否购买都会支付。

这个界需要对真实条件价值 w 的误差，不是原模型分数 MSE、ensemble 方差或 softmax 置信度。若购买某组信息会改变主搜索 cache，风险定义须包括这种变化；若会影响以后 query，独立查询的公式不再自动等于整批 QPS。

## 4. 多动作选择误差与预算迁移

设 a*=argmax m_a、hat_a=argmax hat_m_a，则

```text
m_a* - m_hat_a
 = (m_a* - hat_m_a*) + (hat_m_a* - hat_m_hat_a)
   + (hat_m_hat_a - m_hat_a)
 <= epsilon + 0 + epsilon.
```

若最优次优间隔 Delta>2epsilon，任一非最优动作都不可能超过最优估计分数，所以遗憾为 0。把这两个事件合并得到平均遗憾 <=2epsilon*P(Delta<=2epsilon)。它要求统一误差界同时覆盖所有动作；不能把平均 MSE 的平方根当这个 epsilon。

若目标预算 m_target 与低预算 m_low 的最大差 <=delta，则 |hat_m_low-m_target|<=epsilon+delta，上一证明立即给 2(epsilon+delta)。没有估计 delta，就没有实际数值迁移保证；换标签只能改变其中一个误差来源。

## 5. 表示压缩

设 z=h(X)，bar_m_a(z)=E[m_a(X)|z]。由 max 的凸性/可忽略更细信息，E[max_a m_a(X)]>=E[max_a bar_m_a(z)]。若每个格内 |m_a(X)-bar_m_a(z)|<=eta，组最优动作相对 X 最优损失至多 2eta；若表项估计另有统一 epsilon，再加 2epsilon。这是粗分区偏差与估计误差的显式分离，不保证 52 个真实路由格满足小 eta。

原 HNSW 上层结束节点相同可以来自不同执行路径；它是多个比较分支区域的并集，不必是凸簇。即使整条原路由轨迹相同，也不能推出主图不同入口的相对响应相同。两个等概率 query 在同一格内收益 +b/-b 时，格信息价值为 0，细信息价值为 b/2，直接反驳“有共享支持就有可部署收益”。

## 6. 召回与时间的保守证书

在一个已冻结候选族的同时误差事件上，若 |R-hat_R|<=e_R、|T-hat_T|<=e_T，选择 hat_R>=rho+e_R 得 R>=rho；若 hat_T+e_T<hat_T0-e_T0，则 T<T0。只有标量化效用为正时，上述两个条件未必成立。

这些界可能很松：52 个格不代表每格都有足够样本，分区选择和稀有动作会放大估计误差。当前不提供未经验证的 IID/有界 wall 条件，也不把样本内 cell 均值当总体均值。实际开发证伪可以发现大失败；它不自动提供微小正收益的正式证书。

## 7. 强制检查的四种失败

| 失败 | 具体构造 | 推翻的错误桥接 |
|---|---|---|
| Recall 提高却更慢 | 默认 (.90,100us)、(.91,105us)，候选 (.91,115us) | 同 L 召回提升不等于同召回加速 |
| 完美选择仍过贵 | 默认每条 100us；替代在两半为 80/120us；完美选择只需均值 90us，但打分费 15us，合计 105us | oracle 或完全正确预测不等于净收益 |
| 平均误差小但选错 | 1000 动作中一个错高估 .12，平均 MSE=.0000144，每次选择损失 .11 | 平均预测误差不保证决策正确 |
| 低预算好处不能迁移 | 默认 Recall .80→.90，替代 .82→.899 | 各动作随 L 改善不保证相对增益保持 |

补充的串行 cache 构造：默认两 query 80+80us；从独立批次取候选首 query 50us 拼第二条默认 80us，会预言 130us。但若候选破坏第二条 cache、额外付 50us，真实为 50+130=180us，比默认 160us 更慢。该构造说明为什么离线相加只能在上下文条件下使用，不声称这是 record125 差值的真实原因。
