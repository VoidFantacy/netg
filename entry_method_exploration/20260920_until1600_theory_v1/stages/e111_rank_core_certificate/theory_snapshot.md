# 从候选池保留规则推出一个目标可达充分条件

2026-09-20，E110之后的理论接续。基础推导直接针对当前完整有限池循环，尚未声明首次性；条件覆盖范围由E111另作核验。这里不用目标–hub cosine区域代替图上可达关系。

## 1. 条件与命题

固定query q、有限有向图G和搜索容量L。设B_m是按搜索距离排序的真实前m个节点，m≤L；距离有限，B_m与外部严格分离，或采用与GT一致的确定性完整并列规则。当前kernel会展开所有最终保留的pending节点，且没有额外的时间/NDC提前截止。

**保留引理：B_m中任何已被发现的节点，在这一搜索过程中不会被候选池驱逐，并且最终会展开。**

证明：其中任一v至多有m−1个排名更优节点。若v被容量L的池排除，必须同时存在至少L个优于v的不同节点，与m≤L矛盾。因此发现后一直保留。有限图中每个节点最多首次发现一次，插入次数有限；原循环终止前会处理所有保留的pending节点，所以v最终展开。该结论是排序和实现语义的结论，不需要欧氏距离或三角不等式。

设初始种子集S，首个被完整展开的节点r已知。定义进入核心的集合

`A_m(q,S,r) = (S ∩ B_m) ∪ (N_out(r) ∩ B_m)`，

以及核心内部闭包`C_m = Reach_{G[B_m]}(A_m)`（包含起点自身）。由首行展开和上述引理沿路径归纳，**C_m中的节点都会被发现并保留**。于是：

- 返回K=1时，若真实GT1∈C_m，则必返回GT1；
- 返回K=100、m=100、L≥100时，实际命中数至少为|C_100|；
- 对单入口h，r=h。多个入口的r必须使用真实初始raw-IP排序；不能直接把画像top1当r。E110干预才显式保证r为画像top1。

初始种子不在B_m也可使用：它自身未获保留保证，但r既然已经完整展开，就已发现其B_m邻居。其它非首种子若未进入B_m，不能无条件加入它们的邻居。

## 2. 和GT10区域覆盖的实质区别

GT10的区域覆盖按目标与hub的cosine归属建立，未要求存在可保留路径。这里用真实有向NSG的邻接及query特定前m名节点，给出满足条件时的**实际Recall下界**；它仍不是实际效用上界，不保证最大化下界会提高已很强的基线。

条件可能很保守：搜索能经过B_m外节点到达目标，所以没有证书不等于不能命中。已有GT只有100宽，本次m=64/100不能代表所有L更大的完整排名核心。先统计证书覆盖当前成功query/目标的比例、全H是否存在证书入口、以及证书能否保证恢复现有失败，才能决定它适不适合作为监督信息。不能先训练后解释。

## 3. 不扫描所有入口搜索的计算方式

每query抽出G[B_m]，对至多100个节点计算有向传递闭包。预先从原H的出邻居建立`base ID→hub列`倒排表。对B_m中每个节点v，把Reach(v)位集并入所有以v为出邻居的hub；hub本身在B_m时也并入。得到原H全部单入口的条件命中下界，无需执行N×H次NSG。

成本包括原GT100、底图和H的既有获取成本（不能计零）、读取图、每query核心闭包和倒排聚合；本轮增量不计算新GT、不构图、不搜索、不训练。它生成新的图派生诊断标签，不能写成“没有生成任何标签”。

## 4. 实现与数值边界

数学命题假设B_m是真正按同一距离/并列语义得到的排名核心。现有GT100来自已冻结完整raw-IP精确搜索，E111继承其身份；m=64有第65名的已存分数可检查间隔，m=100缺少第101名，不能新宣称已独立验证其外部严格分离。实际kernel采用浮点距离、只比较distance的Neighbor规则，故需逐项对已有真实输出验证证书包含关系，报告分数并列/边界信息。经验零违例不替代全数据的浮点误差证明。

该命题也不覆盖提前NDC截断、不同优先队列、并发非确定搜索或只处理部分邻接行的执行。E111只分析已完整返回的E107/E110对应kernel结果。

## 5. 前作与当前下一步

[Adaptive Entry Point Selection](https://arxiv.org/html/2402.04713v1)的B-MSNET/欧氏路径界、[Distance Adaptive Beam Search](https://arxiv.org/html/2505.15636v1)的可导航图与自适应停止条件，均提示需要具体路径和停止假设。本地命题是保守的排序核心可达证书，未改变停止条件，未宣称与上述论文同等强度或新颖性。检索亦定位到[Graph Based K-Nearest Neighbor Search Revisited](https://doi.org/10.1145/3736716)，目前出版社全文访问403，尚未完成其LMG理论核对，不作首次性判断。

若证书覆盖薄弱，停止用它训练的投入，继续把它保留为成立条件；若有足够跨数据保证恢复量，后继也须再证明不使用GT的预测与真实成本。这不是复活全局BTG扩散或旧64NN Atlas：当前只计算query特定排名核心的精确闭包，尚无新预测器。
