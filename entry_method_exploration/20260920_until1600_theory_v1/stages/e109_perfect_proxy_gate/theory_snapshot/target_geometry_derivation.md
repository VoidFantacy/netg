# 查询到目标几何的学习：先检验代理，再决定是否训练

2026-09-20，E107真实矩阵运行期间的理论草案。此文件没有选择或启动训练；数值结论仍待E107及独立锁定的代理检查。它回答下一种学习目标如何从GT10的解释中推出，以及为什么不能直接换网络。

## 1. 从逆向画像到正向预测

GT10为每个真实hub聚合需要其目标区域的query方向，估计的是重加权query均值方向。另一种信息方向是直接预测一个query的相关目标几何。令固定底库上该query的GT前10个目标单位方向为t_j(q)，定义

\[
m(q)=\frac1{10}\sum_{j=1}^{10}t_j(q).
\]

这不等于现有GT10画像。现有画像聚合query，m聚合目标。m不额外单位化，以保留目标分散度；仅用于按单位raw hub评分时，正数归一化不改变排名。底层NSG仍必须用原始query/raw-IP，不能把预测向量替换其查询语义。

若T是在该query的10个真实目标方向中均匀抽取的一个，则E[T|q]=m(q)。平方损失满足

\[
E\|f(q)-T\|^2=E\|f(q)-m(q)\|^2+E\|T-m(q)\|^2.
\]

交叉项条件期望为0。直接用已有GT10计算的m监督f，避免再随机抽目标的标签方差。这是标准条件均值恒等式，不是新的统计定理，不保证有限样本泛化。GT目标依赖固定底库及metric，二者变化后标签失效。

## 2. 严格保证只属于哪一个代理

对单位raw hub u_h及三个不同入口S，定义平均目标相似度

\[
C(q,S)=\frac13\sum_{h\in S}u_h^\top m(q).
\]

按u_hᵀf(q)取top3，得到S_f；按真实m取top3得到S_C。对任意S，平均三个单位向量的范数至多1，故分数误差至多ε(q)=‖f(q)−m(q)‖，从而

\[
C(q,S_C)-C(q,S_f)\le 2\epsilon(q).
\]

真实m的top3是这个加性几何代理的最优解，**不是NSG搜索效用oracle或Recall上界**。代理没有目标覆盖的去重/互补项，也没有候选池竞争。它甚至可以偏好三个几乎重复的入口。

仅当另有明确a(q)、b(q)≥0，且对全三入口动作族都有

\[
|U_{K,L}(q,S)-a(q)-b(q)C(q,S)|\le\delta(q),
\]

才有相对真实搜索最优动作的条件界

\[
U(q,S_U)-U(q,S_f)\le2\delta(q)+2b(q)\epsilon(q).
\]

证明是插入上述两端近似、再利用S_C最大化C。当前没有证据使δ很小；E107的强连通反例已表明不能直接假定单调的几何代理代表有限beam搜索。K1/K100还分别与训练目标数10存在目标差异。不存在“只要MSE降低就提高Recall”的无条件推论。

## 3. 能证伪什么，以及不能证伪什么

在训练任何预测器前，可以只用预锁的既有fit行，计算不可部署的真实m，并执行其三个几何入口的原NSG搜索，对照相同query上的原GT10 exact3和原单位hub exact3。若这个完美几何预测对应的实际入口都没有明确净收益，则没有足够依据花成本拟合它；停止此候选目标，保留结果。

这是研发投入门，不是“不可能性证明”：近似f可能意外选出更好的搜索动作，真实m也不是实际Recall上界。但是，用代理拟合误差论证收益的理论链此时缺少实证支持，不能以追加网络、epoch或seed修补这一缺口。相反，即使真实m明显更好，也只支持进入一次受控预测实验，不能说明m能从新query准确预测，更不能说明完整在线wall能通过。

若代理检查通过，后续需分别锁定简单线性预测与一个轻量非线性预测，使用同一稠密目标、原GT10对照和独立模型冻结。学习的是m，而非旧E104的56个实测集合教师概率。要分开报告代理误差、真实入口、K1/K100、失败query及最终在线成本。当前尚未锁定任何网络/优化器/epoch，不能把此段写作已实现方法。

## 4. 与已有工作的区别和重合

E104已使用真实三入口教师集合概率，不能说它缺联合标签。本草案改变监督对象为全fit的目标几何，其潜在优点是稠密、可共享、无新逐动作搜索标签；潜在缺点是重新引入几何到搜索的代理偏差。两者改变数据量、监督和表示，不能把未来差异单独归因于非线性。

E79/E80使用全GT10或按hub条件的目标均值来划分训练query，最后仍以query均值导出多画像。本草案拟直接预测目标几何用于raw hub路由，区别在在线映射及监督用途；“用了目标均值”本身已有历史，不能作为创新。原E79/E80失败不被覆盖。

LeanVec以双线性投影减少原query–base内积的近似误差，并用于压缩搜索；GleanVec采用分区后的局部线性变换。它们说明query变换/双侧表示早有工作，本草案的目标是条件相关目标方向而非保持所有原始内积，仍不能据此宣称首次性或CCF B贡献已成立。本文不是这两种方法的复现。
