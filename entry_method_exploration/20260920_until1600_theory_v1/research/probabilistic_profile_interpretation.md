# GT10闭式画像的概率解释及其限制

2026-09-20，只作理论推导，0新标签、训练或搜索。结论是解释已有构造的一个条件模型，不声称真实query已经通过该分布假设的拟合检验，也不据此开启新的浓度/先验调参分支。

采用单位query x、单位画像方向μ_h。vMF方向分布写作`f_h(x)=c_d(κ_h) exp(κ_h μ_hᵀx)`。其归一化样本和方向估计、混合后验见[Banerjee等，JMLR 2005，§2–3](https://www.jmlr.org/papers/volume6/banerjee05a/banerjee05a.pdf)；下面将该标准形式代入当前固定GT权重，是本地推导。

固定公共κ>0及GT10权重a_ih，令画像方向先验`p(μ_h)∝exp(κ μ_hᵀu_h)`。固定权重的加权对数似然加先验为

`Σ_i a_ih log f_h(x_i) + log p(μ_h) = const + κ μ_hᵀ(u_h+Σ_i a_ih x_i)`。

在单位球约束下，其最大后验方向恰为当前`p_h=normalize(u_h+Σ_i a_ih x_i)`，非零向量条件与源码一致。分数权重应理解为加权似然或固定责任度的优化；不能把它们当作十个独立query，也不能说GT10实现了完整EM。当前a来自真实目标向hub的硬/软分配，不是从这套query混合模型迭代推断出来的责任度。

若再假设各hub先验概率π_h相同、κ_h相同，且单个方向分布描述各标签条件query，则最大后验hub排序等价于`p_hᵀx`。对非零原query q，单位化只乘公共正比例，精确排序同`p_hᵀq`。这解释了“把目标区域关联的query求方向画像，再按内积路由”在哪种模型下合理。

当先验与浓度不同，完整后验分数应是

`log π_h + log c_d(κ_h) + κ_h μ_hᵀx`。

当前单位画像内积一般不包含前两项，也未显式拟合不同κ_h；多峰条件query同样不能由单个均值方向完整刻画。这些都是**模型条件**，不是已经测得的失败原因。即使把条件区域后验预测得完全正确，优化的仍是GT目标区域标签；E109已经说明这一代理不能无条件转成有限beam Recall。不能因发现条件不成立就直接训练更复杂分布、再期待它解决图搜索桥接问题。

当前研究中的正确用途是三点：说明GT10的归一化平均有明确优化意义；把“方向原型有效”所需的统计假设写出来；把统计假设与图上的可搜索性假设分开。它不提供GT10对GT1的普遍优势、完整因果解释或新的论文首次性。已有多画像方法的实际记录见[55](../../../experiment_history/55_multimode_index.md)、[56](../../../experiment_history/56_multimode_wall.md)，本次不重启这些版本。
