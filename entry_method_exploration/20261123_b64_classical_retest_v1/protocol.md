# E252 经典平方 L2 数据的新 B64 迁移复测

Deep10M（96维）、BIGANN-SIFT10M（128维）和 GIST1M（960维）使用 E183 原始底库、NSG 主图、三路 GT10 画像与 JOINT32 表。GT10 家族固定采用 E197 对应配置，Deep 和 SIFT 为 soft，GIST 为 hard。三集均沿用原平方 L2 和 ID 顺序。真 K1 与真 K100 分别执行完整查询，K100 的 L 至少为 100。

Mixed64 按 E243/E251 的规则，在原 B32 每行完整有序前缀上做联合覆盖续填。每集原前 16,000 条拟合加其剩余 4,000 条和前 4,192 条 QGT learn 角色，合计 24,192 条有 exact L2 GT100 的真实查询。新增标签沿用 E97 的同底库穷举标签。QGT 与完整 fit 的源行 ID 互斥，全部训练与整个公开查询集按向量字节排重。两个新增训练来源参与过原 GT10 画像或入口离线构建。冻结主搜索的真 K100 L176、192、208 返回，按每个真实漏点的 query/L/target 事件进入 E226 greedily extend 编译器。在线沿用三行并集、主返回排除、原距离精算与合并。两个方法使用 E211 发布库的 L2 标量主搜索，残差采用同一原生标量距离计算器。B32 调用原 E206 fast_apply。

公开查询窗在新表评测前固定，两个 10M 数据都采用 PCG64 seed 252 选 3,072 行并以原顺序执行，GIST1M 全部 1,000 行。各数据/K 网格和达标阈值固定在代码及配置，以历史 E183 覆盖范围预设。每个方法/K/L 两次正式完整批次，CPU15 单线程，库线程设为 1，按 L 序号交换首轮顺序，第二轮逆序。完整墙钟涵盖正常路由、主搜、查表去重、精算、合并和结果对象生命周期。公开测试 GT 在全部正式计时结束后按冻结哈希读取。每点额外独立核验首 256 条候选集合、原距离排序和返回一致性，单独记资格，不计入正式批次。报告保留复跑原始墙钟、完整包哈希、同 L 召回/候选差和固定目标最快实测达标点；图仅包含 Mixed64。
