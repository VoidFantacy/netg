# 多入口联合响应与GT10训练目标数

2026-10-02下午解析推导；没有搜索、模拟、枚举、数组诊断、训练或性能测量。这里的模型用于区分需要的前件，不是当前默认的新实现。

## 1. 单入口已校准也不保证top3联合最优

设query目标类Y∈{x,y}，概率.6/.4。四入口h₁,h₂,h₃仅服务x，h₄仅服务y；假设理想无竞争coverage，入口集合命中当且仅当其中任一入口服务Y。

前三个入口的单入口真实期望召回都是.6，h₄为.4。即使单入口值预测完全精确，top3为{h₁,h₂,h₃}，联合召回仍只有.6；{h₁,h₂,h₄}却为1。

这说明**重复覆盖**本身就会破坏从single排序到joint最优的推论，尚不需要有限pool淘汰。理想coverage是单调次模目标；固定容量自然beam的真实召回还可能非单调，见上午[167条件/反例](../20261002_theory_until1300_v1/search_effect_theory.md)。不能以单入口有信息、top3更多、或近邻目标更近直接推联合提升。

这类max-coverage/动作非加性及真实组合监督都有直接前作；本地E28/E30/E32/E36已考虑联合入口，见[历史审阅](theory_prior_and_falsifier_audit.md)和[原三入口策略](../../experiment_history/25_query_swap_policy.md)。本段不是新联合模型提案。

## 2. 一套足以让top3规则成立的联合合同

每个真实GT成员t唯一分配到类h(t)。对任一被比较的合法S，假设固定有限搜索的实际命中集合满足

O_S(q)∩GTK(q)={t∈GTK(q):h(t)∈S}。

这个等式同时要求：选择h能找到它的全部类内GT成员、不同入口没有负竞争、没有额外跨类成功、最终pool不会丢掉这些成员。它远强于raw图可达或单入口平均服务表。

定义a_h^(K)(q)=|{t∈GTK(q):h(t)=h}|/K，则

r_S^(K)(q)=Σ_{h∈S}a_h^(K)(q)。

在|S|=m≤L且全部动作费用相同时，选最大的m个a_h^(K)确实是联合质量最优。证明只是非负质量的可分加和；若不同动作成本不同，或负竞争出现，就不能继承这个top-m结论。

较一般的ideal union coverage可以用每入口服务集C_h(q)，但此时r_S=|∪_{h∈S}C_h∩GTK|/K不一定可分。贪心或次模近似需自己的假设及计算成本，不等于直接取最高single值；当前真实有限beam不能自动使用该保证。

## 3. 训练GT10不等于评估Recall@1/@100

即使上节理想可分合同成立，当前训练权重a_h^(10)也只是前10目标的归属质量；真实评估K=1或100需要a_h^(K)。名字GT10没有把真实指标改成Recall@10。

若选S₁₀=argmax_{|S|=m}Σ_{h∈S}a_h^(10)，而真实最优为S_K，令δ_h=a_h^(K)−a_h^(10)，则

r_SK^(K)−r_S10^(K)
 = Σ_SK a^(10)−Σ_S10 a^(10)+Σ_SK δ−Σ_S10 δ
 ≤ Σ_SK δ−Σ_S10 δ
 ≤ min(||δ||₁,2m||δ||∞,1)。

这是理想可分模型下的解析目标数失配界，不含真实有限搜索响应残差、归一化画像误差或近似路由误差。若归属是soft，除非实际响应严格实现相同soft覆盖效用，上节的真实命中分解并不由soft权重自动成立。

反例可只用目标排序：有≥m+1个目标类，GT1属于h₀，前10中另外m个类的数量各多于h₀。取m=3，分布为1/10、3/10、3/10、3/10，训练top3排除GT1所属类h₀；在理想分区服务响应中，真实Recall@1为0，另一三入口动作包含h₀便为1。每类目标可取q方向不同严格IP分数，使上述GT次序合法；这里只使用明确给定的rank标签，不声称当前实际图具有此理想响应。

K100同样可能与前10类质量排序不同。若把权重理解成对廉价信息F的条件期望，则要比较E[a^(10)|F]与E[a^(K)|F]的rank或幅度；跨query随机性不会自动使两者相同。正面前件可以是同一类服务分布在不同GT rank上的适当稳定性，但必须明确成立范围及是否针对真实joint效用。

## 4. 平均十目标降低噪声的说法需要一个随机对象

固定query、固定精确GT、固定hard/soft目标归属时，a_h^(10)(q)是确定量，没有一份可直接除以10的“标签噪声”。可以研究query总体、随机训练样本、随机目标采样或近似GT误差；这些是不同随机对象。

如果确实定义随机Y_j为第j个目标的类指示，那么条件方差为

Var((1/10)Σ_j Y_j|F)=(1/100)Σ_{i,j}Cov(Y_i,Y_j|F)。

只有特定独立/同分布合同才化成单目标方差的1/10。相邻rank、同query目标及同近似教师误差通常可能相关；本轮不假设它们独立，也不新增协方差诊断。目标平均可以经验上稳定方向，但方向稳定不是真实Recall因果改善或正确费用的证明；E130/E134已保留这些区别。

## 5. 对当前理论解释的用途

可以分开五层：目标归属质量与真实GTK的rank失配；GT10逆向query矩与正确服务排序的失配；近似路由实际入口失配；联合pool竞争/重复覆盖；完整获取和执行费用。一个代理MSE或single oracle不会同时解决五层。

本轮只澄清保证条件与反例，不选择新的训练目标数、加模式、改入口数量或改变主搜索。若以后提出方法，须说明它改善哪一层、旧实验为何没覆盖、同监督最简单控制能否解释收益，最后仍需真实Recall@1/@100与完整wall确认；此次没有实验授权。
