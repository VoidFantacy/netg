# 有限入口动作的决策信息、监督与完整费用

2026-10-02 下午理论研究，15:39（UTC+8）终稿冻结。只读原论文、项目协议及已有文字结论，手推证明与分布反例；0实验、0枚举、0新旧数组诊断、0训练/GT/向量评分。不修改上午原件。全文的“最优”“一致”“证书”均带下述假设，不宣称已有可部署新策略。

**主要判断：当前缺口不能笼统称为 query 信息不足。** 固定索引下完整 query 通常已可见，target 分数和 GT 只是它的昂贵确定函数；需要解决的是在有限计算、有限表示、有限监督下，能否可靠预测相对默认的真实动作效用并付得起完整费用。Bayes 规则、成本敏感选择、按需访问、代理校准都有直接前作和本地实验，换一个模型名字不构成 gap。

**最新目标口径：离线训练时间无需节省，可以增加。** 本文不设廉价训练、监督生成或预处理的性能门；更昂贵的离线计算若能产生可迁移响应模型、更准确校准或可部署表示，不能仅因训练/构建费用拒绝。最终门仍是可靠的Recall–QPS综合提高，新增在线信息获取、推理、route/search/output及必要bookkeeping均计完整wall，并比较共享最强默认。本轮授权仍只到16:00的理论研究，没有训练/预处理或实验执行。

## 1. 对象先固定，Recall 与速度不混成任意奖励

固定一个声明的 dataset/K/L 工作点。θ 包含 base/metric、底图、画像/路由图、有序映射、初始化/展开/停止、native callback、FP 环境和 tie。有限动作集合 A 含原默认动作 0；动作可以是一个事前固定、总能合法执行的入口策略，例如原三入口或原 query 的 rank1 单入口。若动作合法性或真实 ID 依赖路由结果，该生成/检查已经是有费用的流程部分，不能当作免费常量。

记该动作真实返回为 R_a(q)，对应合法 GT 为 G_K(q)，

    H_a(q) = |R_a(q)∩G_K(q)|/K ∈ [0,1]。

这里只讨论真实 Recall@1/@100。多个入口的动作必须是实际共同 beam 的完整动作，不能把单入口命中并集作为 H_a。θ/K/L/入口共同调用改变时，旧 H 标签不再自动有效。wall 还受硬件状态 Ω 影响，记**完整策略**时间为 T_π(q,Ω)，包含获取信息、模型/表推理、路由、映射、固定主搜索与返回；它不是 NDC 或离线分项时间的加和估计。

对同一冻结 workload，pooled QPS 是 N/完整总 wall；在稳定可积的总体模型下才对应 1/E[T]。一般 E[1/T] 不等于 1/E[T]，也不能按 query 选择每种默认中最快的实测时间。

相对固定默认，局部双指标改进的一个充分条件是 E[H_π−H_0]≥0、E[T_π−T_0]≤0 且至少一项有事前声明的实际改善。这不是要求所有探索点都显著，也不是一般前沿改善的唯一可能形式；质量/速度取舍仍需在预声明工作区间证明有实际前沿收益。任意 scalar 奖励正值不会自动证明两个坐标都改善。

## 2. 全 q 可见时：统计信息、表示与计算三种限制

令 F_raw=σ(Q,θ)，廉价表示 F_φ=σ(φ(Q,θ))⊆F_raw。理想情况下，确定性 target 访问结果 Z=f_θ(Q) 满足

    σ(Q,θ,Z)=σ(Q,θ)，
    E[U_a|Q,θ,Z]=E[U_a|Q,θ]。

所以在无计算限制、任意可测策略的 Bayes 意义下，Z 的新增信息价值为零。GT/搜索响应也在固定确定性配置下有同一边界。这不表示 GT 标签、target 访问或学习无用：训练者可能未知映射，部署者无法在规定时间算出它，或当前 φ 丢失了决策需要的变化。若评分包含随机 FP/并发环境，须将其纳入条件配置；测得的访问时间也可能揭示硬件状态，但那是另一个观察/状态模型，不能混入确定性分数的信息结论。

对固定、可积、已包括最终动作费用的 scalar 效用 U_a，定义

    V(F)=E[max_a E[U_a|F]]。

若 F⊆G，则 V(G)≥V(F)：令 a_F 为 F 下的最优动作，G 下最优性给 E[max_a E[U_a|G]]≥E[E[U_{a_F}|G]]=E[U_{a_F}]=V(F)。如果同一个 F 可测动作在 G 下仍总是最优，等号成立。免费更多信息的最优价值非降，不代表强制支付访问费用的程序会更好。

这里的“可见信息 F”是该决策合同允许使用的观测/表示，不是硬件读到完整 q 后仍有一种新的 Shannon 信息缺失。把计算限制压缩成 F_φ 是一个分析近似；一般有限时间算法类未必能由一个 σ-field 精确刻画。若同一动作的执行时间取决于此前怎样计算 φ/Z，就不存在路径无关的单个 U_a，必须改用完整计划动作或带缓存/费用状态的模型。

一种不混淆归因的概念分解是

    V(F_raw)−E[U_π̂]
    = [V(F_raw)−V(F_φ)]
      + [V(F_φ)−sup_{π∈Π}E[U_π]]
      + [sup_{π∈Π}E[U_π]−E[U_π̂]]。

三项分别是廉价表示的损失、该表示上模型类/允许计算的近似损失、拟合/估计/优化的损失；前提是 Π 确实是 F_φ 可测策略类、π̂∈Π、效用与分布相同。实际额外推理/获取费用、分布迁移另行计入，不能把此免费价值分解直接当线上收益分解。完整 q 可见只消除“原始输入之外缺信息”的说法，不消除这些瓶颈。

E133 已明确“特权”属于训练/计算预算意义，不是原 query 外新增 Shannon 信息：[旧理论](../20260922_until2200_improvement_v1/research/semantic_decision_geometry_v1/theory.md)。本段是在有限动作/费用合同下整理该边界，不是新信息论结论。

## 3. Bayes 动作、平均约束与逐 query 安全

对已固定 scalar U_a，给定允许使用的信息 F，Bayes 动作为

    a*(F)∈argmax_a μ_a(F)，μ_a=E[U_a|F]。

证明只需条件期望：任意 F 可测动作 π 有 E[U_π]=E[μ_π]≤E[max_a μ_a]。默认作为一列、tie 默认优先，因此在**免费推理且 μ 正确**的模型中，最优策略至少不输默认的平均 scalar 效用。新 gate 的费用若尚未计入 U，则这个性质不适用于完整线上方法。

若目标是最小平均时间且平均 Recall 不低于默认，形式为

    min_π E[T_π]，s.t. E[H_π]≥E[H_0]。

可用 Lagrange 对象 λE[H_π]−E[T_π] 描述受支持的决策。需要时间/质量单位、约束及 λ 在反馈前有解释；若允许随机策略且可行集合闭/凸并满足相应强对偶条件，才可用对偶最优值恢复约束问题。只准确定策略时可行前沿可能非凸；一个固定 λ 不必找到所有 Pareto 点。这里不提出 λ 调参路线，不用 scalar 提升替代两项实际结果。

三种“无损”必须区分：

- 平均约束：E[ΔH]≥0，允许某些 query 受损。
- 条件平均：E[ΔH|F]≥0，仍允许同一信息格内有罕见损伤。
- 逐 query：ΔH(q)≥0 几乎处处；这需要真实响应/严格证书，不能由训练格均值或正预测得到。

一个双指标的充分合同是：对实际执行的完整计划，在全部决策信息 F 条件下同时有 E[ΔH|F]≥0、E[ΔT|F]≤0 几乎处处，再由全期望得到平均双非降。它仍不是逐 query 保真，也比只要求平均约束更强。若要用预测下界/上界实现它，必须对选择过的动作和全部信息建立有效的同时条件界；点预测、训练均值或 marginal calibration 不满足该前件。付费 gate 的 fallback 计划已经承担获取 F 的费用，不能把它的 ΔT 标签设成0来制造此合同。

即便每个信息格的候选都以概率 0.51 救回、0.49 损伤，条件平均 +0.02，也仍有 49% 损伤。这是手设分布，不是本地测量。E164 的训练格经验非降实际没有传到外折，故“每叶训练非降”不是新的安全证明：[冻结规则](../20260930_theory_until2200_v1/research/router_rank_pareto_v1/protocol.md)、[已发生的外折失效](../20260930_theory_until2200_v1/research/router_rank_pareto_v1/report.md)。

K100 的逐 query 命中数非降还弱于“每个原正确成员保留”：新正确成员可抵消原正确成员丢失。令 g=|G∩(R_a\R_0)|、d=|G∩(R_0\R_a)|，则 ΔH=(g−d)/100；净正负 query 不能代替全部成员 gain/damage。native 全返回 bits 保真比以上质量安全更强；上午 memo 条件讨论的就是后者。

## 4. GT/teacher ID 何时是正确监督

一个训练变量 Y 能支持动作效用决策，须有已知合法损失 ℓ(a,Y,F)，使 E[ℓ(a,Y,F)|F] 等于真实动作风险，或至少保持所有部署动作的条件差值排序。标准“预测最终类别”的 ℓ=1[a≠Y] 满足这一点；“把 Y 当入口再跑有限搜索”一般不满足，因为真实返回还依赖完整图、query 比较、共同入口与队列轨迹。

GT1/GT100 可以给已执行、同合同动作的 R_a 正确评分，因此可构造真实配对 ΔH。GT ID 单独只给“谁是近邻”，没有告诉每个合法入口能否以固定 L 救回它，也不提供完整费用。teacher ID 若只是 raw-target argmax、所属 hub、或其代理最优入口，必须额外证明该代理对实际动作的效用关系；“teacher 自己优于默认”不证明预测其分数/ID更准会提高学生真实效用。E133 已给出了代理误差与服务残差的精确分解，不能以新蒸馏名字绕开：[旧分解](../20260922_until2200_improvement_v1/research/semantic_decision_geometry_v1/theory.md)。

对有限动作、平均 Recall/时间目标，真正需要的决策量可以是每个动作相对默认的条件均值对 `(E[ΔH_a|F], E[ΔT_a|F])`；不必预测全部返回ID才能作平均决策。默认是精确零锚，query难度的共同项在质量差中消去。保留返回/GT仍可用于验证标签、成员损伤与逐 query性质；尾部风险或概率约束还需相应条件分布，而非仅这两个均值。此监督压缩不是新 gap：E118 已学习真实相对动作响应，E164 已对有限rank动作使用真实反馈；其未兑现的泛化/成本问题没有因此消失。

只有 winner action 标签通常也不足以最大化平均效用。手推两世界反例：candidate 胜概率均 0.6、负概率均 0.4；世界 A 的 ΔH 为 +0.10/−0.01，均值 +0.056；世界 B 为 +0.01/−0.10，均值 −0.034。两种情况均可由 K100 的合法 10/1 命中差产生，winner label 分布完全相同，最优平均动作相反；普通 winner 分类丢失幅度。

R1 是特殊情况：若明确标记 rescue/damage/tie 三态，固定质量增量就是 +1/−1/0，可恢复期望差；只有默认优先的 winner 标记却把 damage 与 tie 合并，仍可能无法恢复。另一个正面特例是：teacher 真的是同一有限动作集的逐query实际质量最优动作，允许信息F能无误识别它，而且推理/获取完全免费，则照该标签执行能取得逐query最大质量，幅度无需另估。真实标签经压缩信息、受限模型或有限训练后，普通 Bayes winner 分类却未必最大化条件平均效用；费用最优还需要正确成本。故不能笼统说所有 teacher 标签都无效，也不能默认它们已是正确效用监督。

## 5. 可校准代理：目标正确、条件正确、费用正确

两动作纯质量令 Δ=H_1−H_0，P(F)=E[Δ_+|F]、N(F)=E[Δ_-|F]。加权 logistic 条件风险

    P log(1+exp(−z))+N log(1+exp(z))

在 P,N>0 时最优 z=log(P/N)，所以 z>0 当且仅当 E[Δ|F]>0；单边为边界解，两项皆零默认。零差不应该被当作普通负类；K100 的幅度应进入权重。这个构造项目 E25 已实际使用，不是本稿新损失：[原协议](../20260910_selective_profile_gate_v1/protocol.md:35)。

但这个 logit 只给 P/(P+N) 的**效用加权比例**，不是所有 query 的 rescue 概率，也没保留事件率 P+N。相同 P/(P+N)=0.9，P+N=0.001 与 0.1 时净质量为 0.0008 与 0.08；支付同一个 0.005 的 scalar 费用时决策相反。因此要比较访问费用，必须保留正确幅度/事件率或直接学习已含费用的真实 ΔU；不能把 weighted confidence 当 VOI。

有限动作可用真实成本向量的 cost-sensitive CE：令 M=max_a ℓ_a，损失为 −Σ_a(M−ℓ_a)log p_a。在条件期望下，权重 w_a=E[M−ℓ_a|F]，最优概率 p_a=w_a/Σw，于是 argmax p_a=argmin E[ℓ_a|F]。这是 Mozannar–Sontag 2020 Proposition 1 的已有归约；全权重零时各动作相同，零权重需概率单纯形边界/infimum，不强称有限 logits 有唯一有限解。

上述归一化发生在**先对原始权重取条件期望**之后。如果每query先除以 `Z(q)=Σ_a(M(q)−ℓ_a(q))`，总体最优变为 `p_a∝E[(M−ℓ_a)/Z|F]`（Z=0须另定合法处理）。query特异分母会改各query权重，不能交换“先归一化再平均”与“先平均再归一化”。两动作Z=|Δℓ|时只剩winner：§4世界B的+0.01/−0.10质量增量经此处理仍给candidate胜概率0.6，实际均值却为−0.034。这个手推边界不归咎于原论文已声明的任务，也不提出loss调参或训练；E25已有真正幅度加权。

这种 p_a 是归一化效用权重，不是“该动作正确”的概率，更不是实际时间单位。原论文 L_CE（α=1）的 optimum 为 p_defer=r/(1+r)、p_y=η_y/(1+r)，其中 r=P(expert正确|F)、η_y=P(Y=y|F)；argmax 保持 Bayes 比较，但直接把 p_defer 当 r 错了。若确已达到这个正确条件模型的最优值，可由r=p_defer/(1−p_defer)及η_y=p_y/(1−p_defer)反变换；有限fit却没有自动满足该前件。分类校准、概率校准、成本尺度校准不能混同。

若真正估计动作条件均值 μ_a=E[U_a|F]且U_a二阶可积，平方损失在无限模型/总体最优下有正确目标：E[(t−U_a)^2|F]=(t−μ_a)^2+Var(U_a|F)。质量H有界满足此条件，未限定尾部的wall效用则不能仅由均值可积推出。正确目标仍不意味着对任何代理的 MSE 下降会改善真实决策，也不保证有限样本/受限模型/新分布。对 μ 的 plug-in 误差 e_a，最优动作 a* 与预测动作 â 满足

    μ_a*−μ_â ≤ max_a e_a−min_a e_a ≤ 2max_a|e_a|。

因此平均 regret ≤2 sqrt(E[Σ_a e_a²])；如果报告的是 m 动作平均 MSE，界为 2 sqrt(m·MSE)。多动作最大化需要对选择处误差负责，不能从小平均 MSE 直接宣称排序正确。前面的极差/2ε结论已见 E118/E133，本稿强调它作用于**同信息 F 的真实条件效用**；它不推出逐 query 无损。

即使目标就是正确的μ，MSE下降也不保证有限模型间决策单调改善：手设同一信息格，真实(H₀,H₁)=(0.50,0.51)，模型A报(0.50,0.99)、模型B报(0.50,0.49)。默认预测完全相同且正确，B的candidate平方误差0.02²远小于A的0.48²，却从正确选择candidate变为default，少获得0.01真实质量。K100的50/51命中使该效用合法，所有预测也在[0,1]；这不是新实验。总体无限模型的平方风险最优仍恢复μ，零误差极限保证不矛盾；这里否定的是两份有限近似之间的单调结论。

只对各输出自己的分数 bins 做 marginal calibration 也不够保证任意选择后的组校准。手设两等概率 query 组，动作 A 命中为 1/0，B 为 0/1；二者都报 0.5 时各自完美 marginal calibrated，却不表达可见组信息下的真实条件价值。若 gate 在第一组选 B、第二组选 A，selected 分数仍全为0.5，真实命中却全为0；这只证明使用额外组信息的选择不自动继承原分数校准，不宣称所有固定tie规则都会失败。若 gate 使用组信息，其需要 E[H_a|全部 gate 信息]，不是 E[H_a|该分数]。真正的条件均值/完整 cost labels 是理论对象；在历史数据上没有据此验证过校准，不在本次新增校准实验。

### 5.1 针对冻结策略类的残差矩，比完整条件均值更弱

固定同一总体分布、合法信息F、预测器 `Û_a(F)` 和允许策略类Π；所有被选策略必须属于Π。先假设动作效用U_a可积、可在共同prefix后同合同执行，且不再依赖怎样选择该动作。记 `r_a=U_a−Û_a`、`M_π,a=1{π(F)=a}`，以及

    V(π)=E[Σ_a M_π,a U_a]，V̂(π)=E[Σ_a M_π,a Û_a]。
    V(π)−V̂(π)=Σ_a E[M_π,a r_a]。

所以真正需要的一个充分合同是

    sup_{π∈Π}|Σ_a E[M_π,a r_a]|≤ε。

逐动作更易表述的充分条件为 `|E[M_π,a r_a]|≤ε_a` 对全部π/a成立，且Σ_a ε_a≤ε。若对每个非空所选组有 `|E[r_a|π=a]|≤α`，其总体加权误差≤α，因为各组概率之和为1；若仅给每个未按组概率加权的矩≤α，通常只能得|A|α，不能漏掉这个因子。独立随机策略可将M换为其条件动作概率；预测器和动作合同仍须事前固定。

若 `E[r_a|F]=0`，所有上述矩为0；但反向不成立。手设两等概率信息组，真实candidate质量为0.9/0.1、默认恒为0.5，预测两动作都为0.5。Π若仅含两个constant动作，各策略总体值预测全正确，却没恢复candidate的条件均值。另加“仅在低质量组选candidate”的策略，其预测0.5、真实0.3；它不在旧Π内，旧合同没有覆盖它。这是合法有界质量的手推分布，不是新枚举/运行。

**类内选择界。** 对满足上述同时矩界的Π，若 `π̂∈argmax_Π V̂(π)`、`π*∈argmax_Π V(π)`，则

    V(π*)−V(π̂)
      =[V(π*)−V̂(π*)]+[V̂(π*)−V̂(π̂)]+[V̂(π̂)−V(π̂)]≤2ε。

预测优化只达到η误差时界为2ε+η；最大值未达到则改用sup及相应近似策略。选出的π̂也有 `|V(π̂)−V̂(π̂)|≤ε`，因为合同同时覆盖Π。它是相对该类的平均价值界，不是相对任意策略/逐query oracle的界，也不保证π̂比某个默认更好；默认差须留预测余量。

对path-dependent费用，`T_π`可能包括π特有的获取、选择、缓存及fallback路径，不能未经证明写成ΣM_π,a T_a。此时直接要求完整计划值 `sup_{π∈Π}|E[T_π]−t̂_π|≤ε_T`；或在§6.1的共同状态合同里，对真正可分解的suffix和完整prefix分别建立矩界再相加。质量动作若其入口/调用也因策略改变，则H同样改成完整计划H_π。把每个候选的独立计时表当作这里的T_a是不合法的。

**两坐标余量。** 对Π及共享默认控制J分别有同时的质量价值误差≤ε_H、完整time误差≤ε_T；所有j∈J返回保真，因此真实默认质量相同，记其预测为ĥ_B。对某个π̂，若事前质量与时间改善要求为δ_H/δ_T≥0，且预测满足

    ĥ_π̂−ĥ_B ≥δ_H+2ε_H，
    min_{j∈J} t̂_Bj−t̂_π̂ ≥δ_T+2ε_T，

则实际 `E[H_π̂−H_B]≥δ_H`，`min_j E[T_Bj]−E[T_π̂]≥δ_T`。证明是两边各最多误差ε；同时界也给 `|min_j E[T_Bj]−min_j t̂_Bj|≤ε_T`。时间比较对象仍是最快**固定实现的平均时间**，不是每query默认oracle。若直接对同query相对默认的配对增量建立价值误差界，默认零锚不再有独立估计误差，可只需一个ε的余量；时间须对每个共享默认的完整差同时成立。没有这种直接界时不能自行去掉因子2。不同K/数据须各有ε_Hj及对应合法总体，按§6.2处理。

一个scalar预测 `λH−T` 的价值误差最多λε_H+ε_T，可给类内 `2(λε_H+ε_T)` 的scalar regret，却仍不推出两个坐标一起改善。用安全余量筛策略后，该筛选类可能排除真实可行但接近边界的策略；没有额外margin前件时，上述2ε界不能变成“相对所有真实质量可行策略的最快时间”保证。若要预声明QPS增益g而非δ_T，充分预测门为 `t̂_π̂+ε_T ≤ (min_j t̂_Bj−ε_T)/(1+g)`，并要求相关下界为正；这是对平均完整时间取倒数的同一合同。

这些残差矩是总体假设/待验证证书。训练格经验均值、同一数据上的训练零残差、marginal score calibration都不能自动证明它。若策略类/预测器由该数据选出，必须明确冻结顺序及同时泛化/适当自适应分析；仅写“Π固定”不能把已经发生的选型变为独立确认。允许事前随机Π时，可条件在其合法冻结结果上表达合同，但取得有效总体界仍须相应证据。本轮不拟合、不检查任何新旧样本矩。

**有限家族的条件证书，只作手推。** 假设事前冻结m≥1个完整policy/default及各预测器，另有合法独立确认的n≥1个query/执行环境对，且这些对确为同总体i.i.d.；每个质量/完整time残差都在一个已知长度分别为W_H/W_T>0的区间内。同query各策略的残差可相关，以下同时界不要求它们彼此独立。记样本平均残差为r̄_π,c、c∈{H,T}，对0<δ<1，以至少1−δ概率，同时有

    ε_c = max_π|r̄_π,c| + W_c sqrt(log(4m/δ)/(2n))
    ≥ max_π |E[r_π,c]|，c∈{H,T}。

证明：对区间长度W的残差R，令 `G(t)=log E exp(t(R−ER))`；指数tilt后的分布仍在该区间，其方差≤W²/4（对区间中点的二阶矩即≤W²/4）。故G″≤W²/4、G(0)=G′(0)=0给G(t)≤t²W²/8。对i.i.d.和的指数Markov界最小化t，得到 `P(|r̄−ER|≥b)≤2 exp(−2nb²/W²)`；对2m个坐标求并集即上式。absolute质量与预测都在[0,1]时W_H≤2；若paired Δ及其预测都只知在[-1,1]，通用残差区间宽可达4，默认一ε代数不自动使统计区间更窄。time并无同样免费范围。统计项仅含log m不表示取得m个合法完整策略响应、建立校准family或计算在线argmax的费用也为log m；这些费用未被此概率界估计。前两项若是纯离线成本可增加，不作为性能拒绝门；在线所需mask/特征/argmax仍须付费。本式不代入n/m/δ，不查历史样本，不建议使用新query；它只说明有限同时家族、冻结顺序、合法paired response和wall尾部前件不能省略。

无已知范围/尾部约束，不能从有限观察给任意总体完整time均值的分布无条件上界。手设非负额外时间X：世界0恒为0；世界1以概率1−p为0、概率p为M，n次全0的概率为(1−p)^n，而均值pM可任意大。选择很小p时两世界的有限观察几乎总相同，再增M即可使均值差任意大，且每个世界均值有限。对实际时间可加任意共同正基数，反例不变。它针对未限制尾部的统计类，不声称某个固定实机必有此异常；若已证明确定上界或其他尾部条件，应使用那个真实前件。连续串行wall的环境相关性也不能由“single-thread”自动变成i.i.d.；本轮没有取得这些前件，以上界不是本地性能证书。

矩合同还只对声明的总体P成立。即使未来Q与P的条件响应相同、密度比w(F)有界，新的signed残差为 `E_Q[M r]=E_P[w(F) M r]`；旧 `E_P[M r]=0` 可以来自异号抵消，w改变混合后不再为0。bounded ratio自身只迁移绝对误差上界，不能免费迁移signed零矩。需额外覆盖合法weighted masks、强条件校准或相应绝对误差；同一压缩F纤维内条件响应本身改变又是另一缺口。独立审稿已在[前作/迁移审查](theory_prior_and_falsifier_audit.md)给手推反例，这里不新增数组诊断或权重拟合。

### 5.2 直接前作及迁移成本：multicalibration 不是免费价值证书

Hébert-Johnson等ICML2018在二元结果模型中，要求对可计算组及预测分箱同时校准，并把校准与组平均残差联系起来；其α校准允许删去小部分成员。若将组类事前包含策略选择mask，可为§5.1的组残差提供一种充分方向，但忽略成员的总概率ζ仍需有界残差B给Bζ补项。罕见rescue组不会仅因名字出现在组列表就得到高精度保护。算法需反复识别违背组/分箱，原文明确依赖组规模、精度、membership计算及自适应数据复用的成本；离线校准可增加费用，但不能从存在性继承ANN在线QPS。[原论文§2–4](https://proceedings.mlr.press/v80/hebert-johnson18a/hebert-johnson18a.pdf)

Gopalan等《Omnipredictors》正式发表在**ITCS2022**。正文以partition内协方差刻画近似multicalibration，canonical predictor是总体条件标签均值；Thm19在二元标签、声明的B-Lipschitz convex损失及比较类C条件下给 `2αB+ε` 的loss竞争界。文中有有界实值/多类定义，但不能将主定理任意推广到无界wall、非凸argmax或所有threshold闭包；full version §6.3另给后者限制。组条件化的误差也可能随组概率倒数放大。这里只迁移“比较类与校准对象须吻合”的前件，不声称该定理直接给固定NSG双指标保证。[正式正文§3–6](https://drops.dagstuhl.de/storage/00lipics/lipics-vol215-itcs2022/LIPIcs.ITCS.2022.79/LIPIcs.ITCS.2022.79.pdf)、[作者full version v1 §6.3](https://arxiv.org/pdf/2109.05389v1)

协方差前作与本合同有一个可直接手证的具体联系。对一个冻结partition S，若动作预测确为人口canonical `f_a=E[H_a|S]`，则

    E[M_π,a(H_a−f_a)] = E[Cov(M_π,a,H_a|S)]。

这是对S先条件化的恒等式，不要求gate在每个partition内恒定。若全部π/a有 `E[|Cov(M_π,a,H_a|S)|]≤α`，便得到§5.1单动作矩≤α，总值误差一般≤|A|α。实际预测Û_a代替f_a时，还要加 `E[M_π,a(f_a−Û_a)]` 的选中估计误差；有限训练格均值不能直接称人口canonical。这里直接控制合法Recall动作响应，未借Thm19声称非凸搜索损失或无界wall已满足条件，也不提供廉价partition/mask的存在构造。

ANN动作有各自的潜在真实响应H_a与完整路径费用，不是一个GT类别Y对所有损失免费通用。采用前作所需labels依旧必须对应实际固定搜索动作；不能用hub ID、raw affinity或未执行动作免费填充。Recall标签有界可谈组矩，wall标签还需合法范围或尾部控制；历史少量time/NDC记录不提供该前件。Π×动作的mask、K/数据/工作点及预测分箱形成同时家族；离线取得合法labels、拟合或校准可以更贵，不能据此否定方法。若部署所需组membership/特征本身调用昂贵target/router，其在线费用则须计完整wall；不能用只能离线取得的mask直接证明便宜gate。

针对窄Π要求矩，比恢复全部F条件均值更弱，也可避免要求模型知道不影响该类决策的变化；但其加总条件几乎就是“该类政策价值预测准确”的重述。它给出了应负责的选择误差及余量，没有新增信息源、便宜识别算法或新response监督。E118/E133已有2ε plug-in边界，E25/E164已有真实选择反馈，本节只收紧合同，不能以multicalibration/omnipredictor的新名字重开已失败方法。

## 6. 昂贵 target 访问的 value of information

先给**纯信息模型**：固定可执行动作 A、固定 U_a，获取 Z 只揭示信息，不生成新动作、不改变最终动作成本/状态。给定已有 F，毛信息价值

    EVSI(F)=E[max_a E[U_a|F,Z] |F]−max_a E[U_a|F] ≥0。

若获取 Z 的 scalar 费用为 k(F)，一次访问值得的条件是 EVSI(F)>k(F)。费用可以由时间乘事前有解释的影子价格得到，但不能靠一个有利 λ 宣称 Recall/QPS 双升。完美信息上界

    EVSI(F)≤EVPI(F)=E[max_a U_a|F]−max_a E[U_a|F]。

不等式来自每个动作的条件期望都≤E[max_a U_a|F,Z]。这是通用 Bayesian selection/计算选择工具，非本项目新方法。

两动作且默认增量为0、候选为可积 Δ，有特别清楚的恒等式：

    EVPI = E[Δ_+|F]−max(0,E[Δ|F])
          = min(E[Δ_+|F],E[Δ_-|F])。

R1 纯质量下为 min(rescue概率,damage概率)。若候选几乎总比默认好，无需信息便执行候选，额外知道结果几乎没有选择价值；如果两者已知完全相同，更多相似分数也没有价值。若比较对象被强制限制为“无访问只能默认”，其免费 oracle 余量为 EΔ_+，这是另一个 action availability 合同，不能与上式混用。

当前 TargetBank 访问同时产生要注入的真实入口，而且影响后续向量/图 cache；只对最终 affinity/slot 增加信息的理想模型不自动描述这段程序。必须把访问结果、已支付成本、可用动作、可复用状态和完整 suffix 成本写入计划状态，或从开始就把“计算 target 然后执行主搜索”当作一个完整动作。固定 act set、纯信息、共同费用只付一次三个前件不满足时，不能直接用 EVSI−k 预测实际 wall。

仅知道当前 μ_a(F) 也不足以算 EVSI：还须知道访问结果 Z 与真实动作效用向量的联合条件分布，才能得到 μ_a(F,Z) 以及它如何跨越动作边界。一个 raw-target 分数、teacher ID 或 weighted confidence 不是这个联合响应模型；把它叫“信息价值”没有建立相对搜索效用的联系。上述 EVPI 只有在同动作/同效用且能免费观察真实结果的理想合同内是上界，不覆盖访问改变缓存执行成本产生的全部计算收益。

多次计算的值需允许后续计算与停止。Hay 等的 myopic value 是“本次计算后立即选动作”的一阶段值；它停止时不证明多步最优也应停。理论上，两次观察分别均无单步决策收益、合起来有收益的互补信息即可产生反例；该论文 Theorem 9 的停止结论另需停止集合对转移封闭。本稿不提出多探针 runner，只防止把单次 proxy VOI 变成通用停止保证。计算选择器自身的评估费用也要计入完整 wall。

### 6.1 收费计算、可用入口与缓存状态的 Bellman 合同

令状态 s 记录部署合同允许使用的 query 表示、已经生成的合法入口/映射、同query可复用的原回调bits及kernel命名空间、执行阶段和预算。路由若未结束，还要保留其原heap/visited/控制状态。若这些不能解释费用转移的Markov性，还需环境状态或相应belief；不会把CPU/cache随机性假装成已观测常量。这是数学状态，不宣称能够廉价导出或学习它。

状态 s 中可以执行的完整搜索后缀动作集合为 A_stop(s)；未生成的入口不能免费放入该集合。计算动作 e 从 s 转至 S'，支付该实际路径的增量时间 c_e；最终执行动作 a 的后缀时间为 τ_a(s)，质量为 H_a。对一个事前声明的时间影子价格 ρ≥0，有限深度、可积模型的 Bellman 关系是

    V(s)=max{
      max_{a∈A_stop(s)} E[H_a−ρτ_a(s)|s],
      max_{e∈A_comp(s)} E[−ρc_e+V(S')|s,e]
    }。

增量时间沿同一次实际执行相邻阶段划分，所有bookkeeping、选择计算和终局执行各付一次；若程序用于求 V 的额外计算没有作为动作费用计入，公式只是免费规划上界。完整时间为 `Σ已执行c_e+τ_final(S_final)`。τ必须依赖执行到达的状态，不能用原完整方法wall替代；已经在prefix付过的路由、范数、target访问不能再收费。停止默认时仍有此前的Σc_e，不能因它是sunk cost就在相对原默认的完整比较中删除。

纯信息EVSI−k是此关系的特殊情况：计算只揭示Z、可执行动作不变、每动作的效用/后缀费用不因状态变化、且下一步立即停止。如果入口可用性、suffix cache或native执行模式改变，这一约简失效；需要比较完整计划，而不是把访问前后不同程序硬塞进同一个 U_a。

对任意已冻结两阶段策略δ，令从初态s₀完成获取/选择的完整prefix时间为C_δ，到达状态S，执行相应后缀。若B*是共享控制集合中**固定实现**的最快默认，则精确代数为

    E[T_δ−T_B*(s₀)]
      = E[C_δ+τ_δ(S)−T_B*(s₀)]
      = E[C_δ+τ_B*(S)−T_B*(s₀)]
        + E[τ_δ(S)−τ_B*(S)]。

第一项是“执行同prefix/选择计算后强制默认”的完整计划，相对原最快默认的额外费用；第二项才是相同到达状态下改变终局动作的净效应。fallback时第二项为0，第一项仍保留。τ_B*(S)必须包含当前尚未做完的默认步骤，避免漏费；也必须复用合同已允许的计算结果，避免重复收费。该式只要求潜在suffix费用在同状态合同下定义；是否可由实机配对分解重建，仍需后续执行核验，不能相加独立微计时冒充它。

共享默认控制应包括这个**同prefix/同选择计算后强制默认**的完整版本，只要它经核验输出保真。若它比已有默认快，就更新最强默认，不能把该默认也能得到的计算收益归给选择信息。单条query的prefix+fallback差可以为负；相对包含此控制的最快固定默认，其总体均值则非负。这里只扩展理论控制集合，不声称存在新实现或已核验速度。

例如符号模型中先执行默认路由r、target访问z、gate g，之后仅执行主搜索m：fallback完整时间是r+z+g+m_B(S)，相对原默认r+m_B(s₀)的差是z+g+m_B(S)−m_B(s₀)。既不能写fallback差为0，也不能把r+z+g加到已经含r的原默认完整时间上。若gate在target访问前选分支，z只在所选分支付；若gate需要访问结果Z，z已经在所有gate query的prefix中支付。这里全部是手设时间符号，没有新计时或程序。

### 6.2 两坐标的可行域与可承受费用上界

固定廉价信息F、付费prefix与候选/default合法suffix合同。令 `c(F)=E[C+τ_B(S)−T_B(s₀)|F]` 是**付费fallback完整计划**相对共同最快默认的费用，而非仅gate算术时间；令m(F)是候选相对该fallback的条件质量差，d(F)是其条件完整后缀/分支时间差。原B输出保真时，fallback的质量差为0。缓存可能使c(F)有正有负；只有另证默认suffix不受影响时，才可把c简化为非负gate费用。若候选分支还有尚未生成的target访问，将它计入d及其状态转移，不把入口免费提供。

在共同prefix、相同选择开销和固定分支响应的**比较模型**中，若 gate 在访问之前按F决定是否走候选，随机化概率p(F)∈[0,1]使用独立随机源，那么

    mean ΔRecall = E[p m]，
    mean Δtime = C̄+E[p d]，C̄=E[c]。

这是固定实际路径的条件均值合同，不是从独立route/graph时间推算。m/d只有在相同F和相同执行状态下成立才可用于它。包含上述付费强制默认控制时C̄≥0，虽c(F)未必逐格非负。计算不同p或随机化本身若改变费用/缓存，必须纳入对应完整计划，不能继续假设C̄/m/d不变。m/d可以异号；平均双指标允许一个信息格的质量损伤被另一个信息格救回抵消，不能误写成每格或逐query安全。

在上述固定费用比较模型内，所有随机策略所得集合 `{(E[p m], E[p d]):0≤p≤1}` 是凸的：混合两策略直接混合两坐标。若F取预先固定的有限信息格，且m/d可积，这个集合是闭有界多面体；一般F需相应可测/紧性条件，不能直接称有限动作就等于有限状态。不同实体算法加上新的选择开销后，其实测wall集合未因此被证明凸。这里只讨论理论随机策略，没有随机化runner。

同一合同下，一个固定λ≥0的scalar支持值可直接写成 `sup_p{λE[p m]−C̄−E[p d]}=−C̄+E[(λm−d)_+]`。这显示“只在预测有利时改道”仍要用总体可得净效益支付全部query的公共费用；默认回退比例高不自动使费用消失。该scalar值为正仍允许Recall/时间取舍，不能替代接下来的双约束可行门。

给定事前质量要求ε_R≥0和时间改善ε_T≥0，定义

    φ(ε_R)=inf_{0≤p≤1, E[p m]≥ε_R} E[p d]。

此合同可实现的必要且在inf达到时充分的条件为 `C̄+φ(ε_R)≤−ε_T`。最低质量门下可承受的公共净费用是 `−φ(ε_R)−ε_T`；它不是target相似度或访问NDC。两个便宜必要条件是 `ε_R≤E[m_+]` 与 `C̄+ε_T≤E[d_-]`：最多选全部正质量格，最多获得全部负时间差格的节省。它们各自可能可行，联合仍不可行，因为正质量与省时未必在兼容的动作/信息格上；φ才同时处理约束。

对λ≥0，Lagrange弱对偶给

    φ(ε_R) ≥ sup_{λ≥0}{λε_R+E[min(0,d−λm)]}。

内层逐F最优选择候选当d−λm<0，等号格可随机化。对预先固定有限F的可行有限值LP，或满足相应强对偶前件的一般凸模型，上式为等号；缺前件时只保留下界。此处λ是描述前沿/解析可行性的对偶变量，没有推荐依据结果调λ或训练新gate。任意confidence最多能编码某一个已正确标定的决策面，不能从普通winner概率或归一化权重同时恢复m、d和C̄。

任一合法λ的下界L_λ均给 `可负担费用≤−L_λ−ε_T`；若已知真实合同的C̄大于这个上界，就能否证该合同，无需找最优gate。λ=0恢复仅省时的E[d_-]界。若还能证明候选分支不可避免的条件平均访问时间下界k(F)，默认尚余suffix均值t_B(F)，且其余候选时间非负，则 `d(F)≥k(F)−t_B(F)`，故必要条件进一步为 `C̄+ε_T≤E[(t_B−k)_+]`。k必须来自同状态真实完整访问合同的合法下界；旧NDC、静态重复比例或理想dot微基准不构成这个wall下界。本轮没有取得k或代入旧数据。

以上只针对一个冻结dataset/K/L的质量与时间。若需多K/数据/预算分别保持质量，必须增加相应真实响应约束 `E[p m_j]≥ε_j`；合法共同模型的dual变为 `sup_{λ_j≥0}{Σ_j λ_jε_j+E[min(0,d−Σ_jλ_jm_j)]}`。不同dataset通常各有期望E_j，不能直接冒充同一个E；若要统一，须先声明workload索引W与P(W=j)=π_j>0，可用质量量 `m'_j=1{W=j}m_j/π_j` 使E[p m'_j]=E_j[p m_j]，或直接分别保留E_j约束。若还要求各dataset/工作点分别变快，须另加各自的 `E_j[c_j+p d_j]≤−ε_Tj` 及对应最强默认；上式单个d的dual只表示那个已声明的整体时间目标，不保证每个域的QPS。各m_j须来自对应合法原生配置，不能用一个K的label或加权平均覆盖另一K损伤，也不能把不同原生调用的时间拼成一个未经执行的策略。必要访问下界k只计尚未在prefix付过的candidate分支访问。

这个两阶段/前沿形式把付费回退和共享默认放进同一合同；它仍依赖未知的真实条件响应和完整路径成本，E25/E118/E164已覆盖相近单次选择对象。本稿没有估计φ、证明本地C̄可被支付或形成性能GO。

## 7. 共享最佳默认门与付费回退

只在输出同原 Default3 保真的默认实现集合 J 中比较：原版，以及若未来实现并核验保真的 UpperHandoff、同 memo 默认、候选同prefix付费强制默认等，所有实现与选择合同事前冻结。本段不声称尚未性能验证的实现已经可用。同一冻结 workload 上

    T_B_best=min_{j∈J} E[T_Bj]。

这是**固定实现的均值最小值**，不是每条 query 事后 min，也不允许 default 故意变慢。若原候选均值 T_A、原默认 T_B、D=T_A−T_B；候选净节省 S_A=T_A−T_A_new；各默认净节省 S_Bj=T_B−T_Bj，含原版 S_B0=0，则候选快过全部控制当且仅当

    S_A>D+max_j S_Bj。

若另考虑[省组理论§3.4](certified_group_elision_theory.md)的随机风险界版本，δ失败概率不能自动使该默认实现属于此处的逐ID保真J。它仍有自己的真实质量响应H_Bj；须按实际质量/完整时间比较，并保留原Default3质量与时间控制，不能通过默认的潜在损伤降低候选质量门。同质量J的简化公式只覆盖已证明保真的版本。首次差异风险界也不等于固定事后已选metadata一定保真或已证更快。

若预声明至少 g>0 的 QPS 增益，相应要求

    S_A≥D+max_j S_Bj + g/(1+g)·T_B_best。

这继承上午完整成本恒等式：[原成本条件](../20261002_theory_until1300_v1/full_cost_conditions.md:11)。旧 E166 约 23.282μs/query 仅是共享研究核的旧缺口量级，不能作为新环境精确门，更不能转成 target 访问的预测 VOI。

按需 gate 的简化式只有在默认fallback suffix成本已证不变、或其变化已计入公共费用时才成立：所有query先付c_gate，只在选择事件I支付额外分支差δT，净差才是E[c_gate+IδT]。一般状态费用应用§6.1/6.2的付费fallback差c(F)，不能只保留gate算术费而漏掉fallback cache效应。回退query也已付费；单纯“正预测才访问”没有免费默认保证。δT须为实际条件路径完整差或经过核验的trace分解，独立route/graph微计时不能替代它。E25的Base/Dual与E118的FeatureDefault已暴露这些费用；后继仍须共享简单默认控制。

## 8. 罕见 rescue/damage 与可靠性的限制

R1 对固定策略的 ΔH∈{−1,0,1}，令 r=P(rescue)、d=P(damage)，则 EΔ=r−d，VarΔ=r+d−(r−d)²。很小的净均值可以来自很少事件，也可以来自大量正负抵消；仅报总体 accuracy、胜率或平均 loss 不能辨别。K100 还要保留幅度和成员增损。

上述方差是解析恒等式，不是新计数。基于 i.i.d.、固定策略的有限样本界还须计入策略集合/选型偏差；训练中挑很多 action/cell/阈值后，对同一批均值使用单策略区间不构成安全证书。E25 的权重高度集中与 E164 的稀疏状态选择已提供具体历史限制，但不能唯一归因为信息、表示或样本；这次不重读数组估计新方差、ESS或阈值。

正均值但区间跨零属于证据不足，不等于已证明无效；训练/代理 theorem 也不替代未参与选型来源上的配对质量与完整成本确认。后续若另获实验授权，应先冻结问题、有限动作、信息/成本口径、最强简单控制与结束门；本文件没有授权该执行。
