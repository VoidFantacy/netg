# 决策目标一致性审查与后续计划

2026-09-22，状态 `STOP_CALIBRATION_ONLY_REUSE`。本轮按授权完成理论核验、旧缓存诊断和条件训练判断；**没有新的 Recall/QPS 提升，不更换 GT10 默认**。停止的是“只校准 E119 已有分数即可形成改进”这一投入路径，不是全部入口选择研究。未触发的校准不是漏做任务。

## 一、这次确实弄清了什么

### 1. Rank 的目标存在一般一致性缺口，但不是所有失败的原因

在无法区分的一组查询中，某动作 10% 概率收益 +1，90% 概率损失 -0.01，期望收益为 +0.091，应选择该动作。E119 的逐查询 gap 归一化抵消了这两个事件的幅度差；连同原 0.1 MSE 项，其唯一最优分数仍为 -0.2131393372，部署规则会错误回退。

已直接提取原源码 `objective` 函数，用 float64 与独立标量公式及导数逐项核验。这是构造出的理论反例，不是实际数据发生机制的归因证明，也不是代码没有按协议执行。原协议没有承诺普适一致性；MSE、GBDT、TabM 的失败不能归咎于这个 Rank 特有的问题。单纯去掉归一化不自动获得多动作理论保证，更不自动获得部署提升。

### 2. 会挑相对较好的入口，不等于知道什么时候应替换 GT10

诊断先固定每条查询的最高分非默认入口，再问两个不同问题：它在全 H 中是否较好；最高分大小能否判断这次切换是否值得。

GBDT 选中入口的真实效用平均分位为 Web **69.76%**、Yandex **75.12%**，相对全部入口的行均值也更好。这不是“完全没有动作排序信息”，但可能包括全局入口质量信息，不能单独证明学到了 query-entry 交互。

然而，按每折、每 K 的分数预先固定五等分后，**六个模型在两集的最高分组等 K 平均净效用全部为负**：

| 模型 | Web 最高分组 U×100 | Yandex 最高分组 U×100 |
|---|---:|---:|
| GeomMSE | -2.1279 | -0.9432 |
| CapMSE | -2.9954 | -1.6856 |
| GeomRank | -0.6340 | -1.4611 |
| CapRank | -1.1652 | -0.2546 |
| GBDT | -1.1171 | -0.9064 |
| TabM | -1.7731 | -2.6117 |

U=ΔRecall−0.1×归一化搜索时间差。**U×100 不是 Recall 百分点，也不是 QPS。** 最高组每 K 为 816/4096 查询，五组因整除关系略不等大。每条查询原候选可能本应回退，强制候选只用于诊断；这个表不是已部署门控效果。

唯一事先提名的 GBDT，最高组 U×100 的描述性 95% 区间为 Web [-2.0566,-0.1729]、Yandex [-1.6464,-0.1768]。最高组与其余组的差值虽均值为正，区间仍跨 0，Yandex 仅 2/4 折差值为正；最高组各 K 的召回也未过质量门。因此没有触发 monitor-only isotonic 最小校准对照，不改阈值或换另一模型接续。

保留正信号：Web 两个 Rank 的最高组相对其余组有正的描述性区间，但其本身仍未超过默认。Yandex 个别非最高分组有正均值，也完整保存在 JSON 中，不把它们选作新规则。本诊断既不能证明所有更窄子集无收益，也不能证明任意非单调校准无效；它足以否定本轮预先限定的训练准入条件。

### 3. L128 不是统一的高召回工作区间

从 E103 已有默认曲线重新计算：

| 数据与指标 | L128 Recall | 90% Recall 的相邻实测 L | 局部 ΔR/ΔlogT |
|---|---:|---:|---:|
| Web R1 | 75.9500% | 640 / 800 | 0.06591 |
| Web R100 | 65.7575% | 1120 / 1250 | 0.08468 |
| Yandex R1 | 91.0500% | 96 / 128 | 0.08877 |
| Yandex R100 | 83.7623% | 200 / 256 | 0.10801 |

这是旧公开评测的区域定位，不是 E119 同一查询集的新测量。Web R100/L1120 是 89.9997%，严格低于 90%，不能四舍五入后算达到门槛。

在局部平滑且 R'(L)、T'(L)>0 的条件下，等召回时间变化近似为 `ΔT + 评分成本 − (T'/R')ΔR`。因此效用权重可由目标区域的 `dR/dlogT` 联系到性能目标，但离散曲线需要真实测量。已有斜率并不说明 0.1 权重离谱，不能把改 lambda 当作救法。应修正的是：**单个低预算代理与完整部署目标不是一回事**。E118 已有完整曲线负结果仍保留，不能借此否认它。

## 二、论文给出的框架与限制

[SPO 校准与风险界](https://proceedings.neurips.cc/paper/2021/file/b943325cc7b7422d2871b345bf9b067f-Paper.pdf)帮助明确“学习误差如何约束决策遗憾”，但其 SPO+ 一致性需要条件分布等假设，不能直接套在我们的稀疏、不对称收益上。[决策学习与排序](https://proceedings.mlr.press/v162/mandi22a.html)帮助区分排序、幅度和最终决策，也不证明任意排序损失都正确。完整推导、条件和反例见 [theory.md](theory.md)。

E119 已检查 ALORS、UniRoute、双线性算法选择、RouteLLM 和作者 TabM；此前 E25、E32、E36 已有收益加权门控和直接策略目标。这轮不把校准、SPO 或一个更强评分器包装成新方法。当前产出是更准确的问题分解，不是论文创新已经成立。

## 三、合理的接续顺序

1. **本轮到此收口。** 六模型诊断、原目标反例、90% 工作区间合同及独立数值审计均完成。无新模型训练、原生部署、测试载荷或自动实验队列。
2. **下一次研究应先解决目标预算的信息问题。** 首要问题不是继续解释 L128 的坏例，而是在上述四个实际工作区域，入口变化究竟能稳定保留多少挽救、产生多少损伤、支付多少完整成本。已有目标预算标签是否存在、能否合法复用，应在任何生成前核查；不默认重做两集全 H 标签大扫。
3. **只有具体结构假设才触发新的最小实验。** 新提案必须写出在线可观测信息、为何它在目标预算与净增损有关、成立条件/反例、相对旧实验与前作的差异，以及同监督简单控制。监督目标至少要通过本轮的条件均值/决策一致性检查。不得把换损失、扩大模型或更多数据本身当作新假设。
4. **最终仍由匹配召回完整 wall 决定。** 主目标固定为两集真实 R1/R100 的 90% Recall，95% 仅为可达时辅助报告；各配置保持固定 L，主搜索不变。模型/规则先冻结，未曝光测试身份先核验，再 CPU15 实际单线程串行测完整路由、评分、搜索及输出。缓存门或单个 L 不替代这一步。

这里没有承诺某个新模型一定提升，也没有用新的宽泛门槛无限延期训练。当前唯一获授权的条件校准已经按具体规则判定不执行。后继需带来目标区域的新证据或新结构，而不是重启 E119。
