# E174 代价与收益的理论解释

本文只解释冻结 `protocol.md` 的 M5 关系与可证伪假设。未读取本轮 GT、返回、Recall 或 QPS，未做数值计算；不新增资格门、参数、实验或调参建议。三轮、两角色与局部证据的实际判定仍沿原协议。

原 GT 主搜索返回记为 (R)，原 M5 查表产生的完整候选记为 (C)。区域版先完成原 M5 的 fresh scalar 重评分与严格合并，再用 (C) 中已付分数选择 seed，从原 NSG 一跳产生 (X)。它保留主搜索与全部 (C)，不回收主搜索预算；seed 复用分数也只免去再次评分，仍需选择、邻接访问、过滤、去重与合并。额外 scalar cap 约束 (X) 的新评分数，不能代表完整 wall。

令 (W_G(L),W_M(L),W_E(L)) 分别为同一 query 数 (n)、真实 K 和同一轮上的 GT、原 M5、区域版完整批次 wall；QPS 为 (n/W)。以下恒等式作用于所比较的完整 wall，不能将 NDC 或候选数量代入时间。它们不是对三轮汇总方式的改写。

**同 L 没有可由保全关系推出的 QPS 双升保证。**

定义 (A_T=W_M(L)-W_G(L))、(E_T=W_E(L)-W_M(L))，则

\[
W_E(L)-W_G(L)=A_T+E_T.
\]

在其他执行条件相同、附加工作可加的理想代价模型中，查表、R/C 重评分、seed/X 工作的直接代价非负；同 L 保留主搜索，没有算法规定的主搜索节约项。因此不能由扩大候选集合推出更快，甚至不能由 Recall 救回推出 QPS 双升。实际完整 wall 的差还受缓存、内存布局、执行波动等影响，差分 (A_T,E_T) 不必自动等于某段代码的独立因果费用，也不预设其观测符号。若出现同 L 更快，须依据完整 wall 证据解释，不能把它写成“额外 dot 很少，所以必然更快”。

**跨 L 必须同时偿还时间和质量差额。**

记冻结的小、大 L 为 (s,h)。令 (S_T=W_G(h)-W_G(s))，仍使用小 L 的 (A_T=W_M(s)-W_G(s))、(E_T=W_E(s)-W_M(s))。区域版小 L 对大 L GT 的速度条件严格等价于

\[
W_E(s)<W_G(h)
\quad\Longleftrightarrow\quad
A_T+E_T<S_T
\quad\Longleftrightarrow\quad
E_T<S_T-A_T.
\]

新增区域工作只能花在减少 L 后留下的完整时间余量内；原 M5 的查表、合法域 guard、R/C 重评分和合并也占用余量。在非负附加代价模型下，区域费用小于所省主搜索耗时只是必要条件，扣掉原 M5 后的余额才是更严格的条件。不能只拿 X 的 dot 数与主搜索 dot 减少量比较，也不能把较大 L 的新搜索称为同状态续搜。(S_T) 是实际完整差额；图搜索的返回、路径和时间不被假定随 L 单调或线性变化。

质量使用原冻结 GT 成员定义。令 (h_A(q)=|A(q)\cap G_K(q)|)，并定义整数差额

\[
D_K=\sum_q[h_{G(h)}(q)-h_{G(s)}(q)],\quad
A_H=\sum_q[h_{M(s)}(q)-h_{G(s)}(q)],\quad
E_H=\sum_q[h_{E(s)}(q)-h_{M(s)}(q)].
\]

小 L 区域版对大 L GT 的 Recall 正差严格等价于 (A_H+E_H>D_K)，即 (E_H>D_K-A_H)。降 L 的质量差额允许逐 query 有正有负，不能假定两个返回集合嵌套。原 M5 已有的补偿 (A_H) 必须单列；若原 M5 已跨过大 L GT 的质量门或已有跨档双升，区域贡献仍只限于同小 L 的增量 (E_H,E_T)。时间条件和质量条件缺一不可。

**配对救回与损伤解释净值，候选覆盖解释可达机会。**

对同 query 的候选返回 (A) 和参考返回 (B)，记

\[
r(q)=|(A(q)\setminus B(q))\cap G_K(q)|,\quad
d(q)=|(B(q)\setminus A(q))\cap G_K(q)|.
\]

则 (h_A(q)-h_B(q)=r(q)-d(q))，Recall 百分点变化为 (100\sum_q[r(q)-d(q)]/(nK))。只报新增救回会遗漏损伤；保留全 (C) 是保留可供排序的支持，不等于最终 K 个 ID 是原 M5 的超集，原 GT tie 与实际 scalar 数值边界仍须按返回成员核验。

只有基线与扩展使用统一精确分数、GT 确为该分数和一致 tie 规则下的真实 TopK，且两次合并都返回同一全序下候选集合的 TopK 等条件成立时，才可论证扩大支持不会减少 GT 命中。本轮的严格距离入堆与 arrival 优先级不自动等于预存 GT 的 tie 规则，实际浮点分数也不能被理论精确分数替代。原 M5 还重新评分 R，可能改变原排序；相对 GT10 更不能直接套用这种单调性证明。实际损伤必须来自 `comparisons` 的 paired damage，不能由保留 R+C 或严格堆结构推定为零。

M5 区域版相对原 M5 的新增真成员应来自 (X)；但“X 含有目标”“目标进入最终返回”“净 Recall 正差”是不同命题。X 位于原 posting 或原 TRAIN GT100 ID 并集之外，只说明候选支持越过该有限 ID 记忆，不能证明本 query 命中了目标、没有损伤或得到了双升。X 仍受选中 seed 的一跳邻接、主 visited 过滤与冻结 cap 限制，不等于拥有任意全库目标的访问能力。

**冻结对照限定解释范围。**

| 对照 | 能检验或限定的替代解释 | 不能据此宣称 |
| --- | --- | --- |
| 原 M5；同小 L 的 REG−M5 | 区分原 M5 已有优势与新增区域支持、救回/损伤、速度费用 | 将整个跨 L 优势归给 X |
| 真实 K1 与 K100 各自运行 | 区分最近目标救回与集合覆盖；K100 的成员收益分母更大，原 R 重评分规模也可能更大 | 从 K1 外推 K100；把分母作为全部原因，或称冻结 M5 没有 GT100 监督 |
| M5FIRST96 对 M5REG96 | 同一份 C 上，first seed 是否已足够，query-best 分数选择是否带来局部增量 | 不同 seed 的邻接覆盖与费用必然相同；分数选择优越具有普遍保证 |
| MF 的 direct/region 与 M5 region | 原冻结频率来源是否也能提供有效 seed；区域增益是否需要 M5 的具体监督选择 | 将差异全部归因于一种训练机制；相同 cap 就是相同费用 |
| GEO 的 direct/region 与 M5 region | 原几何来源是否也足以通过同一扩展器获益 | 全流程无监督，或 M5 的差异已证明跨模态独有机制；GEO 继承 GT10 画像 |

FIRST、较小额外 cap 和 MF/GEO 的 direct 配对只在 pilot a 中存在，不能写成 confirm b 重复了这些控制。若频率或几何来源同样有效，解释应收缩到这些冻结条件下的通用区域候选生成；即使 M5 更强，也只支持相应来源、query、K、L 和预算上的局部差异。不同 posting 行不证明不同 basin，跨模态残差监督与表外 ID 不证明已测 modality gap、语义桥或因果机制。
