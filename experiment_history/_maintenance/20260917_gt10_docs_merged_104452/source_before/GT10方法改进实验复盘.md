# GT10 形成后的研究简报

整理日期：2026-09-17。范围：2026-09-10—09-14，E25—E95。
以下为历史 Recall@10 结果，pp 表示百分点；新实验已改用 Recall@1/100。训练或开发集的局部收益与最终性能分开说明。

**2026-09-10｜选择性使用 GT10（E25—E26）**

- **门控选择：**学习哪些查询用 GT1、哪些用 GT10，希望保留收益并避开损伤。双路门控有少量召回改善，但额外路由导致 QPS 下降，未形成稳定优势。
- **画像收缩：**直接混合 GT1/GT10 画像，维持一次小图路由。多数点削弱了原 GT10 收益，没有同时做到保留收益、减少损伤。

**2026-09-11｜机制分析与 MLP 改进（E27—E32）**

- **GT10 机制：**检查目标归属、画像支持和真实入口变化。GT10-hard 的有效样本量中位数由 WebVid 的 16 增至 67.36、Yandex 的 22 增至 60.08；打乱目标关联后多数结果变差，支持多目标关联信息有作用。
- **离线 MLP：**在 GT10-hard 画像上训练共享线性变换、小 MLP（d→64→d）及自由残差；导出新画像后重建小 HNSW，线上不运行 MLP。
- **真实联合教师：**每条查询取 8 个候选，枚举 56 个三入口组合，用真实搜索命中与距离次数选教师，训练画像评分。WebVid 的 MLP 在 L400 比 hard 高 0.240 pp、QPS 约持平，但低预算和 Yandex 未稳定改善。
- **教师与损失改进：**试过无收益时保留原入口、多组等效教师、交叉熵与 margin 对照、延长优化，以及直接最大化组合期望 Recall。训练收益有所提高，最终未稳定超过原 GT10；直接组合评分还增加在线成本。

**2026-09-11｜小图删边 RL 与在线 MLP 换点（E33—E36）**

- **删边 RL：**学习小 HNSW 底层边的保留概率，以真实搜索反馈训练，部署静态图。路由距离次数下降约 18%～19%，但完整 QPS 没有稳定改善；WebVid 有局部正值，Yandex 效果较差。
- **在线换点 RL：**一次小 HNSW 取 8 个候选，MLP 决定三入口的替换或停止，最多三步；同时做同策略精确梯度对照。
- **结果：**audit512、L128 上，WebVid Recall −0.4688 pp、QPS −9.32%；Yandex Recall +0.3906 pp、QPS −8.30%。模型即使早停仍先评分全部 56 个集合，距离计数没有体现这部分运算成本。

**2026-09-12｜离线画像 RL、反馈与更新改进（E37—E59）**

- **离线画像 RL：**把学习移回离线，扰动画像参数→重建小 HNSW→真实搜索取奖励；比较 RL 与成对扰动的 ES。随后从整套画像共享变换改为每次只动一个画像，完整性能仍未稳定改善。
- **完整反馈：**发现小 batch 经常漏掉有效动作，增加全池反馈；通过相同查询、完整三入口和搜索配置的精确缓存减少重复调用。解决了部分反馈遗漏，仍未解决收益迁移。
- **更新转化诊断：**已有净正候选的 RL 步骤中，更新后的均值模型仍不改变训练池命中的比例，WebVid 为 85.98%，Yandex 为 95.88%。连续参数变化经常没有跨过入口选择的离散边界。
- **贪心提交：**直接从真实评估的候选中择优提交，这是非 RL 对照。WebVid 两 seed 的 monitor 增量为 +0.3125/+0.2051 pp，比原 RL 更明显；Yandex 一正一负，迁移仍不稳。
- **RL 步长接受：**保留 RL 方向，真实比较四分之一步、半步、整步和不动。获得局部正值，未建立最终优势。
- **纯构图 RL：**只学构图向量，建图后恢复原 GT10 评分向量，分离评分与邻接变化。仍只有局部收益，没有成为最终优选。
- **最终比较：**扩展到每集 19 个候选后先选型，再比较五个 L。选出的新方法相对原 GT10 默认，十个数据集×预算点的 Recall 全部略低，QPS 差异处于重复计时范围内；默认不变。

**2026-09-13｜重权、多画像与局部修复（E60—E94）**

- **迁移支持检查：**固定 RL 动作在另一来源查询上验证，两集满足原训练目标和辅助支持的状态均为 0/40，停止扩大相同动作。
- **遗漏目标／失败查询重权：**提高未找到的 GT 成员或零命中查询的画像权重。部分训练点变好，也会损伤原本正确的查询，未稳定通过开发验证。
- **多画像：**每个真实 hub 增加两个子画像，一次小图检索后去重为三个真实入口；继续试过去重精简、搜索加宽、子画像收缩和目标空间联合分组。
- **局部信号：**Yandex 精简多画像在历史开发集 L128 比 hard 高 0.2881 pp、QPS 低约 0.96%；WebVid 未获得同样改善，不能直接当作跨数据优势。
- **补边与父画像恢复：**依据查询排名和真实搜索效用补小图边，恢复部分父画像，再组合两种修复。单项训练收益合并后并非简单相加，跨查询仍有增益与损伤。
- **冻结最终比较：**WebVid 组合在 L128 比精简多画像高 0.270 pp，但比原 GT10-soft 低 0.385 pp；Yandex 精简版比 hard 高 0.070 pp，高预算又有损伤。完整曲线未支持替换默认。这些后续构造和修复多数不是 RL。

**2026-09-14｜查询统计构图与分支停止（E95）**

- 使用查询二阶矩的完整矩阵／对角尺度生成构图向量，建小图后恢复原 GT10 评分。
- 两数据集、两种构造、L64/L128 共八个开发点，Recall 全部下降、零命中全部增加，因此未继续测 QPS，停止当前固定 hub 的画像／小图增强分支。

**阶段结论**

- GT10 原有收益保留，默认仍为 WebVid GT10-soft-t1、Yandex GT10-hard。
- MLP、RL 和后续表示改造都实际训练或验证过，有局部进展，尚未稳定超过原 GT10。
- 已定位的问题包括监督与联合搜索效用的差距、反馈稀疏、更新难以改变入口、跨查询损益和在线成本；不能简单归因于“训练不够”，也不能推断所有 RL 都无效。
