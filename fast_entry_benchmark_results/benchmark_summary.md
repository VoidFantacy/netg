# Fast-Entry 双数据集 QPS / Recall / Tail 报告

> 统一协议：held-out 10K queries；QPS 每个 artifact 内运行 3 次；Fast 使用聚类 seeds `20260828/20260829/20260830`。

QPS 的 `±` 为内部重复与 Fast 跨 seed 合并后的总体标准差。跨 invocation 的原始 QPS 会受系统状态影响，因此 Fast/Neural 判断优先看同次 Medoid 归一化后的差值。

## 结论速览

- **WebVid：Fast Prototype 明确优于 Formal Neural。** Recall@1 提高 `+0.0080~+0.0131`，Recall@100 提高 `+0.0021~+0.0032`；同次 Medoid 归一化 QPS 分别提高 `+1.15%~+9.67%` 与 `+1.83%~+8.89%`。
- **Yandex：Fast Prototype 基本复现 Formal Neural，并获得小幅 QPS 优势。** Recall@1 差值为 `-0.00213~+0.00003`，Recall@100 差值为 `-0.00020~+0.00018`；同次 Medoid 归一化 QPS 分别提高 `+1.34%~+7.16%` 与 `+1.14%~+5.53%`。
- **Tail 没有被均值掩盖。** 相对 Medoid，Fast 在两个数据集、全部 L 和全部 预注册阈值上均为正净救回；WebVid 的 Fast tail 进一步优于 Neural，Yandex 则总体与 Neural 接近。
- 因此当前证据支持 fast-entry 的跨数据集有效性，但论文表述应区分：WebVid 是效果与速度双提升，Yandex 是基本等效效果下的低成本替代。

## 解释边界

- Recall 在同一 artifact 上是确定性的；Fast 的 recall/tail 标准差来自三个聚类 seed。
- QPS 不是跨日期单次值，而是当前统一批次的多次运行；仍应同时看 mean/std。
- Fast 与 Formal 位于不同 invocation，优先使用 same-run Medoid 归一化差值消除机器状态漂移。
- Tail 的重复运行不会改变确定性结果，因此用三个 Fast seed 衡量方法方差，而不是机械重复同一文件。
- 本报告不包含 exact train-GT 生成成本；离线总成本结论必须另行计入。
