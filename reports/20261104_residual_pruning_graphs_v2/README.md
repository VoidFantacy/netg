停止依据来自E199原测量：80个主门窗口点中79个被同期强控制覆盖；剩余WebVid A/K1点仅快0.0254%，三轮速度范围重叠且B窗未复现。完整学习级联16个窗口点全部被覆盖。精排相对同池学生选1，K100只增加0.022–0.086个百分点召回而完整耗时增加23–38µs；K1无正增益，耗时增加23–129µs，WebVid召回还下降0.098个百分点。因此当前复杂版本不再值得继续堆叠。

直接补点的机制很简单：离线把训练查询中主搜索遗漏的真实目标ID记入对应路由行，线上取三个路由行、去重并排除原返回，用原metric计算候选距离，与原Top-K合并。B32每行最多32个ID，三行去重前最多96个；16K/8K表示用于造表的监督查询数，不是线上候选数。这两个表版本仍属于一个补点方法；没有在线学习选点、短名单重排或追加图导航。

历史条件有效的M5/B32/SQ及返回等价工程省费保留原身份。E199的8K直接表在COCO/K100和WebVid/K1有两窗有限网格未覆盖观察，但最弱窗口速度优势分别仅约0.14%与0.21%，不作为稳定替换证明。曲线中的SQ菱形只是同期L200条件对照，未把旧方法全部判负。历史正面结果见[原证据目录](../../experiment_history/_maintenance/20261029_residual_positive_evidence_sync_v1/conclusion_zh.md)。
