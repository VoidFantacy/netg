# Fast 最佳入口诊断：可证伪定义与理论边界

2026-09-08。此笔记在新诊断结果产生前定义分析口径，并只读核查本地 v2 报告、Fast/NSG 源码和原论文。没有运行搜索、训练或修改旧文件。后续结果及执行参数以本目录冻结协议为准；本文不预判结论。

**“Fast 选不到最好入口”至少包含四种不同问题：实现未兑现代理分数、几何代理本身错位、最优入口随预算变化、当前表征与样本密度不足以迁移搜索效用。一个失败的 selector 或低 oracle-ID 准确率，不能在这四项之间完成归因，更不能证明最佳入口普遍不可学习。**

## 1. 对象必须限定到当前图、池、目标和预算

令 `G` 为冻结的原 NSG，`H` 为当前 815/821 个真实 base hub IDs，`L∈{64,128}`，`K=10`。令

`Search(q,e,L;G)` 表示原始 IP、单入口 e、原 kernel 下的完整搜索。

为每次搜索保存命中数 `h(q,e,L)∈{0,…,10}`、`R=h/10`、graph NDC `D(q,e,L)`，以及相对该 query 的 GT10 hit mask。`R*_H(q,L)=max_{e∈H}R(q,e,L)` 只是**当前池的免费单入口 Recall oracle**，不是全 base、所有图或三入口的上界；其 NDC 也没有支付获知最佳入口的成本。

Recall 优先的可展示代表为 `e_R(q,L)=argmax_e (h,-D,-base_id)`。其中 NDC 和 base ID 只用于固定同分规则；**不能因人为挑出一个代表，就把其他同 Recall 的入口当负标签。** 如果需要成本优先或混合 utility oracle，必须另外命名、固定系数，并同时保留原始 R/D；不把它和 Recall oracle 混用。

当前 `ACSG.cpp:1517–1537` 最多接受前三个入口、共享 visited；`:1565–1638` 按真实 query–base 距离排序，维护容量 L 的候选池和回退扫描。因此多入口的结果是一个新的联合搜索动作，不能由多个独立单入口结果替代。[原 kernel](../../../ACSG/ACSG.cpp)

## 2. 并列与近优集合：先排除“标签很难，但选好并不难”

用整数命中定义，避免浮点阈值歧义：

`Aδ(q,L)={e∈H : h(q,e,L) ≥ max_H h(q,e,L)−δ}`，主报 `δ=0` 和 `δ=1`。

`A0` 包含所有最大 Recall 入口；`A1` 允许少命中一个 GT10，也就是每 query 的 Recall@10 少 0.1。后者不是平均 Recall 允许少 10 个百分点的通过门槛，只是描述局部目标有多尖锐。若该 query 的最大命中为 0，`A0=H`；此时标签完全不唯一，也没有正 Recall oracle 空间，应单列。

最小统计量：

| 量 | 解释 |
|---|---|
| `|A0|`、`|A1|` 的分位数与占 H 比例 | 好入口是稀少尖峰，还是很大的平台；集合越大，唯一 ID 准确率越不合适。 |
| `1[Fast1∈Aδ]`、`1[C8∩Aδ≠∅]` | 当前选择和短名单是否已包含最优/近优解；不能只看是否命中 `e_R`。 |
| `R*_H−R(Fast1)`、`R*_H−max_{e∈C8}R(e)` | 真实 Recall 遗憾值；后者衡量短名单漏掉了多少当前池机会。 |
| `D(Fast1)/min_{e∈A0}D(e)`，在 `Fast1∈A0` 的 query 上 | 同 Recall 平台内是否主要剩成本空间；不让低 Recall 但便宜的入口混入比较。 |
| `min/median/max D` within `A0` | Recall ties 不代表所有“好入口”同样便宜。 |

随机从 H 选中 `Aδ` 的基准概率为 `|Aδ|/|H|`。跨 query 的集合重叠还受 hub 全局流行度影响，不能只和这个均匀基准比较；第 5 节增加随机源 query 控制。

若唯一 `e_R` 预测/迁移差，但 `A0/A1` 覆盖高且 Recall regret 很小，正确解释是“唯一标签不稳定或过严”，不是“实用入口难以预测”。

## 3. 跨 L 稳定性：比较效用迁移，不只比较 ID

同一个 query 和同一个入口的效用，必须带预算索引。至少报告：

- `Aδ(q,64)` 与 `Aδ(q,128)` 的 Jaccard、交集是否为空；Jaccard 小但交集非空仍可能存在共享好入口。
- 双向代表迁移遗憾：`R*_H(q,128)−R(q,e_R(q,64),128)`，以及交换 64/128 的反向值。
- 去除 tie-break 影响的集合迁移：将源 L 的整个 `A0` 搬到目标 L，分别报其中平均 Recall 和最大 Recall。最大值是利用目标标签后的乐观诊断；不是可部署选择。
- 跨两 L 的低遗憾公共入口是否存在：`min_e max_L [R*_H(q,L)−R(q,e,L)]`。它使用当前 query 的两 L 标签，仅表示是否存在预算稳健的入口。

如果 `e_R` ID 常变而双向遗憾很小，预算并没有制造重要的决策冲突。只有在集合也少重叠、双向遗憾和公共入口遗憾都明显时，才支持“最佳入口对 L 有实质依赖”。即使如此，也只能反驳一个**不含 L 的统一标签**，不能证明含 L 的模型学不会。

同一个入口在更大预算下的行为、以及不同入口之间的排序，是两件事。不能仅凭跨 L 排序变化就声称搜索随机；也不能把更大 L 的效用当成小 L 的标签。

## 4. 几何 basin 与真实好入口之间的错位

源码 `build_fast_entry_variants.py:144–164,293` 明确使用每个训练 query 的 GT1 base vector，并按它与 normalized raw hubs 的 cosine 最大值分配 basin，再将该 basin 内 normalized queries 与 raw-hub prior 相加并归一化。它不使用 `Search(q,e,L)` 的 Recall、NDC 或路径标签。[画像构建](../../../benches/run/build_fast_entry_variants.py)

在诊断 query 上离线定义几何标签：

`b(q)=argmax_{e∈H} cos(x_GT1(q),x_e)`。

注意这个定义消费 query 的 GT1，只能作离线代理核查，不能在线使用。令 `f(q)` 是实际 Fast1 入口，可写出精确记账恒等式：

`R*_H−R(f) = [R*_H−R(b)] + [R(b)−R(f)]`。

第一项衡量**即使直接知道几何标签，仍剩多少真实单入口搜索差距**；第二项衡量实际 Fast 相对几何标签的效用差异，可能为负。不能把第二项命名为非负“拟合误差”，也不能把两项占比强制裁剪到 0–100%。

建议并列四项：`b∈Aδ` 的比例、`b` 的 Recall/NDC、exact prototype top1 的 Recall/NDC、实际 Micro-HNSW top1 的 Recall/NDC。exact prototype 是同一画像分数的精确检索，不是新的搜索效用模型。

- 若实际 Micro-HNSW 与 exact prototype 入口不同，应先量化**代理分数检索误差**；其搜索效用差可正可负，exact 代理检索不保证更优搜索。
- 若 exact prototype 与 b 不同，这是画像分类器没有完全恢复其几何标签；是否由单均值、多模态、样本少或 prior 造成，单次比较尚不能区分。
- 若直接用 b 也远离 `A0/A1`，可否定“只要把当前 GT1 basin 标签预测准，就能到达真实最好入口”的解释。它支持代理错位，但不证明这是全部差距的唯一原因。
- GT1 更不能自动代表 GT10 分布；“离 GT1 近”也不意味着该入口在固定图和 L 下会遍历到全部 GT10。

若需要 C8 内外的归因，单入口 Recall 可非负分解为：

`R*_H−R(Fast1) = [R*_H−max_C8 R] + [max_C8 R−R(Fast1)]`，前提是实际 Fast1 确在 C8。

该分解分别是短名单之外与短名单之内的空间。exact prototype C8 和 ANN C8 之间没有效用集合包含关系，其 oracle 差值必须保留符号，不能预设 exact C8 的真实效用更好。

## 5. 邻近 query 效用迁移与 20K 密度控制

主计划为每数据集预定 512 个历史 pilot query；另对其中预定前 128 条，从同一 20K prototype-fit 范围各找一个 cosine 最近 fit query，并取预定 128 条随机 fit query 作控制。去重后的总搜索行数不超过 768。所有行都计算 H 上两 L 的单入口结果。这里的 20K 最近邻扫描属于离线诊断，费用必须记录；不训练新 selector，也不将历史 pilot 称独立测试集。

令 `s(q)` 为一个源 query，例如最近 fit query。源 query 的 `Aδ(s(q),L)` 已由其全 H 搜索得到。固定 q/L 后报告：

`T_mean(q←s)=mean_{e∈Aδ(s,L)} R(q,e,L)`；

`T_best(q←s)=max_{e∈Aδ(s,L)} R(q,e,L)`；

对应遗憾为 `R*_H(q,L)−T`。另可报告按固定 `e_R(s,L)` 直接迁移的结果，但不以这个任意 tie 代表替代集合结果。

`T_mean` 是对源 query 所有同等好入口的平均迁移效果；`T_best` 是源好入口集合在目标 query 上**是否至少藏有一个可迁移入口**。后者查看了目标的真实标签，是乐观上界，不能写成最近邻 selector 的实测质量。若 best 高、mean 低，问题可能在集合内选择；若二者均低，源最优集合本身难迁移。

最小控制应保持以下配对：

1. 同一前 128 pilot 上比较“512 pilot 中 leave-one-out 最近邻”“20K fit 最近邻”“随机 fit 源”。第一项不存在足够其他合法行时才记缺失；不把自身作为最近邻。以主协议实际包含的标签行与映射为准，不新增 search。
2. 报源-目标 cosine 距离及其分位数，确认 20K 最近 fit 的确更近；精确重复/近重复 query 单列。否则所谓密度控制没有兑现。
3. 最近源和随机源都用相同 δ、L、H、tie 规则；随机源映射在看标签前固定。也可对全部 128 个随机 fit 源求平均参考，不能把这 128 个源当作 128 倍独立目标样本。
4. 整行效用向量的源 query 置换可检查“相近”是否比一般 query 更有信息；置换时两 L 一起移动，保留 hub 的流行度与同 query 动作相关性。
5. 如已有 GT10 元数据，可描述源-目标的 GT10 重叠，区分“query 向量接近但目标不同”和“目标也相近但搜索入口不迁移”。这是解释变量，不是在线输入。

“最近 fit 明显近于随机，迁移仍不优于随机”只支持**在该表征、采样密度和有限候选/预算下，简单局部效用迁移信号弱**。它不能排除更合适的表示、分布条件或不同模型，也不能估计不可约 Bayes error。512/128 条观察无法证明高维 query 空间处处不连续或不可学习。

反过来，最近 fit 迁移明显优于随机，会直接反驳“当前输入完全没有可预测信息”；但最近邻诊断是离线查完整效用矩阵，仍未支付可部署路由/存储成本，也不构成新方法 GO。

## 6. 联合入口：用真重放解释代理错位

对 pilot512 的 C8，计划计算全部 28 pairs 和 56 triples；single 已来自全 H 表。不同入口数分别报告，不能让三入口与单入口的变化直接代表“学到互补”。

令 `M_e` 为独立单入口的 GT10 hit mask，`M_S` 为同一 L 的联合动作真实 mask。定义：

`P(S)=union_{e∈S} M_e`，

`lost(S)=|P(S)\M_S|`，`new(S)=|M_S\P(S)|`。

于是 `R_joint(S)−R_union_proxy(S)=[new(S)−lost(S)]/10` 是精确记账。`lost` 表明独立搜索能找到的目标在共享搜索中未找到；`new` 表明联合搜索找到单入口独立结果均未命中的目标。两者允许同时存在。

这个并集代理支付了多次独立搜索隐含的探索预算，本来就不是共享池的同成本算法；它既不是严格上界，也不是严格下界。真实 replay 可以证伪“独立好入口直接取前三就足够”，但不能仅由 gap 推出交互可由廉价特征学习。组合 oracle 仍限定 C8、原 kernel、给定 m 和 L，不是全 H 组合 oracle。

## 7. 路径敏感性：源码能推出什么

本地 kernel 的桥接节点可能先被发现，但因为 `dist >= retset[L−1].distance` 被拒绝进入候选池（`ACSG.cpp:1581–1599`）；visited 在这个判断之前标记。一个节点与 GT 的几何位置、图上存在到 GT 的路径，都不足以保证该路径上的必要中间节点在本次有限 L 搜索中被展开。

不过“依赖路径”不等于“随机”。固定 query、图、入口顺序、distance 实现和 tie 行为，且无随机 fallback 时，这个函数有确定输出。plain/count 或重复重放不一致首先是实现、状态或数值行为的验收问题，不应归为标签噪声。

另有一个可由代码比较结构得到的**理想实数算术推论**：固定图/入口/L 时，raw-IP 分支比较依赖 `q·(x_i−x_j)` 的符号。在保持所有相关点积分数次序的 query 区域内，遍历决策与返回 IDs 保持不变；GT 的 top-K 次序也保持不变。跨越某些比较边界时结果可以突变。因此效用可具有分段常值结构。这个推论只说明局部稳定区与边界均可能存在，不说明现实 query 恰好靠近边界，更不说明小模型一定能或一定不能表示这些区域。浮点运算/tie 的实际边界需以冻结实现为准。

本次不额外扰动 query 或扩展搜索预算来寻找不稳定案例。跨 L 与近邻迁移统计是现有授权矩阵内的诊断，不能把它们改名为对任意微小扰动的鲁棒性证明。

## 8. 原论文支持到哪里

以下仅列实际核查的理论相关段落，不声称完整综述。

| 原论文与阅读范围 | 能使用的结论 | 不能套用到当前任务的结论 |
|---|---|---|
| Fu et al., NSG，PVLDB 2019，引言、Alg.1、§2、§3.1 | 搜索显式依赖起点和有界候选池；引言区分 MRNG 理论与实用 NSG 近似。 | 不可把 Euclidean、理想单调图的结论变成当前 raw-IP 冻结 NSG 的入口最优性或可学习性保证。 |
| Prokhorenkova & Shekhovtsov，ICML 2020，§3、§4.4/Theorem 4、§5.1 | 对均匀球面数据、规定图构造与维度范围，分析 beam 的准确性和复杂度。 | 200/512 维真实 OOD/raw-IP 数据并未核实满足这些分布/图假设；论文没有证明入口标签光滑或可学习。 |

来源：[NSG 官方论文](https://www.vldb.org/pvldb/vol12/p461-fu.pdf)、[ICML 2020 官方全文](https://proceedings.mlr.press/v119/prokhorenkova20a/prokhorenkova20a.pdf)、[NeurIPS 2023 官方全文](https://proceedings.neurips.cc/paper_files/paper/2023/file/d0ac28b79816b51124fcc804b2496a36-Paper-Conference.pdf)、[作者 hard-instance 仓库](https://github.com/xuhaike/Hard-Instances-for-Popular-Approximate-Nearest-Neighbor-Search-Implementations)、[Adaptive Beam Search §4](https://arxiv.org/html/2505.15636v1#S4)、[其桥接点反例](https://arxiv.org/html/2505.15636v1#A1.SS2)。

尤其需保留三个逻辑边界：

1. **搜索保证不是学习保证。** 图导航定理研究某个搜索算法如何找到邻居，没有给定我们的在线特征、模型族、训练样本数与 query 分布，因而不能导出最佳入口的学习上下界。
2. **raw IP 不是上述 metric 假设。** 本地比较用负内积排序；它一般不满足非负性、零自距和三角不等式。只归一化辅助 query/画像没有修复原主图的 metric 条件；WebVid 近单位范数也不能当严格等范数证明。
3. **本任务不需要也没有适用的 NP-hard 论断。** 当前 H、两 L 及 C8 的有限动作可直接枚举并获得 oracle。已有枚举昂贵或廉价选择器失败，不构成计算不可解或统计不可学习的证明。

## 9. 结果出来后可以采用的结论措辞

| 观察到的模式 | 可支持的解释 | 仍不能宣称 |
|---|---|---|
| 唯一 ID 常变，但近优集合很大、regret 很小 | “唯一标签夸大了选择困难。” | “没有任何成本优化空间。” |
| ANN/exact proxy 差异大，其他合同检查通过 | “当前代理检索的近似误差值得先处理。” | “精确 proxy 必然提升实际图搜索。” |
| 直接 GT1 basin 仍远低于全 H oracle | “几何标签不等同于有限预算好入口。” | “GT1 basin 是全部失败的唯一原因。” |
| 两 L 的集合与实质效用转移均不稳定 | “当前最优选择有预算条件。” | “加上 L 也不可预测。” |
| 20K 最近 fit 比随机近，且效用迁移明显更好 | “存在局部可迁移信号，完全无信息解释被反驳。” | “该信号已能以足够低成本部署。” |
| 20K 最近 fit 仍无明显迁移优势 | “简单近邻表征下的信号有限，有限样本难度仍在。” | “不存在其他可学习规律或不可约误差已被测出。” |
| 真实组合优于单入口并集选法，但仍没有选择器 | “监督/部署对象错位有可测代价。” | “交互可学习、已获得 Recall–QPS 改善。” |

统计单位是目标 query；H 个动作、两个 L、多个源或重复计时均不是新增独立样本。主指标保持全体预定 query 的配对结果，失败/低 Recall 子集只作预先说明的描述性切片。没有明显差异可以支持停止当前有限诊断或暂不推进方法，但应使用“未发现足够证据/本配置无收益/样本下结论有限”，不用“证明不可学习”。
